# 顧客原話抽取方法論

只談怎麼消化已存在的顧客原話（評論、留言、客服對話），不談怎麼發起研究（訪談、問卷）。

## 1. JTBD 三類任務

每段原話都問：這位顧客想完成什麼任務？三層都要抽，不要只抽功能層。

1. **功能任務**：字面上要完成的事（「想要腸胃順暢」）
2. **情感任務**：想要有什麼感覺（「不再為脹氣尷尬」「想要安心」）
3. **社會任務**：想在別人眼中呈現什麼形象（「被家人覺得有在照顧自己」）

三層分開記錄，不要合併成一句。功能層放產品說明，**情感／社會層才是 Hook 與情緒文案的素材**。

## 2. 痛點判準

- **優先收「未被提示且帶情緒」的痛點**——顧客自己主動講、用了情緒字眼的（「很崩潰」「超級困擾」「終於解脫」），比被問卷選項引導出來的更真實。
- 被提示出來的（評分表勾選項）信號較弱，可以收但標低優先。
- 每個痛點同時記三件事：情境（什麼時候發生）、情緒字眼（怎麼形容感受）、顧客自己的用詞（原文照抄）。

## 3. 頻率 × 強度排序

分群後用「頻率 × 強度」決定哪個主題優先寫進文案。

- **頻率**：出現在幾筆原話裡（越多越是共通痛點，不是個案）
- **強度**：情緒字眼多重（用詞越激烈、描述越具體越高）
- 兩者都高的排最前。只出現一次但情緒很重的，標記為「值得追蹤但暫不當主打」——不捨棄也不升級。

## 4. 顧客語言直接入文案

- **原話比行銷術語有效**：「我每天都在跟脹氣奮鬥」比「改善消化機能」更有畫面、更容易被認出「這在講我」。抽取時連用詞一起記，不要只記重點意思。
- Hook 與文案優先引用抽出來的原話（或貼近原話的說法），不要憑空生成「聽起來專業」的句子。
- 引用進文案時必須**標出處**（哪個平台、哪則留言），方便事後核對與判斷可信度。

## 5. 去哪找（台灣管道）

| 管道 | 適合找什麼 |
|---|---|
| 蝦皮商品評論 | 買過的人最直接的抱怨與稱讚，帶星等可分級看 |
| momo 商品評論 | 客群偏主婦／家庭採購，語氣較生活化 |
| Dcard | 年輕族群真實討論串，「求推薦」「踩雷心得」信號高 |
| PTT 相關看板 | 長文心得、比較文，用詞直接、少行銷修飾 |
| FB 社團與粉專留言 | 社團同溫層情緒濃度高；粉專留言看得到公開提問與抱怨 |
| 客服對話紀錄 | 最貼近真實購買障礙與售後困擾，沒有公開評論的美化濾鏡 |

**電商評論的閱讀順序**：先看中低星（2–3 星，買了但沒全滿意，最誠實，常帶「其實⋯」的但書）→ 再看低星（1 星，分清是產品問題還是物流／客服問題）→ 最後看高星（5 星，抓「顧客用什麼詞稱讚」，正面素材庫）。

**高價值原話 = 具體情境 ＋ 情緒 ＋ 顧客自己的用詞**，三個條件同時具備。
✅「連續熬夜三天之後整個人腫到眼睛都腫，吃了兩天終於消下去，鬆一口氣」
❌「好用+1」「推推」「效果不錯」——沒情境、沒具體用詞，抽不出素材。

## 6. AI 抽取規則

1. 依第 2 節痛點判準與第 1 節 JTBD 分類抽取，**連原文用詞一起記，不要改寫成聽起來比較專業的版本**。
2. 每一條都標出處（哪個管道、哪一則），供之後引用與核對。
3. 生成 Hook 或文案時優先用抽出來的原話或貼近原話的說法。這是治「模型裸生成＝平庸」的主藥。
4. **語料庫為空時不阻擋生成**，但畫面上明確標注「無顧客原話支撐」，不假裝有依據。
