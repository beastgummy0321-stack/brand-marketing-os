# 文案方法論

這份文件回答兩個問題：**寫廣告文案 / Hook / 落地頁時要守哪五條鐵律？** 以及
**哪些心理模型真的用得上、什麼時候用？** 另外收一份「禁用手法」清單，擋掉會踩誠實原則
的老套路。

## 一、文案五大原則

寫任何文案前，先過這五條：

### 1. 清晰 > 聰明（Clarity Over Cleverness）
文案要在「清楚」和「有創意」之間選一個時，永遠選清楚。讀者看一眼看不懂的雙關語、
玩文字遊戲的標題，都是在賭讀者會停下來解謎——他們不會，他們會滑走。
〔來源：copywriting/SKILL.md〕

### 2. 利益 > 功能（Benefits Over Features）
功能是「產品做了什麼」，利益是「這對顧客來說意味著什麼」。保健品文案常見錯誤：
只寫「每粒含 500mg 專利益生菌」（功能），沒接「所以你不用再因為脹氣不敢出門」（利益）。
每個功能都要問一句「所以呢？」直到接上顧客真正在意的結果。
〔來源：copywriting/SKILL.md〕

### 3. 具體 > 模糊（Specificity Over Vagueness）
- 模糊：「幫助你調整體質」
- 具體：「連續喝 14 天，多數使用者回報排便從 3 天一次變成每天都有」

數字、時間、可驗證的描述都比形容詞有說服力。「調整體質」「優化循環」這類詞聽起來
專業，實際上什麼都沒講。
〔來源：copywriting/SKILL.md〕

### 4. 顧客語言 > 公司語言（Customer Language Over Company Language）
用顧客自己描述問題時會用的字，不要用公司內部的產品術語。顧客原話的來源與抽取方法見
`customer-voice.md`；文案優先引用語料庫裡的真實用詞（例如顧客自己說「脹氣脹到像懷孕」，
比行銷寫的「腹部不適」更有共鳴）。
〔來源：copywriting/SKILL.md〕

### 5. 一節一論點（One Idea Per Section）
每個段落 / 每張圖 / 每組 Hook 只推進一個論點，論點之間要有邏輯順序往下堆疊，不要在
同一段塞「便宜、有效、天然、方便」四件事——讀者記不住，也不知道你到底在主打什麼。
〔來源：copywriting/SKILL.md〕

## 二、廣告文案相關結構準則

### 核心寫作規則
1. **簡單 > 複雜**：用「用」不用「使用」，用「幫助」不用「有助於促進」。
2. **具體 > 空泛**：避免「優化」「創新」「提升效率」這類可以套在任何產品上的詞。
3. **主動 > 被動**：「我們每天出貨」不要寫成「貨物由本公司每日出貨」。
4. **肯定 > 保留**：拿掉「幾乎」「非常」「應該」這類削弱語氣的詞，除非是法規要求的保留用語。
5. **展示 > 敘述**：與其寫「效果很好」，不如具體描述使用後的畫面或數字。
6. **誠實 > 聳動**：捏造的數據或見證會侵蝕信任，也是法律風險——保健品另外還會踩《食安法》
   功效宣稱紅線（紅線詞掃描屬既有法務掃描機制，不在本檔範圍）。
〔來源：copywriting/SKILL.md〕

### 下筆前快速自檢
- 有沒有外行人看不懂的行話？
- 有沒有一句話想講太多件事？
- 有沒有被動語態？
- 有沒有驚嘆號？（拿掉）
- 有沒有沒有實質內容的行銷 buzzword？
〔來源：copywriting/SKILL.md〕

### CTA（行動呼籲）準則
弱 CTA（避免）：送出、註冊、了解更多、點此、開始使用——這些詞沒有告訴顧客會得到什麼。

強 CTA 公式：**動詞 + 顧客會得到的東西 + 必要時加限定詞**
- 「立即試喝一瓶」
- 「看懂我的檢驗報告」
- 「算算看我的方案」
〔來源：copywriting/SKILL.md〕

### 與廣告 Hook 相關的標題公式（節選）
以下從完整標題公式庫中，挑出對廣告文案 / Hook 開場最實用的幾類，完整版見
`copy-frameworks.md`：

| 類型 | 公式 | 範例（在地化） |
|---|---|---|
| 痛點提問 | 《痛點提問句》 | 「還在為脹氣不敢出門？」 |
| 結果導向 | 達成{渴望結果}不必{付出的代價} | 「不用戒澱粉也能控糖」 |
| 永不再犯 | 再也不用{討厭的事} | 「再也不用囤一堆吃不完的雞精」 |
| 反差對比 | 你以為是{貴／麻煩的做法}？其實{便宜／簡單的做法} | 「你以為要靠意志力？其實靠對的時間點」（衍生改寫，來源僅有 Differentiation-Focused 類別，無逐字公式） |
| 證明導向 | {數字}{人}用{產品}達到{結果} | 「3000 位顧客回購率超過六成」 |

〔來源：copywriting/references/copy-frameworks.md〕

### 段落銜接與語氣（節選）
- 段落間用自然銜接詞（例如「所以」「這也是為什麼」），避免每段都用同一個轉折詞。
- 避免明顯的 AI 腔轉折語，例如「值得注意的是」「在現今的數位時代」「讓我們深入探討」——
  這些會讓文案讀起來像機器寫的，降低信任感。
〔來源：copywriting/references/natural-transitions.md〕

## 三、心理模型精選（15 個，對台灣電商／保健食品有用）

只收對「單則廣告文案 / Hook / 落地頁」直接有用的模型；完整 45+ 模型清單見來源 skill，
其餘（如 Rule of 7、Network Effects、Flywheel Effect 等通路 / 成長策略模型）不適用於
單則文案撰寫，明確不收。

| 模型 | 白話原理 | 什麼時候用 |
|---|---|---|
| 損失厭惡（Loss Aversion） | 「失去」的痛感大約是「獲得」的兩倍，人更怕失去而不是想獲得。 | 想強調「不行動的代價」時，例如「錯過這期價格，下期回原價」。 |
| 錨定效應（Anchoring） | 第一個看到的數字會定住後面所有判斷的基準。 | 想讓折扣或方案顯得划算時，先亮出原價或大包裝單價再亮優惠價。 |
| 社會證明（Social Proof / Bandwagon） | 別人在做、別人買了，會讓人覺得這個選擇比較安全。 | 顧客猶豫「這個牌子可信嗎」時，放實際購買數 / 評價數 / 回購率。 |
| 稀缺與急迫性（Scarcity / Urgency） | 限量、限時會提高感知價值——但只有真實限量才有效，見第四節禁用手法。 | 檔期真的有限時價、真的有限量庫存時才用，不可捏造。 |
| 權威效應（Authority Bias） | 人會傾向相信有專業背書的說法，降低自己判斷的負擔。 | 有真實的營養師 / 藥師 / 檢驗報告背書時，放上來建立信任。 |
| 框架效應（Framing） | 同一個事實，正面說法和負面說法給人的感受完全不同。 | 把「檢測合格率 98%」說成正面成果，而不是暗示「有 2% 不合格」。 |
| 對比效應（Contrast） | 東西看起來貴不貴，取決於跟什麼放在一起比。 | 想凸顯優勢時，把「一般做法」和「用了產品後」並排放，讓差異一眼看到。 |
| 心理帳戶（Mental Accounting） | 同一筆錢，換個說法放進不同「帳戶」，感受就不一樣。 | 把「月費 900 元」拆成「一天 30 元」，讓價格感覺變小。 |
| 後悔規避（Regret Aversion） | 人會避開「事後可能後悔」的選項，即使理性上划算。 | 用保證、鑑賞期、無條件退換來降低顧客怕買錯的心理成本。 |
| 互惠原則（Reciprocity） | 先拿到好處的人，會比較願意回報。 | 提供免費樣品 / 免費檢測 / 實用知識內容後，再提出購買邀請。 |
| 承諾與一致性（Commitment & Consistency） | 人一旦做出小承諾，會傾向讓後續行為跟這個承諾一致。 | 先讓顧客做小動作（填問卷、領試用），再引導到正式購買，一步比一步大。 |
| 身分認同／統一原則（Unity Principle） | 「這說的就是我」「我們是同一群人」會大幅提高共鳴。 | 用台灣在地的身分標籤（如上班族、新手媽媽）讓受眾覺得文案在對自己說話。 |
| 免費效應（Zero-Price Effect） | 「免費」在心理上不只是低價，是完全不同等級的吸引力。 | 想拉高首次體驗轉換率時，用免運 / 免費贈品，比等額折扣更有感。 |
| 選擇困難／希克定律（Paradox of Choice / Hick's Law） | 選項越多，決策時間越長、放棄機率也越高。 | 頁面上的方案 / CTA 太多個時，簡化成一個主推選項，其餘弱化。 |
| 尾數定價（Charm Pricing） | 價格結尾是 9 會讓人感覺比整數便宜很多，即使實際差距很小。 | 電商定價走「划算感」路線時使用（例如 NT$399 而非 NT$400）。 |

〔來源：marketing-psychology/SKILL.md〕

## 四、禁用手法

以下手法違反第一節「誠實 > 聳動」原則，一律不用。這裡只收「手法」層——保健品的功效
宣稱紅線詞（例如「治療」「消除」等《食安法》禁用字）由既有法務掃描機制管，不在本檔
重複列出。

### 假稀缺 / 假限量
明明沒有真的限量，卻寫「僅剩最後 10 件」。稀缺效應只在真實時才成立（見第三節），
捏造的限量一旦被顧客發現（例如同一句話掛了三個月），會直接摧毀信任。
〔來源：marketing-psychology/SKILL.md（Scarcity「Only use when genuine」）〕

### 假倒數計時
頁面上放一個「限時優惠倒數」，但倒數結束後重新整理又重新開始倒數。這是最常見的
「假急迫性」手法，顧客很容易發現並感到被騙。
〔來源：copywriting/SKILL.md（Honest over sensational）〕

### 無法兌現的承諾
寫出產品做不到的效果、時間或保證（例如承諾「7 天見效」但沒有任何依據）。這既是
誠信問題，對保健食品而言也直接踩《食安法》誇大功效的紅線（紅線詞本身由法務掃描管，
這裡強調的是「承諾要對得起產品實際能做到的事」這個手法層原則）。
〔來源：copywriting/SKILL.md（Fabricated statistics or testimonials erode trust and create legal liability）〕

### 捏造數據與見證
編造顧客評價、編造「檢驗數據」、盜用他人使用心得冒充自家顧客。這類手法短期可能拉高
轉換，但一旦被拆穿，對品牌是不可逆的傷害。
〔來源：copywriting/SKILL.md（Honest over sensational）〕

本檔只管廣告／落地頁等對外行銷內容；系統介面文字（按鈕、備註、提示、等待頁、錯誤訊息）
改用 `app/methodology/ui-copy.md` 的專業中性準則，兩者目的與讀者不同，不共用同一套規則。
