# 文案方法論

適用廣告文案、Hook、落地頁。

## 五大原則

1. **清晰 > 聰明**：雙關語和文字遊戲是在賭讀者停下來解謎，他們不會。
2. **利益 > 功能**：每個功能追問「所以呢？」直到接上顧客在意的結果。「每粒含 500mg 益生菌」是功能，「不用再因為脹氣不敢出門」是利益。
3. **具體 > 模糊**：「調整體質」「優化循環」聽起來專業，實際什麼都沒講。換成數字、時間、可驗證的描述。
4. **顧客語言 > 公司語言**：優先引用 `customer-voice.md` 語料庫裡的真實用詞。顧客說「脹氣脹到像懷孕」，比「腹部不適」有共鳴。
5. **一節一論點**：一段只推進一個論點。塞「便宜、有效、天然、方便」四件事，讀者一件都記不住。

## 寫作規則

- 用「用」不用「使用」，用「幫助」不用「有助於促進」。
- 避免可以套在任何產品上的詞：優化、創新、提升效率。
- 主動語態：「我們每天出貨」不寫「貨物由本公司每日出貨」。
- 拿掉「幾乎」「非常」「應該」，除非是法規要求的保留用語。
- 展示而非敘述：不寫「效果很好」，寫使用後的畫面或數字。
- 誠實 > 聳動：捏造數據或見證是法律風險，保健品另踩《食安法》功效宣稱紅線。
- 不用驚嘆號。
- 不用 AI 腔轉折：「值得注意的是」「在現今的數位時代」「讓我們深入探討」。段落間用「所以」「這也是為什麼」這類自然銜接，同一個轉折詞不重複用。

## CTA

弱（不用）：送出、註冊、了解更多、點此、開始使用——沒告訴顧客會得到什麼。

強＝**動詞 ＋ 顧客會得到的東西**：立即試喝一瓶、看懂我的檢驗報告、算算看我的方案。

## Hook 標題公式

| 類型 | 公式 | 在地範例 |
|---|---|---|
| 痛點提問 | 直接問痛點 | 還在為脹氣不敢出門？ |
| 結果導向 | 達成{渴望}不必{代價} | 不用戒澱粉也能控糖 |
| 永不再犯 | 再也不用{討厭的事} | 再也不用囤一堆吃不完的雞精 |
| 反差對比 | 你以為是{貴／麻煩}？其實{便宜／簡單} | 你以為要靠意志力？其實靠對的時間點 |
| 證明導向 | {數字}{人}用{產品}達到{結果} | 3000 位顧客回購率超過六成 |

## 改寫範例

**功能 → 利益**
原句：產品 A-1 每包含 500 億 CFU 專利菌株，有助於維持消化道機能。
改寫：大餐隔天不再卡住。產品 A-1 一天一包，飯後配水。
（「有助於維持消化道機能」是法規套語不是利益；功能要接上顧客在意的結果。）

**模糊 → 具體**
原句：本產品經由嚴格的品質管理流程所製造，能有效提升您的每日保健效率。
改寫：每一批都送第三方檢驗，報告放在商品頁上，你自己看。
（「嚴格」「有效」「提升效率」三個空詞，換成一個可驗證的動作；順便被動改主動。）

**弱 CTA → 強 CTA**
原句：了解更多
改寫：看這批的檢驗報告
（動詞＋顧客會得到的東西。）

改進一律來自重寫，不來自加料——不要為了讓文案變好而補上沒有依據的數字。

## 心理模型（15 個）

| 模型 | 什麼時候用 |
|---|---|
| 損失厭惡 | 強調不行動的代價：「錯過這期價格，下期回原價」 |
| 錨定效應 | 先亮原價或大包裝單價，再亮優惠價 |
| 社會證明 | 顧客猶豫品牌可不可信時，放購買數／評價數／回購率 |
| 稀缺與急迫 | **只在真的限時限量時用**，捏造見禁用手法 |
| 權威效應 | 有真實的營養師／藥師／檢驗報告背書時 |
| 框架效應 | 說「檢測合格率 98%」，不說「有 2% 不合格」 |
| 對比效應 | 把「一般做法」和「用了產品後」並排 |
| 心理帳戶 | 「月費 900 元」拆成「一天 30 元」 |
| 後悔規避 | 用保證、鑑賞期、無條件退換降低怕買錯的成本 |
| 互惠原則 | 先給免費樣品／檢測／知識內容，再提購買 |
| 承諾與一致性 | 先讓顧客填問卷或領試用，再引導正式購買 |
| 身分認同 | 用在地身分標籤（上班族、新手媽媽），讓受眾覺得在對自己說話 |
| 免費效應 | 拉高首購轉換用免運／贈品，比等額折扣有感 |
| 選擇困難 | 方案或 CTA 太多時，簡化成一個主推，其餘弱化 |
| 尾數定價 | 走划算感路線時用 NT$399 而非 NT$400 |

## 禁用手法

違反「誠實 > 聳動」，一律不用。功效宣稱紅線詞由法務掃描另外管，這裡只管手法層。

- **假稀缺／假限量**：沒有真的限量卻寫「僅剩最後 10 件」。同一句掛三個月會被顧客發現。
- **假倒數計時**：重新整理又重新開始倒數。
- **無法兌現的承諾**：承諾產品做不到的效果或時間，例如沒有依據的「7 天見效」。
- **捏造數據與見證**：編造評價、編造檢驗數據、盜用他人心得冒充自家顧客。
