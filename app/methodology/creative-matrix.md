**選類原則**

- 一支影片或一張圖只主打 1 個角度，最多疊 2–3 個，硬塞會失焦。
- 一套素材要橫跨「最前段攔截」到「末端補刀」，不要全擠在同一個漏斗位置。
- **保健食品特別注意**：功能收益講解、專家背書、硬核測評、數據背書最容易過度承諾。沒有可用證據支撐時，改用體驗、情境、口感、流程或外觀描述，並保留給人工審核。

## 2. 真人實拍 DNA

只套用在「人物出鏡」欄標示是／可、且實際選了真人上鏡的素材。純產品去背圖、純色塊字卡、物件特寫不套用。

**一句話原則**：背景景深虛化 ＋ 真實人物 ＋ 真實鏡頭 = 真實拍攝感。AI 圖最常見的破綻是背景太乾淨、太平、太完整——真實照片有鏡頭景深，主體清楚、背景自然柔散。

**分層視覺執行**（每個真人 prompt 都照這張表分層寫）

| 圖層 | 要求 |
|---|---|
| 文字（大標／副標／數字） | 絕對銳利、實填不透明、零模糊、零噪點 |
| 產品 | 清晰對焦，落在景深焦平面上 |
| 人物主體（臉／手／與產品互動處） | 對焦清晰，保留真實皮膚質感與微表情，不磨皮成塑膠 |
| 背景／環境 | 真實鏡頭淺景深、自然散景虛化，前後景分離 |

背景虛化＝光學景深散景，不是整張套高斯模糊。要「對焦在主體、背景柔散」，不要「整片均勻糊掉」。

**人物與場景**：一律寫成**台灣面孔、台灣場景**（台灣辦公室、台灣小家庭餐桌、台灣街景），不用泛亞裔或其他地區描述。兩套調性擇一：暗調陽剛型（提神／運動／機能：紅色方向性邊光、汗珠反光、85mm 觀感）；暖調生活型（保健／食品／上班族：暖調柔光、50mm 觀感、左右分割構圖）。

**正／反範例**

- ✅「背景是化開的散景燈點，產品與臉部清晰對焦，紅色邊光，汗珠真實反光。」
- ❌「背景是健身房，所有東西都清楚銳利。」（全平、很假）
- ✅「大標與『150mg』數字實填銳利、零噪點；背景自然柔散。」
- ❌「整張圖無任何模糊。」（背景變死板假感）

## 3. 產圖硬規則（所有圖片 prompt）

1. **圖上文字用「」寫死**：大標、副標、規格行的實際文字寫死在引號內，不留給生成模型自由發揮。
2. **數字獨立成行**：「30 瓶」「NT$2,700」「滿千免運」各一行，不要寫成一長串。這是降低數字出錯率的關鍵動作；含價格／數量的組別先跑第一組確認數字正確再批量產出。
3. **產品外觀以參照圖為準**：有參照圖時 prompt 不重述瓶身顏色、包裝花色，只描述構圖與情境，避免文字與參照圖打架。數量（「三盒」）屬構圖資訊可以保留。
4. 每組 prompt 收尾固定放「視覺執行」（依第 2 節分層寫法）與「禁止出現」（只列法規／審核紅線，不列保守限制）。

## 4. Hook 切法

每次產出影片至少給 10 組 Hook，**至少橫跨 5 種以上切法**，不可 10 組全是同一種切法的換句話說。Hook 要對應第 1 節挑選的角度與心理槓桿（選了「精準勸退」角度，就用「精準勸退」或「身分點名」切法，不要文不對題）。圖片產出同樣適用，用在大標與副標的措辭。

| 切法 | 說明 | 範例 |
|---|---|---|
| 痛點具象化 | 把痛點畫面化，讓人一秒對號入座 | 你不是不養生，你只是怕那個腥味。 |
| 反直覺宣稱 | 用違反預期的說法打破既定印象 | 這瓶雞精，第一口比較像雞湯。 |
| 身分點名 | 直接點名族群，製造「這在講我」 | 買過雞精但喝不完的人，這支看完。 |
| 精準勸退 | 表面勸退，實則篩選受眾 | 如果你很愛傳統雞精味，這瓶可能太順口。 |
| 對比夾擊 | 兩種狀態並排對照 | 硬吞雞精，還是喝一瓶像雞湯的？ |
| 價值反轉 | 把日常保養重新框架成不費力的事 | 日常保養，不一定要像在挑戰味覺。 |
| 懸念倒數 | 先埋謎團吊住注意力 | 我不告訴他這是雞精，看他猜不猜得出來。 |
| 自黑打臉 | 先講常見質疑，再自己回應 | 雞精不都很腥嗎？這句話，我們自己也想改掉。 |
| 場景闖入 | 第一人稱畫面直接切進生活情境 | 我下午想喝熱的，但不想再喝咖啡。 |
| 數字衝擊 | 用具體數字當視覺／台詞焦點 | 大字「NT$100」＋「怕踩雷，先從一瓶試喝就好。」 |
| 聲音前置 | 聲音先於畫面出現，製造反差 | 黑畫面只有開瓶聲＋倒湯聲，3 秒後才出畫面。 |
