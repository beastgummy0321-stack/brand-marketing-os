# 創意矩陣

這份文件回答三個問題：**廣告素材有哪些創意角度可選？各自適用什麼情境、靠哪個心理槓桿、
需不需要人物出鏡？** 以及選完角度之後，**圖片質感、圖上文字、Hook 切法**各自要守哪些硬規則。

## 萃取說明：SKILL.md 斷尾實際缺什麼、有沒有補全

`meta-ad-producer-tw.skill` 的 `SKILL.md` 讀到「圖片輸出規則」一節，寫到「每組 prompt
結尾的視覺執行一律改用分層寫法，不要再寫『全圖無模糊』」這句話中途被截斷（文字檔尾端
只剩「文字（大標/副標/數字）：絕對銳」半句）。實際核對後，這個分層寫法的完整規則——
文字/產品/人物/背景各自要多銳利、多虛化——完整寫在 `references/photoreal-real-shot-dna.md`
的「分層視覺執行」表格裡，且 SKILL.md 在被截斷之前，已經把「圖上文字寫死在『』」「數字
獨立成行」「產品外觀交參照圖」等規則講完了。結論：**斷尾只切掉一段即將重複的收尾語，
規則本身沒有缺口**，四份 references 檔案完整補全。

另外核對「9大創意類別 30創意角度.txt」（簡體）與 `creative-types.md`：後者本身就是前者
的繁體在地化＋豐富版（9 大類、30 子類，分類與順序逐條對得上），另外補了 5 個 Meta 投放
特化子類（31–35），兩份來源在**分類與角度實質上沒有衝突**。本檔在此基礎上做的在地化
清洗，只換掉殘留的中國大陸限定用語與語境（例如「打工人」「寶媽」「小姐姐」「拼多多」
「新疆長絨棉」），換成台灣對應說法或改用台灣品牌情境舉例，角度定義與心理機制不變。

### 選類原則
- 一支影片或一張圖通常只主打 1 個角度，硬塞多個會失焦，最多疊 2–3 個。
- 一套素材要橫跨「最前段攔截」到「末端補刀」，不要全擠在同一個漏斗位置。
- 高敏感品類（保健食品）：「功能收益講解」「專家背書」「硬核測評」「數據背書」最容易
  過度承諾；若沒有可用證據支撐，改用體驗、情境、口感、流程或外觀描述，並保留給人工審核。
〔來源：SKILL.md／references/creative-types.md〕

## 二、真人實拍 DNA（獨立規則，只在人物出鏡的切角套用）

**適用範圍**：只套用在「人物出鏡」欄標示是／可，且實際選擇真人上鏡的素材。純產品去背圖、
純色塊字卡、ASMR 物件特寫等本來就不該有人或環境景深的圖，**不套用**。

**一句話原則**：背景景深虛化 + 真實人物 + 真實鏡頭 = 真實拍攝感。AI 圖最常見的破綻是
「背景太乾淨、太平、太完整」——真實照片有鏡頭景深，主體清楚、背景自然柔散。
〔來源：references/photoreal-real-shot-dna.md〕

### 分層視覺執行（每個真人 prompt 都要照這張表分層寫）

| 圖層 | 要求 |
|---|---|
| 文字（大標/副標/數字） | 絕對銳利、實填不透明、零模糊、零噪點 |
| 產品 | 清晰對焦、落在景深焦平面上 |
| 人物主體（臉/手/與產品互動處） | 對焦清晰，保留真實皮膚質感與微表情，不磨皮成塑膠 |
| 背景／環境 | 真實鏡頭淺景深、自然散景虛化，前後景分離 |

⚠️ 背景虛化＝光學景深散景（bokeh），不是整張套高斯模糊濾鏡；要「對焦在主體、背景柔散」，
不要「整片均勻糊掉」，否則背景會變死板、整張變很假。
〔來源：references/photoreal-real-shot-dna.md〕

### 人物與場景寫死規則（台灣在地化）
- 人物一律寫成**台灣面孔、台灣場景**（例如台灣辦公室、台灣小家庭餐桌、台灣街景），
  不使用泛亞裔或其他地區臉孔／場景描述。
- 提供兩套調性模板可選（依產品挑一套）：
  - **暗調陽剛型**（提神／運動／機能）：紅色方向性邊光、汗珠反光、85mm 人像鏡觀感。
  - **暖調生活型**（保健／食品／上班族）：暖調柔光、50mm 人像鏡觀感、左右分割構圖。
〔來源：references/photoreal-real-shot-dna.md〕

### 正／反範例對照
- ✅ 好：「背景是化開的散景燈點，產品與臉部清晰對焦，紅色邊光，汗珠真實反光。」
- ❌ 壞：「背景是健身房，所有東西都清楚銳利。」（→ 全平、很假）
- ✅ 好：「大標與『150mg』數字實填銳利、零噪點；背景自然柔散。」
- ❌ 壞：「整張圖無任何模糊。」（→ 背景變死板假感）
〔來源：references/photoreal-real-shot-dna.md〕

## 三、產圖硬規則（所有圖片 prompt 都要守，不限真人實拍）

1. **圖上文字用「」寫死**：大標、副標、規格行的實際文字內容，一律寫死在「」引號內，
   不留給生成模型自由發揮，避免圖上文字亂寫或誤植。
2. **數字獨立成行**：價格、數量、規格等數字資訊各自獨立成一行（例如「30 瓶」「NT$2,700」
   「滿千免運」各一行），不要寫成一長串（如「30 瓶只要 NT$2,700 滿千免運」）——這是降低
   生成模型數字出錯率的關鍵動作，含價格/數量的組別要先跑第一組確認數字正確再批量產出。
3. **產品外觀以參照圖為準，prompt 不重畫**：有參照圖時，prompt 不重述瓶身顏色、包裝花色
   等外觀細節，只描述構圖與情境，避免文字描述與參照圖打架、生成出不一致的外觀。數量
   （例如「三盒」）屬構圖資訊可以保留，但瓶身長相一律交給參照圖。
4. 每組 prompt 收尾固定放「視覺執行」（依第二節分層寫法）與「禁止出現」（只列法規／
   審核紅線，不列保守限制）。
〔來源：SKILL.md／references/production-examples-chicken-essence.md〕

## 四、Hook 切法規則（至少橫跨多種切法，禁止同義改寫充數）

每次產出影片，至少給 10 組 Hook，且必須橫跨不同切法，不能 10 句只是同一種切法的
同義改寫。以下切法清單（至少混用其中數種）：

| 切法 | 說明 | 範例 |
|---|---|---|
| 痛點具象化 | 把痛點畫面化，讓人一秒對號入座 | 「你不是不養生，你只是怕那個腥味。」 |
| 反直覺宣稱 | 用違反預期的說法打破既定印象 | 「這瓶雞精，第一口比較像雞湯。」 |
| 身分點名 | 直接點名特定族群，製造「這在講我」的感覺 | 「買過雞精但喝不完的人，這支看完。」 |
| 精準勸退 | 表面勸退，實則篩選受眾（呼應第一節角度 18） | 「如果你很愛傳統雞精味，這瓶可能太順口。」 |
| 對比夾擊 | 兩種狀態並排對照，凸顯差異 | 「硬吞雞精，還是喝一瓶像雞湯的？」 |
| 價值反轉 | 把日常保養重新框架成不費力的事 | 「日常保養，不一定要像在挑戰味覺。」 |
| 懸念倒數 | 先埋一個謎團，吊住注意力 | 「我不告訴他這是雞精，看他猜不猜得出來。」 |
| 自黑打臉 | 先講出常見質疑，再自己回應打臉 | 「雞精不都很腥嗎？這句話，我們自己也想改掉。」 |
| 場景闖入 | 用第一人稱畫面直接切進生活情境 | 「我下午想喝熱的，但不想再喝咖啡。」 |
| 數字衝擊 | 用具體數字當視覺／台詞焦點 | 畫面大字「NT$100」搭配「怕踩雷，先從一瓶試喝就好。」 |
| 聲音前置強化 | 用聲音先於畫面出現，製造反差 | 黑畫面只有開瓶聲＋倒湯聲，3 秒後才出畫面。 |

〔來源：SKILL.md／references/production-examples-chicken-essence.md〕

### 使用規則
- 至少橫跨 5 種以上切法，不可 10 組 Hook 全部落在同一種切法的換句話說。
- Hook 要能對應到本檔第一節挑選的創意角度與心理槓桿（例如選了「精準勸退」角度，
  對應的 Hook 切法就用「精準勸退」或「身分點名」，不要文不對題）。
- 影片以外的產出（圖片）也適用同一套切法邏輯，用在圖上大標與副標的措辭上。
〔來源：SKILL.md〕
