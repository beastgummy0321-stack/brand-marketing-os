**選類原則**
- 一支影片或一張圖只主打 1 個角度，最多疊 2–3 個，硬塞會失焦。
- 一套素材要橫跨「最前段攔截」到「末端補刀」，不要全擠在同一個漏斗位置。
- **受法規管制的品類特別注意**：功能收益講解、專家背書、硬核測評、數據背書最容易過度承諾。沒有可用證據支撐時，改用體驗、情境、口感、流程或外觀描述，並保留給人工審核。
## 2. 真人實拍 DNA
只套用在「人物出鏡」欄標示是／可、且實際選了真人上鏡的素材。純產品去背圖、純色塊字卡、物件特寫不套用。
**一句話原則**：背景景深虛化 ＋ 真實人物 ＋ 真實鏡頭 = 真實拍攝感。AI 圖最常見的破綻是背景太乾淨、太平、太完整——真實照片有鏡頭景深，主體清楚、背景自然柔散。
**分層視覺執行**（每個真人 prompt 都照這張表分層寫）
| 圖層 | 要求 |
|---|---|
| 文字（大標／副標／數字） | 絕對銳利、實填不透明、零模糊、零噪點 |
| 產品 | 清晰對焦，落在景深焦平面上 |
| 人物主體（臉／手／與產品互動處） | 對焦清晰，保留真實皮膚質感與微表情，不磨皮成塑膠 |
| 背景／環境 | 真實鏡頭淺景深、自然散景虛化，前後景分離 |
背景虛化＝光學景深散景，不是整張套高斯模糊。要「對焦在主體、背景柔散」，不要「整片均勻糊掉」。
**人物與場景**：依品牌市場參數決定在地面孔與場景（例如市場＝台灣時，寫成台灣辦公室、台灣小家庭餐桌、台灣街景等具體在地場景）。**目前只有台灣市場建置了在地描述；其他市場尚未建置，不要自行推測當地面孔或場景**，先用中性描述或請人工補。兩套調性擇一：**暗調強對比型**（紅色方向性邊光、汗珠或水氣反光、85mm 觀感，適合訴求強度感、專注感的產品或服務）；**暖調生活型**（暖調柔光、50mm 觀感、左右分割構圖，適合訴求日常感、陪伴感的產品或服務）。
**正／反範例**
- ✅「背景是化開的散景燈點，產品與臉部清晰對焦，紅色邊光，汗珠真實反光。」
- ❌「背景是健身房，所有東西都清楚銳利。」（全平、很假）
- ✅「大標與『150mg』數字實填銳利、零噪點；背景自然柔散。」
- ❌「整張圖無任何模糊。」（背景變死板假感）
## 3. 產圖硬規則（所有圖片 prompt）
1. **圖上文字用「」寫死**：大標、副標、規格行的實際文字寫死在引號內，不留給生成模型自由發揮。
2. **數字獨立成行**：「30 份」「{幣別}2,700」「滿額折扣」各一行，不要寫成一長串。這是降低數字出錯率的關鍵動作；含價格／數量的組別先跑第一組確認數字正確再批量產出。
3. **產品外觀以參照圖為準**：有參照圖時 prompt 不重述瓶身顏色、包裝花色，只描述構圖與情境，避免文字與參照圖打架。數量（「三盒」）屬構圖資訊可以保留。
4. 每組 prompt 收尾固定放「視覺執行」（依第 2 節分層寫法）與「禁止出現」（只列法規／審核紅線，不列保守限制）。
## 4. Hook 切法
每次產出影片至少給 10 組 Hook，**至少橫跨 5 種以上切法**，不可 10 組全是同一種切法的換句話說。Hook 判準＝吸睛強度＋兌現。Hook 不必對應切角或受眾、可誇張可戲劇化；但腳本必須在片內兌現 Hook 承諾的張力，兌現不了的腳本×Hook 組合不得配對。圖片產出同樣適用，用在大標與副標的措辭。
**以下是句型骨架，不是逐字範例**——大括號是插槽，實際填詞由品類、品牌與語料庫決定。
| 切法 | 句型骨架 |
|---|---|
| 痛點具象化 | 你不是不{被誤解的行為}，你只是{真正的阻礙}。 |
| 反直覺宣稱 | 這個{產品／服務}，{某個體驗面向}比較像{意外的參照物}。 |
| 身分點名 | {做過某件事}但{沒達成的結果}的人，這支看完。 |
| 精準勸退 | 如果你很{習慣某種舊做法}，這個可能{反差點}。 |
| 對比夾擊 | 硬{吃苦做法}，還是{輕鬆做法}？ |
| 價值反轉 | {某個日常行為}，不一定要像在{受苦的比喻}。 |
| 懸念倒數 | 我不告訴{對象}這是{產品}，看他猜不猜得出來。 |
| 自黑打臉 | {品類}不都很{刻板缺點}嗎？這句話，我們自己也想改掉。 |
| 場景闖入 | 我{某個時刻}想要{渴望}，但不想再{舊方案}。 |
| 數字衝擊 | 大字「{數字}」＋「{一句降低門檻的話}。」 |
| 聲音前置 | 黑畫面只有{代表性音效}，{秒數} 秒後才出畫面。 |
| 預期違背 | 開場先放{不對勁的畫面或設定}，看到後面才知道{脈絡}。 |
| 好奇缺口 | {丟出一個資訊洞}，看完才補得上。 |
| 放大焦慮 | 再不{行動}，{負面後果}只會更糟。（恐嚇式與人身屬性是 Meta 紅線，健康品類慎用） |
| 利益前置 | {結果}直接甩出來，不鋪陳。 |
| 警告避坑 | 別{做某件事}，不然{代價}。 |
| 內幕揭秘 | {行業}不想讓你知道的{事}。 |
## 5. 影片腳本框架
一支腳本先選一套框架，再依該框架的段落產出。**十支片都用同一套結構，換再多角度也會像同一支。**
段落標籤只能從所選框架的段落名挑，不可自創。時間軸以 30 秒為基準，依實際長度等比縮放。
**主力五套**
| 框架 | 段落（依序，30 秒基準） | 什麼時候用 |
|---|---|---|
| PAS | 痛點 0–5s → 加壓 5–18s → 解方 18–25s → 行動 25–30s | 冷流量最泛用 |
| AIDA | 攔截 0–5s → 勾住 5–18s → 渴望 18–35s → 行動 35–45s | 30–60 秒、需要教育的產品 |
| BAB | 之前 0–8s → 之後 8–20s → 橋接 20–27s → 行動 27–30s | 前後對比明顯時 |
| UGC 見證流 | 個人開場 0–4s → 情境 4–12s → 發現產品 12–22s → 結果佐證 22–27s → 推薦 27–30s | 真人口播，21–45 秒 |
| 產品實演 | 亮點開場 0–5s → 操作走一遍 5–18s → 差異化 18–24s → 社會證明＋行動 24–30s | 再行銷 |
**進階七套**
| 框架 | 段落（依序） | 什麼時候用 |
|---|---|---|
| PPPP | 描繪 → 承諾 → 證明 → 推一把 | 靠證言與數據撐的片 |
| AIDCA | 攔截 → 勾住 → 渴望 → 破疑 → 行動 | 高單價、受眾多疑 |
| FAB | 規格 → 優勢 → 好處 | 已經在比規格的受眾 |
| Hook-Story-Offer | 破格開場 → 故事 → 提案 | 暖流量、身分認同型 |
| PASTOR | 對象 → 放大 → 故事 → 轉變 → 提案 → 回應 | 敘事驅動，壓到 40 秒可用 |
| 預期反轉 | 誤導開場 0–5s → 加深預期 5–12s → 反轉點 12–18s → 產品兌現 18–25s → 行動 25–30s | 反轉型三選一：誤導式／補償式／極致式；受眾對品類廣告麻木、需要破防時 |
| 帶貨五段式 | 鉤子 0–3s → 展示 3–8s → 賣點 8–15s → 信任 15–20s → 轉化 20–30s | 冷流量轉單（與「產品實演」分工：實演給再行銷） |
**腳本輸出規則**
1. Hook 段一律留插槽，不寫死——Hook 是共用池，10 個任選其一套進來（見第 4 節）。
2. 每段兩行：`<段落標籤>：<口播台詞>` 與 `畫面：<一句話畫面說明>`。不寫運鏡、不寫轉場。
3. 同一批腳本至少橫跨 2 種框架，不可全部同一套。
4. 30 秒以上腳本中段至少埋一個小鉤子（反轉／懸念／彩蛋）。
5. 每 5–10 秒一個新資訊點或情緒點；單一資訊點 2–3 秒內台詞＋畫面同步講完。
6. 三問檢查：開頭答「為什麼要看」、中段答「為什麼要看完」、結尾答「為什麼要行動」。
7. 一支影片只講透一個核心賣點（賣點前置）；CTA 放在興趣最高點不硬等片尾；價格與優惠必上醒目字幕。
