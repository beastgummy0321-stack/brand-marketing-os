# 圖片提示詞模板

素材工作檯圖片提示詞任務用的模板：八個可替換模組 → 九行輸出格式 → 固定段與變動段怎麼
切 → 字數與內容規則。這裡定的是一則提示詞長什麼樣子，不是視覺調性（`creative-matrix.md`
第 2 節）或產圖硬規則（同檔第 3 節）——三份一起讀。

## 1. 八個可替換模組

| 模組 | 可替換內容 |
|---|---|
| ① Theme | 場景＋核心賣點 |
| ② Format | 比例＋媒介用途 |
| ③ Capture Style | UGC／棚拍／電影／紀實（工單的「風格」欄決定，預設 UGC） |
| ④ Environment | 任何具體空間 |
| ⑤ Human | 人物設定＋動作 |
| ⑥ Hero Object | 商品／車／人物／食物 |
| ⑦ Spatial Composition | 主體之間的位置關係 |
| ⑧ Authenticity Control | 真實感＋反棚拍限制 |

## 2. 輸出格式（逐行，共 9 行，一模組一行，原樣照抄，不合併、不省略、不加項）

<編號>｜<場景／主題> × 「<圖上文字，逐字取自標題>」
<圖片比例>｜<用途>
攝影形式：<風格＋光線＋主色輔色，一句>
場景：<地點、時間、背景，一句>
人物：<類型、動作、露臉與否，一句>
主體：見參考商品照，<位置、佔比、鏡位、留白，一句>
關係：<主體與人物／背景的前後、方向，一句>
真實感：<兩三個不完美細節>
保留：<Logo、商品外型、圖上文字>｜禁止：<AI 感、卡通感、人體錯誤、Logo 變形等>

範例（216 字）：

```
1｜辦公桌開工 × 「看起來像軟糖，規格卻不是零食」
4:5｜Meta 動態消息
攝影形式：UGC 手機實拍，紅色方向性邊光、暗調高對比、黑主紅輔
場景：深色台灣辦公桌，筆電與文件柔散
人物：台灣年輕成人手部拿取商品，不露臉
主體：見參考商品照，桌面中央占六成，低機位特寫，左上留白
關係：商品前景清晰，手從右側伸入，背景退後
真實感：紙張微歪、指紋使用痕跡、不過度整齊
保留：Logo、商品外型、「看起來像軟糖，規格卻不是零食」｜禁止：AI 感、卡通感、人體錯誤、Logo 變形
```

## 3. 固定段／變動段（`CONTEXT.md` 廣告素材）

**固定段**——一張工單只寫一次，這張工單底下每一則都逐字相同：比例｜用途、攝影形式、人物、
保留｜禁止（第 2、3、5、9 行）。

**變動段**——每一則各自不同：編號｜場景 ×「圖上文字」、場景、主體、關係、真實感（第 1、4、
6、7、8 行）。圖上文字每則可換一個標題，但只能從工單附上的標題原文裡挑。

外殼負責把固定段與變動段組成上面的 9 行，模型只回結構化欄位，不回組好的字串。

## 4. 風格（Capture Style）

風格是工作檯的一份資料清單，一種風格一筆（名稱、攝影形式那一行的寫法、真實感的提示），加
一種風格＝加一筆，不改程式。這次只有預設的 **UGC 手機實拍**：手機視角、自然光或現場光、
生活雜物與不完美構圖是特色，不是缺點。視覺調性（`visual_tone`：暗調強對比／暖調生活）管
光線與色彩，風格管拍法與真實感——兩者併寫在「攝影形式」那一行。

## 5. 規則

- 每則組好的九行提示詞 200～250 字（不含換行符號，標點算在內）。
- 全程繁體中文。
- 圖上文字一律用「」包住，逐字取自工單附上的標題原文，不得自己發明（`creative-matrix.md`
  §3.1）。
- 主體不重述商品外觀，一律以「見參考商品照，」起頭（`creative-matrix.md` §3.3）。
- 提示詞的則數＝工單指定的條數，不在這份檔或任何回覆裡寫死一個數字。
