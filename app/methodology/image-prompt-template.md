# 圖片提示詞模板

外殼組出每一則提示詞，模型只回欄位。模式看工單來源：檔期派工的工單走變體模式（先 ① 再 ②），手動開的工單走探索模式（先 ③ 再 ②）；沒有內容的行整行不出現。

## 1. 模型看得到什麼（工作單，不會貼進提示詞）

`prompts.brief_text` 寫第一組；F01-T03-I02 加最後三行。

### 變體模式

- `產品：`
- `這個節點的座標…`（受眾、痛點、切角、標題公式從這裡讀）
- `風格：<label>；<style_block>`
- `模式：變體模式`
- `可用字句（逐字，不得改）：…`（可能沒有這一行）
- `可用的大標（可用可不用）：「…」`（可能沒有這一行）
- 然後是品牌上下文

### 探索模式

- `產品：`
- `風格：<label>；<style_block>`
- `自由指示：…`（可能沒有這一行）
- `模式：探索模式；角度數：<N>`
- `可用字句（逐字，不得改）：…`（可能沒有這一行）
- `可用的大標（可用可不用）：「…」`（可能沒有這一行）
- 然後是品牌上下文

探索模式沒有座標這一行。

## 2. ① 主圖提示詞（變體模式）

```
【風格】<style_block>
【商品】<商品句>
【受眾】<受眾>；痛點：<痛點>
【這則的訴求】切角：<切角>——<切角說明>；標題公式：<標題公式>——<標題公式說明>
【可用字句（逐字，不得改）】<可用字句，以／相連>
【畫面】<scene>／<person>／<subject_position>
【圖上文字】大標：「<headline>」；副標：「<subhead>」；文字純色填滿，數字獨立成行
【輸出】<格式>（<格式說明>），一張
```

| 行 | 誰填 | 內容 |
|---|---|---|
| 【風格】 | 外殼 | 工單風格那筆的 `style_block` 原文，前面不加 label |
| 【商品】 | 外殼 | 工單有商品、且那個商品有 `product_photo` 素材 → 「見參考商品照：<商品名>。不重述外觀。」；其他情況 → 「無參考商品照，畫面以情境與人物為主，不畫商品特寫。」 |
| 【受眾】 | 外殼 | 節點座標的受眾與痛點；兩個都沒有就整行不出現 |
| 【這則的訴求】 | 外殼 | 節點座標的切角與標題公式，說明取自座標詞彙表；沒有說明只寫名稱 |
| 【可用字句（逐字，不得改）】 | 外殼 | 檔期促銷說明的非空行；沒有就整行不出現 |
| 【畫面】 | 模型 | `hero.scene`／`hero.person`／`hero.subject_position` |
| 【圖上文字】 | 模型 | `hero.headline`、`hero.subhead`；`subhead` 是 null 時「；副標：「…」」整段不出現 |
| 【輸出】 | 外殼 | 節點的格式座標與說明；沒有格式座標時是「【輸出】一張」 |

（骨架裡 `<headline>`／`<subhead>` 的「」是外殼寫的；規則區塊第 4 條是模型不自己加的原因。）

## 3. ② 變體提示詞（兩種模式共用，不呼叫模型）

```
以附上的這張圖為基底，分別生成 <N> 個完全不同風格排版與人物的圖片，主要訴求保持不變。一次一張。
不變：訴求「<訴求句>」、可用字句「<可用字句，以／相連>」（數字逐字）、商品外型與 Logo、<輸出句>。
可變：場景、人物、構圖、文字排版位置、配色。
【風格】<style_block>
```

- `<N>`：使用者輸入的張數。
- `<訴求句>`：變體模式時是節點的切角名稱；探索模式、或沒有切角時，寫「以這張圖原本的主訴求為準」。
- 沒有可用字句時，可用字句那個子句整段不出現。
- `<輸出句>`：變體模式時是提示詞①【輸出】的內容；探索模式時是空的，那個子句整段不出現。

## 4. ③ 探索提示詞（探索模式）

```
【風格】<style_block>
【商品】<商品句>
【目的與對象】<目的與對象>
【可用字句（逐字，不得改）】<可用字句，以／相連>
【任務】分別給我 <N> 張圖，每張一個不同的說服切角，排版與風格彼此差異要大：
1. <name>｜<brief>｜圖上文字：「<on_image_line>」
<N>. <name>｜<brief>｜圖上文字：「<on_image_line>」
【圖上文字】每張圖只出現它自己那一行字；文字純色填滿，數字獨立成行
```

| 行 | 誰填 | 內容 |
|---|---|---|
| 【風格】、【商品】 | 外殼 | 同①的填法 |
| 【目的與對象】 | 外殼 | 工單的自由指示；沒有就寫「未指定」 |
| 【可用字句（逐字，不得改）】 | 外殼 | 同①的填法 |
| 【任務】 | 外殼 | `<N>` |
| 編號那幾行 | 模型 | `angles[i].name`（`creative-matrix.md` §1 的切角之一）、`angles[i].brief`、`angles[i].on_image_line` |
| 【圖上文字】 | 外殼 | 固定句 |

③ 沒有【輸出】這一行，因為手動開的工單沒有格式座標。

## 5. 圖上文字與數字

1. 工作單上的「可用的大標（可用可不用）」只是參考：可以沿用、改寫或不用；沒有這一行時，回覆照樣完整。
2. 大標、副標與每張圖的圖上文字，都是為這張圖新寫的文案；可用字句不是用字清單，不限制怎麼寫。唯一的限制是第 3 條。
3. 圖上的數字與事實（價格、折扣、規格、認證）必須逐字出現在可用字句或品牌上下文裡，兩處都找不到的數字不上圖；工作單沒有可用字句這一行時，品牌上下文裡逐字出現的數字照樣可用。
4. 回傳的大標、副標與圖上文字不加「」，外殼組提示詞時會加上。

## 6. 風格

一個風格是 `app/workbench/image_styles.json` 裡的一筆（`key`、`label`、`style_block`）；加一種風格＝加一筆。【風格】就是 `style_block` 本身，不加別的東西。畫面裡的人物來自受眾（變體模式）或來自目的與對象加品牌上下文（探索模式），不會來自風格。

## 7. 其他規則

- 全程繁體中文。
- 張數是使用者輸入的 `<N>`，這份檔與任何回覆都不寫死一個數字。
- 提示詞只寫該包含什麼，不帶禁止句。
