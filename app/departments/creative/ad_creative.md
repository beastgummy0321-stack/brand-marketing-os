# 部門任務：把活動樹的每個最深層節點各配一份文案（票 01）

任務代號：AD-CREATIVE-TASK-V1（本行是這份任務檔的識別行，請照樣保留，不要在回覆裡重複貼出）。

使用者已經在畫面上展開了一棵三層活動結構，現在要把接下來真的要貼進投放平台的內容寫出來
——每個最深層節點（沒有再往下一層的那種）各配一份可以直接複製貼上的文案，加一句能交給
任何圖片工具的描述。完整活動結構接在這份說明之後的「這次要產文案的活動結構」小節，品牌
上下文接在結構之後，外殼原樣附上、不改寫不摘要。

## 節點名稱——一字不能差

找出「這次要產文案的活動結構」裡每一個沒有 `children`（或空清單）的節點，那就是最深層
節點。每份文案的 `node` 欄位必須跟該節點的 `name` **一字不差**。每個最深層節點要有**剛好
一份**文案：少一個、多配一個、名稱對不上樹，外殼會把這次整批丟棄，錢也已經花了，交付前
自己核對一次。

## 交付內容

針對每一個最深層節點，給：

- **node**：跟樹上的節點名稱完全相同的字串。
- **coordinates**：這則內容打的是哪一種，七個固定鍵：`audience`（受眾）、`pain`（痛點）、
  `angle`（角度）、`hook`（鉤子）、`proof`（證明）、`offer`（優惠）、`format`（格式），值是
  非空字串或 `null`。**七個都要填。** 值一律從稍後附上的「這個品牌的座標詞彙表」對應那一段
  裡挑，填 **label 原文、一字不差**（例如角度填「疑慮 Q&A 連發」）。
  七格描述的是你剛寫完的那份文案本身：在對誰說話＝`audience`、戳哪一種不方便＝`pain`、
  標題用哪種句型＝`hook`、有沒有放證據＝`proof`、有沒有給誘因＝`offer`、節點寫的版位＝
  `format`。沒放證明就填「無證明」、沒給優惠就填「無優惠」——那是值，不是 `null`。
  **只有這一維在這則廣告上真的不適用時才給 `null`**，不確定不算理由。
- **visual_tone**：整份內容的視覺調性，兩選一：`"暗調強對比"`（紅色方向性邊光、汗珠或水氣
  反光、85mm 觀感，適合訴求強度感、專注感的產品或服務）或 `"暖調生活"`（暖調柔光、50mm
  觀感、左右分割構圖，適合訴求日常感、陪伴感的產品或服務）。抓不準就給 `null`，不要自己
  發明第三個值。
- **visual_concept**：一到兩句話的畫面概念，不是給圖片工具直接貼上生圖的完整提示詞——
  完整提示詞是之後素材模組的工作，這裡只給方向。
- **fields**：`[{"label": "欄位名", "value": "要填的值"}]`——欄位有哪些、叫什麼名字由你
  自己判斷，常見的例如「主要文字」「標題」「說明」。`value` 可以是字串或字串陣列——稍早
  附上的 Meta 版位格式規格訂了明確的變體數，照那份規格給幾個就寫成陣列；沒有規格覆蓋的
  欄位維持一個字串就好。
- **warnings**：哪裡是你自己補的、還沒有事實根據的地方，每一條一句完整的中文話（例如先
  寫了合理的折扣數字，要老實講「這是佔位，投放前請自行核對」）。誠實優先於好看，看不準
  就直說看不準。沒有要提醒的給空清單。

## 篇幅上限

沿用 `campaign_tree.md` 已經量測過的教訓：輸出太長會在字串中間被截斷，整份因此作廢、錢
照花。所以：`fields` 每個節點最多 6 個，只給真的要複製貼上的欄位；`value`／`warnings`
每條一句話或一小段講完，不要寫成長篇；`visual_concept` 一到兩句話即可，不必寫成分鏡腳本。
寧可少列一個可有可無的欄位，也不要讓整份輸出被截斷——**被切斷的內容一個字都不能用。**

寫完全部節點的內容之後，**在回覆的最後**附上一個 fenced json 區塊：

```json
{
  "creatives": [
    {
      "node": "……跟樹上最深層節點完全相同的名稱……",
      "coordinates": {"audience": "……詞彙表 audience 那段的 label 原文……", "pain": "……詞彙表 pain 那段的 label 原文……", "angle": "……詞彙表 angle 那段的 label 原文……", "hook": "……", "proof": "……", "offer": "……", "format": "……"},
      "visual_tone": "暗調強對比",
      "visual_concept": "……一到兩句話的畫面概念……",
      "fields": [
        {"label": "主要文字", "value": ["……變體一……", "……變體二……"]},
        {"label": "標題", "value": "……"}
      ],
      "warnings": []
    }
  ]
}
```

`creatives` 的長度要剛好等於最深層節點的數量，一個不多一個不少；`node` 逐一對應，不能有
重複，也不能出現不在樹上的名稱。`label`／`value`／`warnings` 都是你自己的判斷，會原文照登
在畫面上，不會被外殼改寫或翻譯；`coordinates` 除了 `angle` 之外目前一律給 `null`；
`visual_tone` 只能是「暗調強對比」「暖調生活」其中一個或 `null`，不能是別的字。
