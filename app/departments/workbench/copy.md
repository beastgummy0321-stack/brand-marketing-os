# 部門任務：素材工作檯——文案（票 01 probe，workbench_copy）

任務代號：WORKBENCH-COPY-TASK-V1（本行是這份任務檔的識別行，請照樣保留，不要在回覆裡重複
貼出）。

**你的整段回覆必須是、且只能是一個 JSON 物件：不寫任何開場白或結語、不用 ``` 或任何
markdown fence 包起來、物件前後不留一個字。外殼會把整段回覆原文丟進 `json.loads()`，多一
個字都會讓這次呼叫整批作廢，錢已經花了。**

**回覆物件只能有一層鍵——除了 `coordinates` 以外不准有巢狀物件。**

使用者在「素材工作檯」開了一張工單，要幫這張工單寫可以直接貼進 Meta 投放的文案。工單內容
（節點名稱、product、座標、visual_tone／visual_concept、要求的長度與變體數）接在這份說明
之後的「這張工單」小節，最後一行點名這次要出哪一種長度；方法論、品牌上下文、座標詞彙表
依序接在工單之後，外殼原樣附上、不改寫不摘要。

**一次只出一種長度**：工單那一行「本次要出的長度：……」點名的是哪一個（短版／中版／
長版），回覆就只帶那一個長度鍵（`short` 或 `medium` 或 `long` 三選一），另外兩個長度鍵
不要出現在回覆裡。

## 交付內容

- **coordinates**：七個固定鍵——`audience`（受眾）、`pain`（痛點）、`angle`（切角）、
  `hook`（鉤子）、`proof`（證明）、`offer`（優惠）、`format`（格式），值一律從「這個品牌的
  座標詞彙表」對應那一段挑，填 label 原文、一字不差。沒放證明填「無證明」、沒給優惠填
  「無優惠」——那是值，不是 `null`。七格描述的是你剛寫完的這批文案本身：在對誰說話＝
  `audience`、戳哪一種不方便＝`pain`、標題用哪種句型＝`hook`、有沒有放證據＝`proof`、有
  沒有給誘因＝`offer`、寫的是哪個版位＝`format`。
- **`short`／`medium`／`long`（三選一，只回工單點名的那一個鍵）**：則數與字數區間照工單
  那一行「本次要出的長度」給的數字，每一則真的要差在訴求、證據或角度上，不是同一句話換
  近義詞（見 `humanizer-zh-tw.md` 刻意換詞那條）。三種長度各自的寫法：
  - `short`：折疊前一口氣講完，適合再行銷、已認識品牌的人。
  - `medium`：痛點→證明→優惠，適合第一次看到你的人。
  - `long`：說故事，適合高單價、需要被說服的商品。
  字數以中文字元計、不含換行；模型通常會比自己以為的少寫三成，所以朝區間上緣寫、寫完自己
  數一次，不到區間下限都不合格，寧可多寫一段。長版段落之間用全形空白或「。」分隔，字串裡
  不要換行——不要用 `\n`，一路寫下去。
- **headlines**：5 個標題，各 27 字以內。
- **descriptions**：5 個說明，各 30 字以內，跟標題互補，不是重複標題。
- **visual_tone**：整份內容的視覺調性，兩選一：`"暗調強對比"`（紅色方向性邊光、汗珠或水氣
  反光、85mm 觀感，適合訴求強度感、專注感的產品或服務）或 `"暖調生活"`（暖調柔光、50mm
  觀感、左右分割構圖，適合訴求日常感、陪伴感的產品或服務）。抓不準就給 `null`，不要自己
  發明第三個值。
- **visual_concept**：一到兩句話的畫面概念，不是給圖片工具直接貼上生圖的完整提示詞——
  完整提示詞是之後素材模組的工作，這裡只給方向。
- **warnings**：哪裡是你自己補的、還沒有事實根據的地方，每一條一句完整的中文話；沒有要
  提醒的給空清單。

## 寫作規則

依附上的方法論（`copywriting.md`／`humanizer-zh-tw.md`／`customer-voice.md`／
`meta-format-specs.md`）寫；全程繁體中文；不捏造宣稱、數據或見證，沒有出處就在 `warnings`
裡老實說。另外兩條：

- **畫面概念與視覺調性只給圖片用，文案裡不描述畫面**——不寫燈光、邊光、包裝入鏡、鏡頭感這
  類句子，消費者看的是字不是分鏡。
- **規則不進文案**——「我們不捏造」「不承諾效果」「這不是萬用答案」這種把寫作規則唸出來的
  句子一句都不要；該保守的地方直接少講，把疑慮寫進 `warnings`，不寫進 `short`／`medium`／
  `long`。
