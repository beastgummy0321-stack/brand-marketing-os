# 部門任務：素材工作檯——圖片提示詞（workbench_image_prompt）

任務代號：WORKBENCH-IMAGE-PROMPT-TASK-V1（本行是這份任務檔的識別行，請照樣保留，不要在
回覆裡重複貼出）。

**你的整段回覆必須是、且只能是一個 JSON 物件：不寫任何開場白或結語、不用 ``` 或任何
markdown fence 包起來、物件前後不留一個字。外殼會把整段回覆原文丟進 `json.loads()`，多一
個字都會讓這次呼叫整批作廢，錢已經花了。**

## 你拿到什麼

### 變體模式

- `產品：`
- `這個節點的座標…`（受眾、痛點、切角、標題公式從這裡讀）
- `風格：<label>；<style_block>`
- `模式：變體模式`
- `可用字句（逐字，不得改）：…`（可能沒有這一行）
- `可用的大標（可用可不用）：「…」`（可能沒有這一行）
- 然後是品牌上下文

### 探索模式

- `產品：`
- `風格：<label>；<style_block>`
- `自由指示：…`（可能沒有這一行）
- `模式：探索模式；角度數：<N>`
- `可用字句（逐字，不得改）：…`（可能沒有這一行）
- `可用的大標（可用可不用）：「…」`（可能沒有這一行）
- 然後是品牌上下文

## 交付內容

變體模式回 `{"hero": {"scene", "person", "subject_position", "headline", "subhead"},
"warnings": []}`：

- `scene`：一句話。
- `person`：照受眾座標寫，是誰、在做什麼、露不露臉。
- `subject_position`：商品或人物的位置、畫面佔比、鏡位、留白；商品外觀照參考商品照，不重述。
- `headline`：這張圖的大標。
- `subhead`：字串或 `null`。

探索模式回 `{"angles": [{"name", "brief", "on_image_line"}], "warnings": []}`，
`angles` 的項數等於角度數：

- `name`：`creative-matrix.md` §1 的一個切角，每一項不同。
- `brief`：一句話講場景與排版，項與項之間排版差很多。
- `on_image_line`：這張圖上唯一的一行字。
- 人物來自自由指示與品牌上下文。

## 圖上文字與數字

1. 工作單上的「可用的大標（可用可不用）」只是參考：可以沿用、改寫或不用；沒有這一行時，回覆照樣完整。
2. 大標、副標與每張圖的圖上文字，都是為這張圖新寫的文案；可用字句不是用字清單，不限制怎麼寫。唯一的限制是第 3 條。
3. 圖上的數字與事實（價格、折扣、規格、認證）必須逐字出現在可用字句或品牌上下文裡，兩處都找不到的數字不上圖；工作單沒有可用字句這一行時，品牌上下文裡逐字出現的數字照樣可用。
4. 回傳的大標、副標與圖上文字不加「」，外殼組提示詞時會加上。

## 回覆——依工單的模式只回下面其中一個物件，物件前後不加任何文字或符號

變體模式時，整段回覆就是這個形狀的物件：

{
  "hero": {
    "scene": "……一句話的場景……",
    "person": "……照受眾座標寫：是誰、在做什麼、露不露臉……",
    "subject_position": "……商品或人物的位置、畫面佔比、鏡位、留白……",
    "headline": "……這張圖的大標……",
    "subhead": "……這張圖的副標……"
  },
  "warnings": []
}

沒有副標時，subhead 填 JSON 的 null。

探索模式時，整段回覆就是這個形狀的物件，angles 的項數等於工單的角度數：

{
  "angles": [
    {"name": "……creative-matrix.md 第一節的一個切角……", "brief": "……一句話的場景與排版……", "on_image_line": "……這張圖上唯一的一行字……"},
    {"name": "……另一個切角……", "brief": "……排版和上一張差很多……", "on_image_line": "……這張圖上唯一的一行字……"}
  ],
  "warnings": []
}
