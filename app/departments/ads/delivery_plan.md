# 部門任務：投放中心——把策略角色展開成投放組與廣告（ads_delivery_plan）

任務代號：ADS-DELIVERY-PLAN-TASK-V1（本行是這份任務檔的識別行，請照樣保留，不要在回覆裡
重複貼出）。

下面會給你這次投放已經採用的角色分配（新客／再行銷／探索，每個角色的預算已經由程式算好，
你不用管金額），以及這個品牌可以用的座標詞彙表（dimension｜key｜label）。你的工作是把每個
角色展開成一個投放組，再幫每個投放組寫出 1～3 支廣告，每支廣告要指定七個座標維度
（audience／pain／angle／hook／proof／offer／format）。【投放期間內的行事曆】是程式列出的
假日、考季與檔期，只在它真的會影響這個品牌的買家時拿來挑情境與 hook，不必硬套節慶。
證明那一段列出的就是這個品牌**確認有**的證據；沒列的不能用。限時限量只在活動有結束日時出現，
截止日由工作檯帶給文案，這裡不寫日期。

【這個賣法】是這次要賣的東西（名稱、單品或組合、確認過的事實、價格）。廣告名稱和情境只講這裡寫的
東西，不要自己加功效或數字。

【不能講】是使用者標了不能講的話。廣告名稱、`scene` 都不能出現這些字；名稱寫了其中一個，整份回覆
會被退回。

【上幾期的排名】是程式從已結案廣告排出來的（每筆＝花費÷成交），「留下」「換掉」是程式的判定。
「換掉」的顧客群＋角度不要原樣再用（同一群換一個角度可以），原樣再用了「換掉」的，整份回覆會被
退回；標「樣本少」的留下只賣了幾筆，值得再驗一次；其餘廣告可以探索。排名裡寫「這期沒列」或
「未指定」的群不算。寫「還沒有結案過的廣告」就照品牌事實與行事曆挑。

【已沿用的廣告】是上一期「留下」的廣告，程式已經連同圖片和文案放進投放組（名稱、七個座標照上一期），
你不要再寫一次，名稱也不能跟它們重複。有寫「請再規劃 K 則」時，你的回覆總共寫 K 則廣告；已經有
沿用廣告的角色可以不寫投放組，沒有沿用廣告的角色每個至少一則。在已有沿用廣告的投放組再加廣告，
`customer_group` 要填跟沿用廣告同一群。

【這期撐得起幾則】是程式用每天預算和上限算出來的：每天的錢撐得起幾則，另加 1 則探索，就是這期最多
幾則（沿用的也算在內）。整份計畫的廣告超過「最多」，整份回覆會被退回；寧可少寫，不要多寫。

【這個賣法的顧客】有列顧客群時：每支廣告要填 `customer_group`＝它寫給的那一群的編號（「第 N 群」的
N，只能填列出的編號）；`pain` 要從那一群的煩惱（括號裡 `pain=` 後面的 key）裡挑，`scene` 是那一群
「什麼時候用」裡的一個時刻。**同一個投放組的廣告都寫給同一群**（一個投放組就是一群人），不同的群
放在不同的投放組。寫「還沒有建顧客群」或「沒有指定商品」就不用填 `customer_group`，照品牌事實挑，
不要自己編一群。

【手上的素材】是程式數出來的照片與影片數量。照片至少 1 張時，整份計畫的廣告總數不要超過照片張數
（每支廣告要有自己的圖可用）。

【這期可用的優惠】有列時：每一行是一個可用的 `offer` key 和它登記的那句話（價格、原價都在句子裡）。
至少要有一支廣告的 `offer` 填列出的某個 key（已沿用的廣告用了列出的優惠也算），那支廣告的名稱和
`scene` 要合這個優惠（句子講的是什麼好處，名稱就點出它，情境就是會在意這個好處的時刻）；其餘廣告
可以填 `none`。全部廣告都填 `none`，整份回覆會被退回。寫「這期沒有可用的優惠」時，每支廣告的
`offer` 都填 `none`。

**你的整段回覆必須是、且只能是一個 JSON 物件：不寫任何開場白或結語、不用 ``` 或任何
markdown fence 包起來、物件前後不留一個字。**

## 三條不可違反的規則

- **角色不能少也不能多。** 下面給你幾個角色，你就回幾個投放組，`role` 要跟給你的角色
  一字不差對上，不能自己加、不能漏掉（唯一例外：【已沿用的廣告】已經放了廣告的角色可以不寫）。
- **座標只能從詞彙表裡挑。** 每個 `coordinates.<dimension>` 一定要填詞彙表裡那個維度的某個
  `key`（不是 `label`），七個維度一個都不能漏、不能編一個詞彙表沒有的 key。
- **名稱是要貼到平台後台的追蹤名稱。** 廣告名稱要能讓人一眼看出「這支廣告在打什麼」，不用
  emoji、不用平台自己的術語（例如不要出現「動態廣告」「A/B 測試」這種平台詞），同一個
  Campaign 裡每支廣告的名稱都要不一樣。

## 交付內容

- `groups`：一個陣列，最多 4 個（通常跟給你的角色數一樣多），每一項是
  `{"role", "name", "ads"}`：
  - `role`：`new`／`retarget`／`explore` 其中之一，對應下面給你的角色分配。
  - `name`：這個投放組的中文名稱，看得出角色跟這次投放的主題。
  - `ads`：這個投放組底下的廣告，1～3 支，每一項是
    `{"name", "coordinates", "scene", "customer_group"}`：
    - `name`：追蹤名稱（見上面規則）。
    - `coordinates`：`{"audience", "pain", "angle", "hook", "proof", "offer", "format"}`
      七個鍵，每個值都是詞彙表裡對應維度的一個 `key`。
    - `scene`：一句 6～60 字的具體情境（誰、在哪、正在做什麼），文案會發生在這個情境裡；
      不同受眾的廣告要用不同情境，廣告名稱要跟情境一致（名字寫運動族，情境就是運動場景）。
      同一支廣告只有一個情境；不同受眾卻用同一句情境，整份回覆會被退回。
    - `customer_group`：【這個賣法的顧客】的群編號（整數，例如 `1`）。有列顧客群時必填；編號不在
      列表裡、`pain` 不在那一群的煩惱裡、或同一個投放組寫給兩群，整份回覆會被退回。沒有列顧客群時
      省略這個鍵。
