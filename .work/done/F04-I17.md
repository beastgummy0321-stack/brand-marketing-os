# Objective

素材組頁（SetStudio）右上角的「到投放中心 ↗」硬寫 `/brands/${brandId}/ads`——把人丟回清單頁，
要自己再找一次是哪一個 Campaign。上游早就把回家的路一起交過來了：`set.origin_href`
（ARCHITECTURE.md §5.4，例：`/brands/<brand>/ads/campaigns/<id>?tab=assets`），任務包頁
（`PackPage.tsx:141`）已經在用它。§0 連結：**handover**（一個步驟要看得到、回得去上一個步驟）。

# Done

- 條件從 `set.source_kind === "schedule_node"` 改成 `set.origin_href`（有路就顯示連結，
  沒有就不顯示）——工作檯不解讀 `source_kind`，這是 §5.4 的規矩，這裡順手回到正軌。
- `to={set.origin_href}` 原樣使用（後端保證它是不含 `/app` basename 的 router 路徑，
  工作檯**不解析、不改寫**）。

  「回到投放中心 ↗」（跟 PackPage 的「回到投放中心」一致；來源名稱那一行已經在左邊的
  `來源：{origin_label}` 印過了）。

其他一行不改（`source_kind` 這個欄位本身留著，型別也不動）。
