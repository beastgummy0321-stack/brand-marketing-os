# Objective

周邊設定與通知的資訊分層。只整理既有入口，不建立新設定服務、收件狀態機或全站導覽。

# Done

- 設定預設常用花費上限；連接狀態易達，模型／技術內容置本頁進階區。保留 URL 深連結、切換草稿、必需 API 金鑰設定和既有費用資訊；缺連接不能藏到找不到。
- 規則卡保留既有資料／保存／恢復接口，欄位單位與作用品牌明確；現有整卡重設清楚寫「重設整張卡」，不得冒充單項還原。單項還原要求適用新比較接口，本票不擴寫 legacy API。
- 智庫預設品牌事實，研究／座標等既有技術分類放本頁進階入口；已存在的 tab URL 可直達並展開，必要待補事實／宣稱不隱藏。不重做其他 tab 內容。
- 通知沿用既有人工 resolved 行為，改明確「標記已處理」及可見處理連結；不宣稱自動修復、不新增已讀資料模型。

# Verify

設定深連結／保留草稿／品牌切換、恢復範圍、智庫進階 URL 導航、通知標記不冒充系統修復。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
