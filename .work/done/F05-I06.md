# Objective

「這個品牌以前投放過廣告嗎？」現在是**送出第一步之後才跳出來的 dialog**
（`IntakeWizard.tsx:57-68` 的 `pendingNewBrand` 流程），而且答案對使用者沒有任何可見後果——他不知道
自己剛剛決定了什麼。使用者裁決：**做在步驟一的表單裡，沒選不能往下，選了立刻說出後果。**

原型：`.harness/scratch/prototype/intake-foundation/index.html` 步驟一（`:168-180`）。

# Done

1. `steps/StartStep.tsx`：品牌名稱底下加一組二選一，標籤逐字是 **「是否曾經投放過網路廣告」**，
   兩個選項「投放過」／「完全沒投放過」（沿用既有 `advertising_history` 的 `has_history`／`none`）。
   **預設不選**；主要按鈕（「建立品牌並開始初掃」）在**沒選或沒填品牌名稱時 disabled**。
2. 選了之後底下立刻出現一行小字（原型逐字）：
   - 投放過 →「接工具那一步綁好廣告帳戶後，系統會拉近 37 個月花費當預算依據。」
   - 完全沒投放過 →「系統會用你的售價與成本算一筆試驗預算。」
3. 送出時把這個答案跟品牌一起送（既有的 `AdvertisingHistoryDialog` 打的是哪支端點就打哪支，
   **後端不動**）。`IntakeWizard.tsx` 的 `pendingNewBrand` 兩段流程刪掉，送出成功直接導頁。
   `AdvertisingHistoryDialog.tsx` 若沒有其他呼叫端就整個刪掉（grep 確認）。
4. e2e：`smoke.spec.ts:41-44` 現在斷言 dialog 的標題「這個品牌以前投放過廣告嗎？」——改成在步驟一
   點「完全沒投放過」再送出。`width-overflow.spec.ts:67` 的「投放史 dialog」那一段一併改成新版面。
5. 寫之前叫 `Skill impeccable:impeccable`，對照原型與 `docs/design-system.md`。
