# Objective
Two backend root causes. (a) Drill-8 #5: the default campaign name is the first 40 chars of the composed goal sentence, so the dates
fall off and every period gets the same name (readback then collides). (b) Drill-8 #6: the first-launch list page cannot show
「本月預算放得下」 because no response carries the launch's month numbers; only approve's raised message reaches the page.

# Done
1. `app/ads/brief.py::_draft_name` → name = `<base>・MM/DD～MM/DD` (start/end of the draft; `・` U+30FB, `～` U+FF5E). `<base>` = the
   picked product's name on the structured path, else the stripped goal text; `<base>` alone is shortened to 30 chars + 「…」 when
   longer; the date suffix is never cut. No dates known → `<base>` only (same shortening). `create_draft` passes what it already
   has. The readback collision rule (`launch_view.py:461`) stays as it is.
2. `app/ads/change_control_launch.py` gains `month_fit(conn, org, brand, campaign_id, snapshot) -> dict` using exactly the inputs
   `_approve_set` gives `month_budget.preflight` — `snapshot["month"]` and `[_launch_item(...)]` — without raising:
   `{"month", "amount", "known_spend", "ongoing_estimate", "reserved_increases", "available", "uncertainties", "ongoing_owners",
   "extra": <reserved_increases with the item − without it>, "blocker": null | "unset" | "short" | "uncertain", "blocker_text": str|null}`.
   Money fields are the `month_budget.view(...)` values with the launch item added (same shape `getMonthlyBudget` returns, so the
   frontend card reads it unchanged). `blocker` mirrors preflight's three refusals in its order: amount unknown → `unset`
   (「要先設 N 月月預算」), uncertainties → `uncertain` (the preflight sentence 「餘額尚不確定，暫不能核准新增花費…」), available < 0 →
   `short` (「N 月預算不夠這期花」); else null. N = the month number.
3. `app/ads/launch_view.py::view`: the `step == "list"` response gains `"month_budget": month_fit(...)`; approved steps return
   `"month_budget": null`. Docstring sentence naming the reader (the first-launch list page).
4. Tests: `test_ads_brief.py` — a structured create with product 「Beast Gummy 超能特惠組 · 單品」 and 10/10–10/16 is named
   「Beast Gummy 超能特惠組 · 單品・10/10～10/16」; a 60-char product name keeps the full suffix. `test_ads_launch_view.py` — list step:
   no month budget → `blocker="unset"`; budget large enough → `blocker=null` and `extra` equals the reservation the approve would
   add; too small → `short`; approved step → `null`. One assertion that approve refuses exactly when `blocker` is non-null (same seam).
