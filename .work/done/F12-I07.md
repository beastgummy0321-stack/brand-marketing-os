# Objective

跨模組一般／進階流程驗收。把 Feature Acceptance 變成可重複的整合驗收；不以 UI 成功宣稱外部平台或實際模型成功。

# Done

- 使用既有 Playwright 設定與可用測試資料／scripted reply；增加單一測試檔覆蓋一般流程不開進階、比較選用、進階保存／還原／缺漏定位、普通品牌無內部入口。由 manifest smoke 自動執行，不再複製 build／e2e 指令。
- 若背景流程無法由既有測試 seam 覆蓋，使用模組 API/整合測試保證行為並在本機重啟的隔離服務做真 UI 檢查；不新增未受約束的 scripted reply、不擴寫生產假資料分支。
- 在本 feature 新建置上按 docs/verification.md 檢查 1024／1920、窄版及鍵盤、loading／empty／error。記錄版本、狀態、截圖在 repo 外；啟停本人測試服務，避開既有埠。客觀結果與唯一主觀 human 項目分開。
- 檢查 ads/workbench 公開入口與依賴不變，新比較 API isolation 仍通過；F07 內容驗收未被 UI 位置變更削弱。

# Verify

Manual verification：執行者在本 feature 新建置與重啟的隔離服務，使用正常登入，於 1024／1920 及窄版實際操作一般流程、進階收合與 dirty 草稿、缺漏定位、比較選用、測試品牌入口；記錄版本、狀態、截圖、通過／未通過並清理自己的服務。Feature integration 由 manifest 跑 checker、全套測試、build、smoke（包含本票新增的 Playwright 檔）；本票不重複列同指令。客觀瀏覽器驗收由執行者完成，不全部交回使用者。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
