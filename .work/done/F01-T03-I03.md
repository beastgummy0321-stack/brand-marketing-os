# Objective

`app/methodology/image-prompt-template.md` §7 line 114 reads 「這份檔與任何回覆都不寫死一個數字」. A
model can read that as "a reply may not contain digits", which contradicts §5 rule 3 (a price or
discount that appears verbatim in the quotable text or brand context is allowed on the image). The
rule only means the image count is the user's `<N>`. Say exactly that and nothing more.

# Done

- Replace line 114, the whole line, verbatim:
  - old: `- 張數是使用者輸入的 `<N>`，這份檔與任何回覆都不寫死一個數字。`
  - new: `- 張數是使用者輸入的 `<N>`，不寫死。`
  (the inner backticks around `<N>` are part of the file text, as today.)
- No other line in the file changes. §5 is not touched; the department file
  `app/departments/workbench/image_prompt.md` does not carry this line and is not touched.

# Verify

The first command is the string count (new line exactly once, the phrase 「不寫死一個數字」 gone); it
uses `\u` escapes so it runs the same under cmd.exe and Git Bash. Then
`uv run python -m pytest app/tests/test_workbench.py::ImagePromptMethodologyShapeTest app/tests/test_methodology.py -q`
proves the template still matches the shape the I01 contract asserts.
