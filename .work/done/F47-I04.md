# Objective
Background work says when the worker stopped, and the workbench recovers from its own race and from a manual override
(feature Contract C and the Q7 decision). Drill 10: with the worker stopped the product read showed 「正在讀商品頁…」 for 3.5 min,
copy generation 「排隊中・前面還有 0 件」, both silent (W1, W2); 「找不到工單」 still happens and its error never clears (W4); a
pack approved with 「確定覆蓋」 is locked forever at 0/1 (Q7).

# Done
1. `background.queue_snapshot()` returns `worker_alive` (a `procrastinate_workers.last_heartbeat` within 60 s, one query on the
   same queue connection; memory-queue mode → `true`). `GET /api/jobs/active` adds `worker_alive` and `stalled`
   (= not alive and this org has ≥ 1 queued/running job). Docstring states Contract C and the commit-before-enqueue rule.
2. Frontend: `lib/jobsApi.ts` types; `lib/useWorkerHealth.ts` (polls `/api/jobs/active` only while a caller says it is waiting,
   reusing the caller's interval); `components/layout/WorkerStoppedNotice.tsx` with the Contract C sentence and 「再檢查一次」
   (re-reads both the job state and the page's own state). Rendered by: the jobs bell (replacing 「排隊中・前面還有 0 件」 while
   stalled), `ScanStep` (brand site read), `ProductOnboarding` (product page read), `AssetsBody` (copy generation; above the
   slots — do not change slot state rules, F45 owns them), `SetStudioPage` (set generation). No page keeps a spinner without it.
3. W4: in `app/workbench/repository.py` every path that writes a brief then enqueues its job commits first, then enqueues
   (`:94-107` and any other such site in the file); a successful run clears `last_error`; the set studio shows a failed
   generation's `last_error` with 「重新生成」 (move the generation-status block of `SetStudioPage.tsx` — 794 lines — into
   `SetGenerationStatus.tsx` so the page stays under the 800-line cap).
4. Q7: a pack approved while a required output was missing keeps `approved_at`, but each set still missing a required part
   accepts generate / select for **that part only**; parts already selected stay locked (`pack_approved` stays for them). The
   pack page reads 「已核准・還缺 N 組」 instead of 「已完成 0/1」 and links to the first incomplete set.
5. Workbench controls (drill-10 乙 #15–#21): 「查看全部 →」 shows the full list; 「查看來源」 opens the source campaign (or is
   absent when there is none); 「下一步・圖片待選定」 opens the set that needs it; 「關閉任務包」 and 「封存」 ask once with what
   happens; closed packs are reachable from the list; a set with no name shows its source name; the header shows the format
   label (「單張圖片」), not `single_image`.
6. Tests: snapshot `worker_alive` true / false (stale heartbeat row) / memory mode; `stalled` per org; the notice renders when
   `stalled` and disappears after 「再檢查一次」 with a live worker; brief committed before enqueue (a job started by the enqueue
   finds the brief); `last_error` cleared on success; override-approved pack lets a missing part be selected and refuses a change
   to a selected one.
