# Objective

一般投放流程與必要上架引導。保留既有建立與採用順序，只減少閱讀負擔和改善必要操作定位。

# Done

- 建立／確認頁保留需求、商品、目標、預算、期間和修改；合併重複功能介紹，不強迫指定平台或品牌。
- 策略一段摘要加主要動作；詳細原因與學習目標收合，影響成本／可用性的未知直接顯示。
- 人工上架必要清單按既有步驟呈現，缺素材與缺設定直達；選填 ID／診斷收合。名稱、可用平台沿 channels／adapter 回傳，不以固定 Meta 文字充當通用指引；實際 Meta 專屬流程仍標真實平台，不冒稱支援未接平台。
- 清楚區分記錄準備、平台完成、配對成功；預算核准與未上線說明保留。
- 一般入口移除與手動上架並列的內部模擬選項；測試品牌原模擬回收依 I03 供內部使用。既有模擬 adapter 能力不刪除或擴權。

# Verify

原草稿恢復／預算更動／必要上架動作回歸；無平台、非 Meta 顯示資料、未連接能力不冒充可發布；普通使用者不用開選填進階就能找到所有必做項目。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
