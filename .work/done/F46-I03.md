# Objective
What shipped is what gets recorded (feature outcome 5, Contracts F and O; drill-10 root cause 2). Today a carousel slot with one
image is ready, the handoff list never says the format and learning records 「輪播」 (P2); an ad planned with an offer whose copy
omits it is confirmed (P1); the hand-built ad set's hint does not name the customer group (P5).

# Done
1. New `app/ads/actual_format.py` (ads-private): `of_asset(asset) -> "video" | "single_image" | None` (`mime_type` starting with
   `video/` → video; any other ready file → single_image; no asset → None) and `of_ad(conn, org, brand, campaign_id, ad)` through
   the ad's assigned material (`material_placement_id` / revision → its asset). `note(planned_key, actual_key, labels) -> str | None`
   = 「規劃是輪播，只放了 1 張圖，會以單圖上架」 for carousel → single_image, else 「規劃是〈planned〉，放的是〈actual〉，會以〈actual〉上架」;
   `None` when equal or either is unknown. Labels from the brand vocabulary (`format` dimension), key as fallback.
2. `live_creative.learning_coordinates`: an ad with an assigned material takes the actual format over the snapshot / planned
   `format` (one place, so visual learning, the campaign learning scope and F46-I04's ranked rows all read it).
3. `launch_view`: an ad's handoff fields gain 「格式」 after 「素材」 = the actual label, plus 「（規劃是〈planned〉）」 when different; no
   material → the planned label. View-time only: not in the frozen snapshot, `expected_json` or any approval hash.
   `audience_hints` adds 「顧客群：〈who〉」 when the group's ads carry one `customer_group_id` (F46-I01) that still resolves.
4. `slots`: every slot gains `format_note` (Contract F): from the material when assigned, else the pending placement's asset, else
   `None`; imported campaigns `None`.
5. `asset_suggestion_policy.violations`: when the placement's `offer_key` is a real key and `validate_claims(...,
   offer_key=)["missing_offer"]` is non-empty → detail `copy`, 「這則規劃的是「〈offer label〉」，文案沒有寫這個優惠：「〈first sentence〉」。」,
   `terms` empty. The slot reads 卡住 with 換一版文案 like any copy refusal (F44 Contract D).
6. Frontend: `Slot` gains `format_note?: string | null`; the tile shows it as in `.harness/scratch/prototype/f45-slot-states/index.html`
   (slot `a2`, the 「ⓘ」 note under the copy). If F45's tile already renders a note from the slot payload, wire it to this field
   instead of adding a second one.
7. Tests: video / image / missing mime; learning coordinates switch carousel → single_image once a material is assigned and keep
   the planned key without one; handoff field row with and without a difference; slot `format_note` for material, pending and
   none; an `offer=bundle` placement whose copy lacks the sentence is refused with that text and one that has it confirms; vitest
   renders the note and nothing when null.
