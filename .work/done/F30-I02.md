# Objective
The 變差 flow when the AI text was rejected or the round failed. Spec: `docs/design/ads/prototype-v10-ai-blocked.html` (Feature "Screens", I02).

# Done
1. Evidence page: when `result_json.rejected` is set, the numbers show as for a ready round and the AI card becomes the dashed 「✦ AI 這次的說明沒採用」 card with 「再請 AI 看一次」 (`retryReview` → navigate to the new round, which shows the existing running state). A `failed` round also offers the same retry beside its message. Retry failure (409) keeps the page and says why.
2. Prepare page: with no AI recommendation, the ladder-chosen option's chip reads 「照順序先試」 instead of 建議.
3. Copy page: with no recommendation, the new version starts from `conditions.creative_snapshot.copy_fields` (the platform's current copy) and the purpose line reads 「AI 沒給新版，從現在的文案直接改」; no `review_id`/`recommendation_id` is attached (as today).
4. Tests: rejected round through all three steps, failed round retry, retry 409, variants copy mode.
5. Evidence for the three hashes, port 8733; §1.7 self-check.
