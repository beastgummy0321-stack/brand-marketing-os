# Objective
Close the two backend gaps F43-I15 (slim #/new) found before any screen work: the draft's customer groups can be edited after create,
and the new-campaign page can preselect the brand's conversion goal from the options it already reads.

# Done
1. `PATCH …/campaigns/{c}` accepts `customer_group_ids` (list of ids; `[]` = all groups of the sell-way): validated against the
   campaign's sell-way groups with the same rule as create (`brief._check_customer_groups`, code `customer_group_unknown`), stored in
   `context_json.customer_group_ids`, `field_sources.audience = "user"`. A PATCH that changes `product_ids` (sell-way) resets
   `customer_group_ids` to all groups of the new sell-way with `field_sources.audience = "sell_way"` unless the same PATCH sets them.
2. `wizard_options.options()` returns `default_objective`: the brand's `conversion_goal` mapped to a campaign objective key through one
   table in `app/ads/objectives.py` — purchase → 購買, lead → 名單, booking → 名單 (lead-like: a booking is a contact, not a sale;
   lead decision 2026-10-01, reversible), awareness → 知名度; unset → null (no preselection).
3. Tests: PATCH groups (valid, unknown id refused, reset on sell-way change); `default_objective` for all four goals and unset.
