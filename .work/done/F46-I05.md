# Objective
The owner and the month review read the same learnings (feature outcome 4 backend half; drill-10 L5: no page shows learnings;
L6: the month review says 「這個月沒有要給下個月的建議」 after a closeout because suggestions only come from open queue rows of
imported campaigns).

# Done
1. `GET /api/ads/brands/{brand_id}/coordinate-learnings` with optional `campaign_id` and `sell_way_id` query params, in
   `learning_routes.py` (same guard): returns `learning_view.learnings_view(...)` as is (Contract L). Unknown `campaign_id` /
   `sell_way_id` of this brand → the empty view, not 404 (a filter, not a lookup).
2. `month_summary.get_summary`: a fourth suggestion kind `next_plan`, one per sell-way, from internal campaigns closed inside the
   month (closed time's org-local date in `[start, end]`) that have ranked rows; the newest closed one per sell-way wins. Fields as
   the other kinds: `key = "next_plan:<campaign_id>"`, `campaign_id`, `campaign_name`, `objective`, `campaign_objective`
   (`repository.campaign_objective_family`), `title` = 「用「〈campaign〉」學到的排下一期」, `why` = 「留下 N 則（最好的「〈ad〉」每筆 X）、
   換掉 M 則」 (no sold row: 「留下 0 則、換掉 M 則，沒有一則賣出」), `action_url` = the view's `next.new_campaign_href`. Dismissal
   accepts the kind (`_SUGGESTION_KINDS`) and stores on that campaign like the others.
3. Tests: route returns the view, filters, guard (`test_ads_routes_guard.py` covers the new route); suggestion appears in the
   closing month only, once per sell-way, respects dismissal, absent when the closed campaign has no rows; existing kinds unchanged.

# Touch notes

the org-local month); a closed campaign with no sell-way (no `next_plan`: there is nothing to prefill). The suggestion card's
button text is F46-I07's.
