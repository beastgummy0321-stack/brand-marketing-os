# Objective

沒有投放組＝**推導不出總預算**，不是「總預算 0 元」。實機走查（2026-09-13，seed 帳號
brd_bughunt）在「所有 Campaign」清單看到三筆還沒採用策略的草稿印成
「還沒有花費資料 / NT$ 0」——那個 0 是程式自己編的。

成因只有一處：`app/ads/repository.py:29-39` 的 `_budget_total()` 在 `groups` 是空列表、
但 `start_date`／`end_date` 都有值時，`sum([]) = 0` → `0.0 x days = 0.0`。這條是 F04 決定 12
（「沒有成效列＝沒有花費，不是花了 0」）的同一種錯，只是發生在總預算那一欄。

修在那一個定義裡，不修在畫面、也不在每個呼叫端補判斷。

# Done

1. **`_budget_total()` 沒有投放組就回 `None`**（`app/ads/repository.py:29-39`）：
   `groups` 是空的（或所有 `daily_budget` 加起來 <= 0）時回 `None`，不回 `0.0`。
   日期缺一半就回 `None` 的既有分支照舊。docstring 補一句為什麼（沒有東西可以推導，
   跟 F04 決定 12 同一條誠實規則）。**只改這個函式的函式體與 docstring。**

2. **確認呼叫端不靠那個 0**（已由規劃師查過，工人照著核對一遍就好，**不要順手改**）：
   - `repository.list_campaigns:242-255` 與 `campaign_detail:351-355`：`pct` 的算式是
     `if spend is not None and budget_total`，`None` 與 `0` 走同一條分支 → 不變。
   - `judgment.campaign_judgment:60-63`：`if not budget_total` 同樣收 `None` 與 `0` → 不變。
   - `adapters/manual.publish:98-106`：`daily_sum <= 0` 先擋掉「沒有投放組就發布」
     （`no_groups_to_publish`），所以 `detail["budget_total"] is None → daily_sum` 那條
     fallback 在這張票之後仍然只會在「有投放組、但沒有期間」時觸發 → 不變。
   - `plan._check_budget_ceiling` 用的是另一支 `group_budget_total()`（直接查 DB 的日預算
     合計），不是這一支 → 不碰。
   如果核對下來發現還有第四個呼叫端真的靠 `0`，**不要在那裡補判斷**，回報（見 Blocked if）。

3. **測試**（`app/tests/test_ads_model.py`，照該檔既有寫法加，不新增檔案、不改既有斷言）：
   一個 `status='draft'`、`start_date`／`end_date` 都有、**沒有建任何投放組**的 Campaign →
   - `campaign_detail(...)["budget_total"] is None`
   - `list_campaigns(...)` 裡那一列的 `budget_progress["total"] is None`
     且 `budget_progress["pct"] is None`
   測試名字要講得出宣稱（例如 `test_no_groups_means_no_total_not_zero`）。
