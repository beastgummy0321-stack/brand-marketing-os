# Objective

The 【輸出】 line does not follow the settled shape. ARCHITECTURE.md §5.7 and
`app/methodology/image-prompt-template.md` §2 (written by F01-T03-I01) both say
`【輸出】<format label>（<format 說明>），一張`, and 「【輸出】一張」 when the node has no format. `_run`
in `app/workbench/jobs.py` (lines 331-335) builds it with `_vocabulary_phrase`, which joins with `——`
(the 【這則的訴求】 convention), so the screen shows 「【輸出】彈性格式——…，一張」. F01-T03-I02 only tested
the renderers with a ready-made `output_line` argument, so nothing caught the assembly.

The leaked engineering note inside the 說明 is fixed at its source by F01-T03-I05; this issue only
fixes how the line is assembled and pins it with a test.

# Done

- In `app/workbench/jobs.py`, add a pure module-level function next to `_vocabulary_phrase`:
  `def _output_line(rows: list, format_label: str) -> str:` returning
  - `"一張"` when `format_label` is empty;
  - `f"{format_label}（{situation}），一張"` when a row with `dimension == "format"` and
    `label == format_label` has a non-empty `(row["attributes"] or {}).get("situation")`;
  - `f"{format_label}，一張"` otherwise (label not in the vocabulary, or no situation).
- In `_run`'s `image_prompt` branch, replace the `format_label = ...` / `if format_label:` ... `else:`
  block (lines 331-335) with
  `output_line = _output_line(coordinate_rows, coordinates_snapshot.get("format") or "")`.
  `_vocabulary_phrase` and its two other callers (切角, 標題公式) are unchanged.
- In `app/tests/test_workbench_image_prompt.py` add `class OutputLineTest(unittest.TestCase)` calling
  `workbench_jobs._output_line` with plain dict rows
  (`{"dimension": "format", "label": ..., "attributes": {"situation": ...}}`), exact equality:
  - 彈性格式 with situation `1～10 張同座標圖` -> `彈性格式（1～10 張同座標圖），一張`
  - 單圖 with situation `4:5，1080×1350` -> `單圖（4:5，1080×1350），一張`
  - empty label -> `一張`
  - label `輪播` with no matching row -> `輪播，一張`
  - and one end-to-end line: `prompts.render_hero_prompt(...)` (reuse the fields of
    `RenderHeroPromptTest.test_line_order_and_dropped_lines`) with
    `output_line=workbench_jobs._output_line(rows, "彈性格式")`; its last line equals
    `【輸出】彈性格式（1～10 張同座標圖），一張`.
