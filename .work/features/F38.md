# Outcome
The five remaining drill-6 items land in one batch, all as program rules (no LLM judgment):
1. A brand registers the evidence it really has as 「證據」 brand facts (six kinds = the six `proof` coordinate keys). The
   delivery plan and the copy prompt only ever offer the proof kinds the brand has evidence for (+ 無證明); a customer-voice
   record counts as 顧客評論原話 evidence. The copy prompt receives the evidence text so it quotes, never invents.
2. Promo offers are off by default (drill-4 RC-C, finally built): new brands get the six promo offer keys seeded disabled,
   existing brands are switched off once by migration (test data); the brand enables real offers in the coordinate screen.
   「限時限量」 copy carries the campaign's end date as its only deadline; the workbench writes the 無優惠 version when no
   deadline is handed over.
3. The manual checklist's 「受眾提示」 adds the brief's own audience text and a fixed per-role exclusion sentence — still a
   read-only hint, never a platform targeting mapping (F36 ruling E stands).
4. Budget history keeps two sources and says so: the account base caption names 「Meta 廣告帳戶全部活動」.
5. `app/workbench/image_port.py` gets its final call shape (typed input/output the future adapter must honour) and still
   does nothing: no provider, no key, no cost. The 圖片 tab stays the prompt-card view.

# Decisions
User-confirmed (dig 2026-09-29):
- Proof availability is derived from confirmed brand facts, not from a seed toggle: fact type `proof` + `fact_key` (one of
  `customer_review, expert_endorsement, lab_report, sales_numbers, media_coverage, founder_voice`). A brand with ≥1 active
  `customer_voice` row also has `customer_review`.
- Offer default-off = RC-C as ruled (`docs/backlog/issue-drill-4-root-causes-pending-rulings.md:63-65`), not re-opened.
- 限時限量 deadline = the campaign (or group) `end_date`; the copy never invents one. No new coordinate attribute, no screen.
- Audience hint = role + audience coordinates + 「簡報受眾：<context_json.audience_hint>」 + role exclusion sentence
  (`new`/`explore` → 「排除：已購買者」, `retarget` → 「只投：互動過或買過的人」). No age/interest inference, no Meta mapping.
- Account history: two sources stay; the caption names the source. Sync-table monthly rows only hold campaigns bound to this
  brand, so they cannot be the account base (would undercount).
- 站內出圖: define the port's signature only; no provider, no stub that pretends to generate; prompt cards remain the product.
Agent choices (reversible):
- `fact_key` is a nullable column on `brand_fact` with a CHECK tying it to `fact_type='proof'`; other fact types keep NULL.
- Unavailable proof/offer keys in a model reply are replaced by `none` (not a plan failure) — the vocabulary already told the
  model what exists; a stray key is a wording slip, not a reason to burn a retry.
- The proof gate lives in the two prompt builders (`ads/plan.py`, `workbench/jobs.py`), not in `coordinate_vocabulary`
  itself, which stays the label lookup for existing ads (`launch_view`, `experiments`, `ab_pairs`, `visual_learning`).
- The coordinate screen's proof toggle keeps its meaning (「allow this creative kind」); evidence is a second, independent
  condition. Both must hold for a proof kind to be offered.
- Wizard truth cards do not propose 「證據」 cards in this feature; the library FactPanel is the entry. Candidate for later.
Unresolved: none blocking.
