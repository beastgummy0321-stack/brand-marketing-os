# Outcome
隔離測試品牌能從正常 UI 保存每日模擬成效、修正與重送、結案並將學習留在同品牌；系統先提出同受眾單一變因比較計畫，使用者確認後才保存為已確認計畫。

# Decisions
- 使用者確認（2026-09-18）：採隔離模擬入口，不擴為正式人工/CSV 回收；A/B 採系統提案、使用者確認。
- 延用既有 ads 成效、模擬配對、結案與品牌內學習。模擬與實際平台證據不能混同，不呼叫付費生成或對外投放。
- 代理實作選擇：入口限本機測試環境；以既有組織設定保存永久測試品牌標記。啟用前排除真實帳戶/綁定/成效，啟用後禁止該品牌手動配對及真實回收。畫面持續標示隔離模擬。
- 每日增量、整日快照取代：實際 ad ID 對應既有素材與受眾；缺回收的廣告不寫零；拒收累計模式。同日重送不累加，修正有版本與操作來源，結案鎖定。初版不宣稱支援每個指標各自缺值。
- 系統依現有結構提出可比較的同投放組/同受眾兩支廣告、僅一個座標不同。缺少合格對照時顯示缺口，不亂湊比較；不自動新增素材或改投放預算。
- 計畫包含假設、主要變因、共同条件、目標指標、觀察窗、樣本/停止/判讀條件，保存確認者及結構快照；結構或條件改變須重新確認。輸出為觀察性比較，不聲稱隨機實驗、統計顯著性或因果關係。

# Acceptance
- 正常 UI 啟用隔離品牌、綁測試 ID、讀寫/更正每日資料；不產生真實平台寫入。
- 重送冪等、品牌/組織/廣告歸屬檢查、日期界線、零與缺列、版本衝突、結案後拒改。
- 同品牌結案來源可追溯，下一輪讀到該品牌學習；其他品牌讀不到。
- 系統比較提案及確認、缺少對照/資料/樣本時不硬判；條件變更可辨識過期。
- 相關測試、完整整合、1024/1920 UI 驗證；不把模擬推論當市場實證。
