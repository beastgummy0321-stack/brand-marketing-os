# Outcome
修復 audit-findings 的 P2 第 6–10 項，使用者能持續生成、找到人物誌、保留計畫草稿、理解並確認內部手動上架準備，以及安全切換品牌。

# Decisions
已授權：P1 完成後往 P2，需產品決策先 dig。代理選擇：延用既有畫面與後端狀態、分品牌與使用者的本機草稿、手動模式先唯讀再明確確認。成效回收、A/B、P3 不在本 Feature。無資料遷移、不新增平台投放。

# Acceptance
- 背景素材連到實際素材組；生成狀態與完成刷新，不再錯顯空狀態。
- 人物誌通知可直達既有閱讀編輯區。
- 新計畫離頁返回可恢復，送出成功清除草稿，品牌間隔離。
- 打開手動清單不核准；確認時揭示只記錄準備、不對外發布。
- 切品牌丟棄舊資源 ID 與資源查詢條件。
- 回歸與整合檢查，UI 使用隔離測試環境。
