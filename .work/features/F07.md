# Outcome

Image prompts in 素材工作檯 stably reach the level of the user's references for any brand, industry
and style, and the system produces them by itself — no user tuning, style picking or instructions.
For each 素材組 one model call writes exactly 10 complete natural-language prompts (輪播: 2 concepts ×
5 cards) that paste into GPT chat in one click. Each prompt follows one industry-agnostic craft
grammar (visual device → layout → look-driven details → subject from the offering's reference →
designed typography → intent from the image task) and ends with the system-derived brand visual
identity plus that item's look texture, pasted verbatim. The system derives each brand's visual
identity and a ranked starting guess of fitting looks from brand facts; a program assigns each of
the 10 slots a look — learned winners take at most 7, at least 3 explore the least-tried looks, and
nothing is permanently excluded by the system's guess. The image task comes from the ad's audience,
offer, proof and the brand's conversion goal. Every item carries a fingerprint; items are labelled
主力／探索 and each set recommends one item so about 3 in 10 sets test an exploration look; the user
marks the hero. Single-image ads get a no-model-call variant prompt whose count the plan decides. At
結案 the system learns by fingerprint within the same audience, downgrades winners that later lose,
and the next round reads only learnings at 可能成立 or above. Coordinate labels stay
everyday words, 彈性 no longer exists, video ads get copy + script, and usage stays lean.
