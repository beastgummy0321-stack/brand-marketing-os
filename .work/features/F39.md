# Outcome
The drill-7 red items and the backend-only yellow items land as program rules plus prompt inputs (no frontend page changes;
those are F40):
1. **Per-ad coordinate grades become learnings.** Closing a campaign writes, besides the existing campaign sentence and the
   visual learnings, one `source_track='coordinate'` learning per graded ad (划算／偏貴／太貴／沒賣出 by the one ruler,
   `period_grades.grade_period` over the campaign window) whose `applicability_scope` carries the grade and the ad's seven
   coordinate keys. Ungraded ads (資料不足／未判斷) write nothing.
2. **The program tallies a coordinate scoreboard and both planners read it.** `coordinate_learning.scoreboard_section`
   renders, from those rows, per-dimension tallies (key｜label：划算 n、偏貴 n、太貴 n、沒賣出 n) plus the last closed
   campaign's 划算 and 太貴／沒賣出 ads with their coordinates. The strategy prompt and the delivery-plan prompt both include
   it; the two department files tell the model to reuse a 划算 combination verbatim at least once, not to reuse a 太貴／沒賣出
   combination unchanged, and to name what it reused in `rationale`. Empty scoreboard = section says so, rule inactive.
3. **Every ad carries one scene, and scenes differ across audiences.** The delivery-plan reply gains `scene` per ad (one
   sentence, 6–60 chars, the concrete moment the copy happens in); ads with different `audience` keys inside one campaign
   must have different scenes, else the plan is rejected like any other invalid reply. The scene is stored on `ads_ad.scene`,
   handed to the workbench brief as `request.scene`, and the copy prompt says the copy must happen in that scene.
4. **The calendar reaches the copy.** The ads side hands `request.calendar_note` (program lines from `calendar_tw.events_between`
   for the group's or campaign's window) to the brief; `brief_text` prints it with the same "only if it really affects the buyer"
   caveat the plan/strategy prompts carry.
5. **The starting point counts closed campaigns.** 【這個品牌的起點】 adds 「已結案 N 期；最近一期「name」每筆 X 對上限 Y，
   結果 …」 and marks the wizard answer as an initial value once N ≥ 1.
6. **One clock.** `month_budget._fresh` and `external_repository`'s `observed_at` use `app.core.db.now_utc()` (the drill clock
   already rebinds that name); no SQL `now()` or bare `datetime.now` on those two paths.

# Decisions
User-confirmed (dig 2026-09-29, drill-7 report §4 red + §6):
- Root cause: the coordinate-choosing model (`plan.py`) received no learning at all, strategy only the campaign sentence.
  Fix = program-tallied scoreboard into both prompts + per-ad grade learnings at closeout (report #1 #2).
- Scene per audience group and calendar into hook/copy (report #3 #4); starting point with closed periods (#5); one clock (#17).
- No frontend page changes in this feature (F40 takes E/D/F/#10/#18 after its own dig + prototype).
Agent choices (reversible):
- Per-ad grades reuse `period_grades.grade_period(conn, org, brand, start, end)` filtered to the closing campaign (same ruler
  and sample gate as the month review) — no second grading rule. Entity → ad through `ads_ad.external_id = ads_external_entity.native_id`
  (the `_PERF_JOIN` mapping).
- Coordinate learnings are a third `source_track` value `coordinate` (column is free text, default 'ads'); strategy's
  `_learnings_section` keeps reading only `ads`, so the sentence list does not grow. `applicability_scope` format:
  `coord；grade=<grade>；audience=<k>；pain=<k>；angle=<k>；hook=<k>；proof=<k>；offer=<k>；format=<k>`; `source_cycle_id =
  <campaign_id>:<ad_id>` (idempotent per ad); `confidence='observed'`; text carries the numbers (nothing promotes on it).
- The scoreboard bias is a prompt rule, not a program gate: the program builds the table, the model chooses (CLAUDE.md
  「程式整理，LLM 判斷」). Drill 8 measures whether it is followed; a gate is the fallback if it is not.
- `scene` is a nullable `ads_ad` column (migration), not a key inside `coordinates_snapshot_json` (that json is the vocabulary
  snapshot). Scene distinctness is exact-string over ads whose `audience` keys differ; same audience may share a scene.
- Scripted provider reply for `ads_delivery_plan` (`app/llm/providers.py`, e2e backend) gains a `scene` per ad.
- Calendar note = `calendar_tw.events_between` lines for the window in the same `- MM/DD～MM/DD name（kind）` wording as
  `prompt_section`; empty window → key omitted → brief prints nothing.
- `_available_roles` unchanged (retarget still needs a real audience source, not just a closed campaign).
Unresolved: none blocking.
