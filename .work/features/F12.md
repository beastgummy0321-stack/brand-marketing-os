# Outcome

一般使用者沿現有逐步流程完成工作，看到必要摘要與下一步；熟手在同頁按項目展開設定。素材比較可選，普通品牌不見內部驗收工具。資料真實性、模組隔離與既有生成能力保持。

# Decisions

- User-confirmed：採用本輪 dig 總結；Full auto 最後再做；現階段只做第二／三層。比較可選，模擬回收僅內部。先規劃，批准具體計畫前不執行。
- User-confirmed：遵循集裝箱邊界與公開接口；平台／產業／品牌中立；程式整理數據，LLM 只作必要判斷；最小變更，不擴張。
- Agent choice：本輪零新增 LLM 呼叫、零新平台 adapter、零 schema／依賴；沿用原生 SQL、context_json、既有 API client 及 UI 元件。比較 settings 只由 ads 擁有，不建通用參數引擎。
- 條件式閱讀：共用 UI 規則看 docs/design-system.md §F12；投放／比較看 docs/architecture/ads.md §6.8；素材看 docs/architecture/workbench.md §5.15；邊界看 ARCHITECTURE.md §1–3；驗證看 docs/verification.md。
- 7 票按 after 排依賴；不為前後端形式拆票。共享契約已在 §6.8 定案。沒有未解產品決策；若發現新分歧，依票上 Blocked if 回報。
- F07 仍開啟且人工驗收未完成；不修改其生成品質、主力／探索、使用者選圖與複製流程，只改詳情的閱讀位置。

# Acceptance

1. 一般流程不展開進階即可找到所有必要操作；商品、目標、預算與日期可理解可修改。
2. 比較選用，缺對照不擋主流程；一般摘要與進階有效設定一致；參數保存真實影響判讀，已確認快照與重確認有保護。
3. 收合不丟草稿、dirty 不被刷新蓋掉、缺漏可定位；鍵盤與窄版能完成。
4. 素材推薦／選定／完成及必要複製仍可用；提示詞不冒充成品。內部生成細節收合。
5. 普通品牌不出現模擬回收／並列演練入口；已隔離測試品牌維持驗收鏈，伺服器隔離不放寬。
6. 未追蹤、零、預估、實際、示意、保守／樂觀與未上線狀態不混淆。
7. 既有模組／租戶／費用閘門不弱化；沒有新增 LLM／外部操作，未支援平台不冒充可用。
8. manifest 驗證及整合 UI 證據完成後，再請使用者判斷資訊主次。規劃 validate 不代表產品測試通過。
