# Outcome
Drill ruler dimensions 7／8 (feedback and honest numbers). The last four defect generators of the 2026-10-04 audit
(`docs/backlog/audit-2026-10-04/README.md` W15, W16, W18, W19; decisions 10, 11, 14, all 1–14 user-confirmed 2026-10-04)
disappear, each with a machine check that goes red if the pattern returns:
1. **W15 one translator, one reason, one href shape** — `lib/http.ts` is the only code that turns an HTTP answer (network
   failure, 401, 4xx/5xx envelope) into a sentence or an error code, and the only way to the login page; every greyed-out
   control says why (`Button` is disabled *because* it has a reason or is busy); served in-app links have one shape and ads
   campaign routes have one builder; a save says 「已儲存」 and a copy says 「已複製」.
2. **W16 numbers carry their basis** — every ROAS and derived money figure is named by its basis, the basis table lives once
   in the backend and one `Figure` piece prints value + basis; unknown never prints as 0; currencies are never summed together;
   the three numbers the browser rebuilt (pace, closeout sentence, ad window spend) are served.
3. **W18 the brand wizard remembers** — step in `?step=`, unsaved fields in the one step-draft store, like product onboarding.
4. **W19 platform literals ratchet** — the shared ads core cannot gain a new Meta word, level name or `app.meta` import; today's
   ones are listed and may only shrink (the full adapter move is a later feature, decision 10).
