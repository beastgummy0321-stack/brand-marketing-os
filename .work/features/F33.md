# Outcome
The strategy AI receives, as program-organised facts, where the brand starts from (asked-about advertising history, spend-history source, buyers, click pool, pixel) and which roles are available; a brand with no retargeting source never gets a 再行銷 group it cannot launch. A static Taiwan calendar (national holidays, makeup workdays, exam seasons, commerce peaks; 2026–2027) exists as program data, and the strategy and delivery-plan prompts receive only the entries overlapping the campaign period, with an explicit "no calendar for this year" note outside the table.

# Decisions
**User rulings** (2026-09-27, dig of drill-6 red group 2):
- 1A: the program lists the available roles and the AI allocates within them; with no retargeting source at all, `retarget` is not offered.
- 2A: the calendar covers national holidays + exam seasons + commerce peaks in one static table.
- Standing: program organises, LLM judges (CLAUDE.md); nothing writes to a platform; no issue asks the user to run real ads.

**Root causes** (verified in code at `4e40e3e0`):
- `strategy.generate` (`strategy.py:296-334`) sends goal, cap, period, facts, products, learnings and budget scenarios; the program already knows `brand.advertising_history` (`has_history`/`none`/NULL), `budget_history` source, external clicks/purchases (`ads_external_daily`), loop purchases (`ads_outcome_daily`) and cached pixels, but none reaches the prompt. The only hint is the scenario header's `mode=cold_start`.
- `strategy.md` shows a fixed new 50 / retarget 30 / explore 20 example; the model mirrors it. `plan.py:138` turns every allocated role into a group, even at 0%. A retarget group then needs a Meta 受眾 ID at handoff (`manual_settings.py:71`) that a no-history brand cannot have. Meta reads exist for pixels only (`meta/repository.py:978`), not custom audiences.
- No calendar data exists anywhere; 「節慶額度」 (`month_budget.py:18`, `MonthlyBudgetPanel.tsx:54`) is a label.

**Agent choices** (reversible):
- Retarget source = any of: `advertising_history == "has_history"`, external clicks in the last 90 days > 0, any purchases (loop or external). Program rule, one function in `strategy.py`; no thresholds beyond > 0 (the AI weighs sizes).
- The ads module may not import `app.orders` (`may_depend_on: ["workbench"]`), so buyers come from ads-owned tables only; the prompt says 「訂單資料不在這裡」 rather than guessing.
- The calendar lives in `app/ads/calendar_tw.py` as a literal table with `source` per row; commerce peaks are conventions (`source: "convention"`). Years outside the table produce a note, never an empty section that reads as "nothing happens".
- The e2e scripted provider becomes prompt-aware for `ads_strategy` and `ads_delivery_plan` (reads the roles the prompt offers/adopted) so a fresh e2e brand keeps working with two roles.

## Contracts (every issue uses exactly these names)
- **P. Available roles in the strategy prompt (F33-I01 writes, F33-I00 reads).** The strategy prompt contains a section whose first line is exactly `【可用角色】` and whose second line lists the role keys joined by `、` in the fixed order `new、retarget、explore` minus the unavailable ones (e.g. `new、explore`). `strategy._validate_reply` refuses a reply naming a role outside that set (`strategy_failed`, nothing saved). The delivery-plan prompt's existing adopted-allocation lines `- <role>（<label>）：<pct>%…` are unchanged; the scripted provider derives the delivery-plan roles from them.
- **Q. Calendar entries (F33-I02).** `calendar_tw.events_between(start: date, end: date) -> list[dict]` returns rows `{start, end, name, kind, note}` with `kind in {"holiday","makeup_workday","exam","commerce"}` overlapping the range, ordered by start. `calendar_tw.coverage_note(start, end) -> str | None` returns a sentence when any year in the range is outside the table. The prompt section header is `【投放期間內的行事曆】`.

# Acceptance
- A brand with no retargeting source: prompt lists `new、explore` only and states the starting-point facts; a reply with `retarget` is refused. A brand with `advertising_history='has_history'` or external clicks: `retarget` offered.
- Existing strategy tests still pass with their fixture brand made eligible (or the fixture reply reduced); the scripted e2e cold-start path yields one group per available role.
- Calendar: a period over 2026-09-26…10-16 yields 教師節／中秋、國慶 and the exam-season row; a 2028 period yields the coverage note; both prompts contain the section.
