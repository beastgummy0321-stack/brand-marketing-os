# Acceptance

1. 暫停與無花費活動可列出、按原生鍵納入；跨分頁及重試冪等，品牌／帳號隔離。
2. 原生父子、預算位置／類型／幣別、日期與狀態保真；資料缺漏、失敗與更新時間可見。
   匯入不被自動結案，不因無 groups 被要求重建策略。
3. 圖片／影片批次保存、預覽、重開可見；同檔去重不跨品牌，損毀／超限不吃掉其他成功檔。
4. 每件必用有安排或待處理原因，原文沿用、缺項補齊；未知內容與未驗證承諾不變成事實。
   按批補齊、成功重用、費用預留與輸出上限能阻止重複或超額呼叫。
5. 確認、回報上架、讀回廣告存在與核對素材版本分開；修改撤銷本版確認、保留歷史。
   版本混用／舊歷史／無法驗證素材時不錯配成效，但可看廣告原始數據。
6. 模型假資料／平台假回應整合證明全路徑與零平台寫入；實際 token 能讀哪些資料另記結果，
   token／平台不可用不能以假回應替代實讀證據。無需實投。
7. 新建與既有活動使用同一工作區；1024／1920 含 empty/loading/error/heavy 狀態可操作。
   所有 repo 必要檢查、runtime 與人工判斷分別記錄，不用佇列 done 代替 Feature close。
