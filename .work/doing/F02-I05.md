# Objective

`ARCHITECTURE.md` §5.11: in-site image generation is a **reserved port, not a feature**. This issue
adds the seat and the data the 圖片 tab needs to render prompt cards today and images later — no
provider, no key, no HTTP client, no cost, no new dependency. Money-adjacent, so it is reviewed:
the rule being protected is that nothing here can ever spend.

# Done

- `app/workbench/image_port.py` — under 60 lines, private to the package: one `connected() -> bool`
  returning `False`, and one `generate(...)` that raises `NotImplementedError("image_port_not_
  connected")`. One docstring says what a real adapter would have to provide (a provider name, a
  job id, a storage key — the four columns `workbench_output` already reserves) and that connecting
  one is a separate feature with its own approval, because it spends money. No registry, no config
  value, no environment variable, no abstract base class with one implementation.
- `SetDetail.image_generation` becomes `{"connected": image_port.connected(), "reason": "席位保留"}`
  — phrased as a seat that is reserved, never as a refusal, and never as 「要看到真結果得讓活動跑」
  or any other live-delivery instruction. **This string lives here and nowhere else**: F02-I09
  renders `image_generation.reason` and is verified to contain no copy of it
  (`.work/features/F02.md` Decisions).
- Each `image_prompt` version in `SetDetail` carries `prompt_cards`: an ordered list of
  `{"label": "① 主圖", "text": …}` / `{"label": "② 變體", "text": …}` (探索模式: `③ 探索` then
  `② 變體`) read straight out of the round's rendered `body_json` — the renderer in `prompts.py`
  does not change and is not touched. `copy_all` is not a field: the frontend joins the cards.
- Versions of the other parts are untouched.
- `app/tests/test_workbench_image_port.py` (new, the falsifier): `connected()` is `False`;
  `generate()` raises; `SetDetail` for a set with one image-prompt round exposes the two cards in
  order with the same text `prompts.py` rendered; a set with no image round exposes an empty list
  and product state 未生成.

# Verify

The commands above — the last one is the cheap guard that no key, no HTTP client and no growth
sneaked into the port.

# Blocked if

The rendered prompt pair is not reachable from `body_json` without re-rendering. Report it; do not
re-render in the read path.
