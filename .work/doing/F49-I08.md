# Objective
The ads home and the all-campaigns list print the served lifecycle, the served decision list and the served verification words
(feature Contracts L, Q, B; frontend-ads F6, F13; drill-11 R4 H3／Q3, R3 E5, N3, Q4). Today an ended campaign reads 「在投 6 則」
with a cleanup card 「每天省約 730 元」, the board keeps its own kind list, 「第 N 件」 is recounted on the settle page, a just-launched
campaign says 「在投 0 則・每日未知」 with no read time, and the home says 「還沒有活動」 over three closed campaigns.

# Done
1. Campaign words: `patterns/campaignWords.ts` — `campaignWord(c)` returns the served `c.lifecycle.label` (keep the optional second
   argument so callers outside this issue compile unchanged); `CAMPAIGN_WORD` goes; `closedWord` takes the served running count;
   `nativeStatusWord` stays until F49-I14 (its last caller). Home rows (`CampaignRows`) print `lifecycle.label` and, for live
   ones, 「在投 {running.count} 則」 with 「上次讀取 M/D HH:MM」 when `running.stale` (and 「另有 {unknown} 則狀態不明」 when present);
   an ended row shows 「已結束・待結案」 and its closeout action. The empty state uses `closed_this_month`
   (「這個月沒有進行中的活動・已結案 N 個」 linking to all campaigns).
2. Board: `home/status.ts` reads `decision`／`position`／`decisions` — `DECISION_ORDER` and the settle splice go; the board lists
   open decision rows by `position`, then done ones; `decisionPosition` returns the served `{pos: position, total:
   decisions.open}`. `QueueRow`／`TodayDecisions` render the `closeout` kind (「結案這一期 →」 to its `action_url`) and print
   `proposal.verification_label` instead of the local verification switch (`proposalAction` keeps building hrefs; its label for
   verification states comes from the payload). `settle/SettlePage.tsx` prints the settle row's served `position`／`decisions.open`
   (`ORDER_BEFORE_SETTLE` goes).
3. All campaigns: `ENDED_STATUSES` goes; filters and counts use `lifecycle.state` (已結束 and 已結案 are separate filters).
4. Month-budget return (Q4): when the home opens with `?budget=edit&return=<path>` (the link F49-I11 builds), after the budget
   editor saves or closes the area offers 「← 回到剛才的核准」 to `<path>` (`return` accepted only when it starts with
   `/brands/{brandId}/ads/`).
5. `oneRuler.test.ts`: delete every allowlist entry that names F49-I08 (`home/status.ts`, `settle/SettlePage.tsx`,
   `AllCampaignsPage.tsx`, the lifecycle entry of `patterns/campaignWords.ts`, any home file the lifecycle scan listed) — the
   scans pass on them and the stale-entry test requires it. Entries naming other issues stay.
6. Tests: an ended campaign row reads 已結束・待結案 with a closeout card and no 在投; the board order and count come from
