# Objective

The 檔期規劃 half of the same hole F02-I18 fixes for 自由創作: `schedule_tree()` hands over
`context = {"product_ids": [...]}` only, so `workbench_pack.context_json` never carries the
platform. Every dispatched pack therefore shows 平台 「—」 in the 生成設定 table (ARCHITECTURE.md
§5.13) and `meta.platform`／`meta.goal` null on the pack page — the row reference image 3 fills
with 「Meta 廣告」 on a dispatched set. `context` is already a §5.4 contract field; this fills it.

`legacy_migration: true` is bookkeeping, not a migration: the only falsifier for this dispatch
lives in `app/tests/test_schedule.py`, one of the thirteen seam files ARCHITECTURE.md §2 lists as
legacy. Do not restructure that file, do not move anything out of legacy — add assertions to the
dispatch test that is already there.

# Done

- `app/schedule/jobs.py::schedule_tree` — the `submit_pack` call's `context` gains two keys and
  nothing else changes:
  - `"platform"`: `platform_label`, already computed a few lines above for `_tree_params_text`.
  - `"goal"`: the objective label from the `data` dict already loaded there (`data["objectives"]`,
    matched on `platform` ＋ `plan_scope["objective"]`), using the same `next(..., default)` shape
    as `platform_label` so an unknown value falls back to the raw string and never raises.
- No change to the sets, to `required_outputs`, to `request`, or to the one-pack-per-tree shape.

# Verify

The commands above. Falsifier: `app/tests/test_schedule.py::TreeDispatchRequestTest` (the existing
dispatch test with its fake provider and worker pass) also reads the `workbench_pack` row and
asserts `context_json["platform"]` is the platform **label** and `context_json["goal"]` the
objective label of the chosen plan — not null, not the raw id. Red proof: drop either key from
`jobs.py` and the assertion fails.

# Blocked if

The objective label needs anything `schedule_tree` does not already have in scope (a second
`_load_platform_data()` call, a new read of the plan row). Then stop and report — the fallback
is to ship `platform` alone rather than to widen the job.
