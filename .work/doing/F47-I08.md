# Objective
The campaign overview tells "on the platform, not spending yet" from "spending" from "closed"; a campaign has one status word
everywhere; a failed account read can be re-read; the top bar's anomaly count is the connections page's own (feature Contracts
E and H; drill-10 S3, Q4, R6, drill-9 #4/#5, §4.3 status-word / 「已結案仍寫在投」 / raw ISO / ACTIVE).

# Done
1. `workspace_reads.workspace` adds `delivery` per Contract E. Counter-examples settled in the contract: draft → `null`; closed →
   `null`; spend rows present but all 0 → `waiting`; never synced since launch → `waiting` (the card's sentence stays true);
   the spend read failed → `null` (screen keeps today's 「未知」). Spend comes from the sync table (the only performance source,
   F37) for this campaign, any day.
2. `OverviewBody` (`LiveOverview`): `waiting` → the next-step card reads 「已上架，等平台開始投放」 + 「平台開始花錢後，下次同步
   （HH:MM）會出現第一筆數字。」 (reuse the existing ✓ card shape and `next_sync_at`), money cells 「還沒開始花」. A closed
   campaign never says 「在投」: the cell reads 「已結案・平台上還開著 N 則」 when `active_ads > 0`, else 「已結案」; the ruler
   heading drops 「在投」 for closed campaigns.
3. One word per campaign: `patterns/campaignWords.ts` (new) maps the campaign's own status / stage to its one word and a platform
   `native_status` to Chinese (ACTIVE 開啟中, PAUSED 已暫停, DELETED 已刪除, ARCHIVED 已封存, anything else 「平台狀態不明」);
   `WorkspaceHead`, home `CampaignRows`, `AllCampaignsPage` and `ExistingCampaignDialog` use it. The dialog shows times with
   the existing date formatter (no ISO) and marks rows already in a workspace 「已在工作區」.
4. Connections (Contract H): `ad_account` sources carry `reread`; a failed source's note is reason + gap; the page shows
   「重新讀取」 on such rows, posting `…/existing-campaigns/refresh` with `reread`, then polls the returned job and re-reads
   the page (a refused refresh shows its sentence).
5. Top bar (Q4): `status_summary` returns `attention: {count, note}` from `connections.get_connections` instead of
   `failing_campaigns`; `Topbar` reads 「N 個資料來源要處理」 with `note` as its title; a draft campaign that was never on a
   platform is never counted (the connections rule already ignores it).
6. Tests: `delivery` for draft / waiting (no rows, zero rows) / live / closed / read failure; overview strings per state; closed
   with open platform ads; `reread` present for failed / missing / never and absent for ok / auth_expired; top bar count equals
   the page's `attention_count`; native status words.
