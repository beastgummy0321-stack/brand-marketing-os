# Objective
Make the complete close operation atomic and retry-safe using the existing transaction and lock.

# Done
Implement S3 at the ads-owned boundary; direct job/test callers receive the same transaction semantics.
Fresh closed-state check occurs after locking. Internal commits defer, each learning track/status/queue
resolution shares rollback, repeat returns original identity. Keep simulation recovery and tenant scope.
Do not change global commit behavior or invent a second idempotency ledger.

# Verify
Temporary tests inject failures after learning and status/queue work, check retained preimage/retry and
wrong-tenant rejection. I05 adds real PostgreSQL/HTTP concurrency proof; MemoryConn success is insufficient.
Preserve any independently durable cost/error receipt. Inspect nested atomic behavior and lock lifetime.

# Scope notes
The operation owns the boundary, so routes/payloads do not change. Import-radius closeout consumers are
included for affected fixtures only; no requirement to reread/rewrite every adjacent test. Route-only
consumers remain unchanged. Final full-suite integration checks their existing behavior.

# Blocked if
Existing Conn/ConnProxy cannot preserve the required boundary, or a close path requires external paid work
inside it. Show the exact boundary gap and revise scope before changing shared primitives or migrations.
