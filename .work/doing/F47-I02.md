# Objective
One way to turn a failed response into a sentence, and one piece each for copy feedback, disabled reasons, error-clears-on-edit
and the close label (feature Contract B). Today several shell API clients throw 「儲存失敗（狀態碼 400）」 while the server sent a
sentence (drill-10 V2; `controls/a-06-ai-limit-0-400.png`, `a-08-rulecard-0-400.png`, `faults/F6-*.png`), copy buttons give no
visible feedback (publish step 2, prompts, invite link), red errors stay after the field is fixed, and the login page shows
「Invalid login credentials」.

# Done
1. `lib/http.ts`: a `throwIfFailed(res, fallback)` (name is the worker's) built on `errorMessageFromResponse`, also reading the
   rule-card `field_errors` body (first message, or each field's message where the caller maps them). `api.ts`, `inboxApi.ts`,
   `jobsApi.ts`, `libraryApi.ts`, `settingsApi.ts`, `useAuthedImage.ts` use it; other `lib/*.ts` already pass their fallback to
   the helper and are not edited.
2. `lib/feedbackGuards.test.ts` (new): fails when a `src/lib/*.ts` file throws a 「（狀態碼 …）」 message not routed through the
   helper, and when `navigator.clipboard` appears in `src/**` outside `components/layout/CopyIconButton.tsx` and
   `components/ads/patterns/CopyField.tsx`. Prove each guard red once on a scratch edit, then remove the edit.
3. Copy: `CopyIconButton` and `CopyField` show the text 「已複製」 for 2 s after success and 「請手動選取複製」 on failure (no
   optimistic state). The hand-rolled copies in `HandoffPage`, `PlatformButton`, `MaterialTaskEditor` and `products/panels/
   HandoffPanel` move onto one of the two.
4. `Button` gains optional `disabledReason`: while disabled and set, one muted sentence renders next to the button and as its
   accessible description. No call site changes here (F47-I03 / I06 adopt it).
5. `useFormSubmit`: its error clears as soon as the form reports a value change (worker's mechanism; document it in the hook).
6. Dialog close: visible and screen-reader label 「關閉」 (both places in `ui/dialog.tsx`).
7. Login: Supabase auth errors map to Chinese (wrong password 「帳號或密碼不對」, unconfirmed e-mail, rate limit, unknown →
   「登入失敗，請稍後再試」) and the message clears when the mode switches; a 401 redirect marks the session as expired so the
   login page says 「登入已過期，請重新登入」; after signing in the user returns to the remembered page (`takePendingPath`) — add
   a test and fix only if it does not.
8. Phone width (found at F45-I08 review, `.harness/scratch/F45-I08/built-assets-375.png`): at < 768px the app shell keeps its
   desktop sidebar open, leaving ~77px of content and a ~582px-wide page. Below `md` the sidebar collapses behind the existing
   collapse control (closed by default, opens as an overlay), the top bar fits 375px without horizontal scroll, and the page
   content gets the full width. Before/after pair at 375px on the 素材 tab.
9. Tests: helper reads `{"error": "…"}`, `{"error": {"message"}}`, `{"detail"}`, `field_errors`, and non-JSON → fallback;
   settings save shows the server sentence; copy shows 「已複製」; login error in Chinese.
