# Objective
The `bundle` offer reads 「組合優惠」 (feature outcome 5): a multi-unit price (三盒價) is a `bundle` since F43 and is not a 加贈.

# Done
1. `app/core/vocab.py` `OFFER_LABELS["bundle"]` and the `offer` seed row in `app/schedule/repository.py` → 「組合優惠」.
2. Migration: `UPDATE brand_coordinate SET label='組合優惠', updated_at=now() WHERE dimension='offer' AND key='bundle' AND
   label='組合加贈';` (brands that renamed it keep theirs).
3. Tests asserting the old label through these two sources follow the new one. Literal fixtures that only carry a label string
   (frontend tests, `app/tests/fixtures/workbench/*.json`) stay.
