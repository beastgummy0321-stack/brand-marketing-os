# Objective
One read convention in which a failed read stays failed, and one exit on every step flow (Feature Contract K; ruling item 5). This removes the class of "the screen says nothing is there because the request failed"; it does not redesign any screen.

# Done
1. `frontend/src/lib/useApiRead.ts` (Contract K shape, aborts on unmount and on dependency change, `reload` re-runs). Every site in Feature Evidence "Failed-read-as-empty" uses it or an equivalent explicit error state: the failure renders `ReadFailed` (ads pages) or the page's existing error line with 重試 (DeliveryTab, workbench FreeJobPage), never an empty list, a hidden block or a silent no-op. A block that fails does not blank the rest of the page (§1.7 item 9).
2. Home: the 「今天要決定」 count and the decision cards come from the same queue read; a failed queue read shows the failed state, never 「都處理完了」 (drill-5 item 7).
3. Step-flow exit: `ActionBar exit={{label: "先不要，回投放中心", to: "/brands/:b/ads"}}` on every open decision step (confirm, handoff before approval, cleanup proposal, review prepare/copy/material/evidence); not shown once the decision is approved/rejected (prototype `S.exit`).
4. `flow/ConfirmPage.tsx` is 783 lines: extract into `flow/confirmParts.tsx` before adding code (cap 800).
5. Tests: for each site, a failing request asserts the failure state and 重試 re-requests; the home count and cards agree under a slow and a failed queue read; the exit renders on an open step and not on an approved one.
