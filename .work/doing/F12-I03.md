# Objective

成效優先與可選素材比較。依 ads §6.8，把成果放在比較和內部工具之前，比較不成為主流程待辦。

# Done

- 未使用比較時只顯示「素材比較（選用）」入口且不請求完整提案；打開不等於確認。已有確認保留簡短狀態與展開入口。
- 正常成效顯示主要成果、資料狀態、白話結論；詳細每日表、次要指標與公式收合，保守／樂觀值與未追蹤意義仍清楚。
- 比較一般卡顯示對象、唯一變因、觀察期間、結果；進階依 API 編輯／重設參數並顯示有效值、來源、範圍、過期。ID／公式／完整紀錄在詳情。
- 缺對照僅在使用比較時顯示解法，不攔其他流程；人工實際條件核對改為具體簡短問題，仍須明確勾選，不自動替人認證。
- 模擬回收仅依目前已隔離的 campaign.simulation_mode 顯示在內部進階區；普通品牌不 mount、不讀取回收端點。初次本機測試品牌由內部驗收 fixture/API 依原 eligibility 與明確 isolation 確認建立，不在普通 UI 提供轉換測試品牌入口。不把新建模擬權限開放到正式環境。
- 提前結案保留可找到的選用操作，重要後果與來源不藏在進階。

# Verify

未啟用比較可走主流程、初次展開不確認、已有／過期／無對照／loading／error；模擬與普通品牌入口隔離；修改門檻正確提交與錯誤保留。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
