# Objective
The regenerate button says why it is not clickable (drill-7 #16 「再生成第一次按常沒反應」). Root cause (F40 Evidence): the disabled
state reads the brief-level `set.generation.status`, shared by every part of the set, so while 文案 is generating the 圖片 tab's button is
disabled with a bare 生成中… and a click does nothing. No status-model change (F40 agent choice).

# Done
1. `SetStudioPage.tsx`: when `generating` is true because of another part (`set.generation.part` if the payload carries it, else the
   running part derived from which product is not 已選定 and has a queued/running state; if neither is knowable, say 「另一個部分」),
   the button label becomes 「正在生成〈part label〉，完成後才能再生成」 and keeps `disabled`; when this part itself is running the label stays
   「生成中…」. Tooltip/`aria-label` carries the same sentence.
2. Tests: another part running → the label names it; own part running → 「生成中…」; idle → 「再生成 N 張」.
