# Done（只做這三項）

## 1. 表格在 1280／1024 不准擠爛（退回的真正原因）

`.table-surface` 有 `overflow-x: auto`（`frontend/src/styles/tokens.css:101`），但表格是
`<table className="w-full …">` ——auto layout 的表格只會縮到容器寬，那條 `overflow-x` 永遠不會
觸發。實測（1280、1024 兩個寬度都拍過）：日期斷成「2026/01/」＋「11」、「由 王小明 建」＋「立」、
目標斷成「品牌認」＋「知」、「未追蹤」在 1024 直接一個字一行。1920 的版面跟設計圖一致，
所以版面本身是對的，缺的只是最小寬度。

做法（挑最小的，不要重排版面）：

- 表格加最小寬度，例如 `<table className="w-full min-w-[1100px] text-left text-sm">`，
  讓 1280／1024 時在 `.table-surface` 自己的捲動區裡橫捲，而不是把欄位擠爛。
  數字自己在 1280／1024 量過再定（1100 是估的，準則是：日期欄一行放得下
  `2026/01/11` 與 `由 王小明 建立`，目標欄一行放得下「品牌認知」）。
- 「建立時間」欄（`th` 與 `td`）、以及預算進度的百分比字（`未追蹤`／`未設定`／`83%`）
  加 `whitespace-nowrap`。**判斷句那一欄不要 nowrap**——它本來就該換行。
- 不准為了這件事去改 `tokens.css`、`patterns/**` 或版面元件（在 `do_not_touch` 裡）。
