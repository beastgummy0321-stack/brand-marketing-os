# Done

這一頁維持**純 props 元件**（不 fetch、沒有 loading／error 狀態，F03-I23 的決定）：需要的東西
`CampaignDetail` 都有，包含 F04-I08 新加的 `judgment` 與 `action_lines`。

版面由上而下：

1. **`KpiStrip`** 三格（圖 6 上方那一條）：
   | label | value | caption |
   |---|---|---|
   | Campaign 目標 | `objective` | `success_target !== null` → `{指標中文} 目標 {格式化的值}`；否則 「未設定成功條件」 |
   | 總預算 | `t.total !== null ? formatCurrency(t.total) : "尚未設定"`（`t = currentBudgetTotal(c)`，既有函式） | `t.total !== null` → `日預算 {…}／天 × {t.days} 天`；否則 「還沒設定投放起訖日」 |
   | 已花費 | `hasOutcome ? formatCurrency(c.outcome.spend) : "還沒有成效資料"` | `hasOutcome` → `佔總預算 {pct}%・平台回報`（`t.total` 為 null 時改「累計花費・平台回報」）；否則 「發布後才會有花費資料」 |
   `hasOutcome` 沿用這個檔案現有的定義。**「採用時的計畫」那一格移除**（它跟總預算的差額在投放
   結構分頁已經有一整張卡，這裡只留三格，圖 6 也是三格）；`budget_planned` 改成總預算那一格
   caption 的一部分：已採用時在 caption 末尾接 `・採用情境 {formatCurrency(budget_planned)}`。
2. **`JudgmentBand`**：`sentence = c.judgment.text`、`facts = c.judgment.detail`，
   icon 依 `tone`（good `TrendingUp`／warn `AlertTriangle`／neutral `Clock`）。
   **不要**在前端重寫任何判斷句。
3. 兩欄 grid（左 2/3、右 1/3；1024 時右欄降到下面）：
   - 左欄：**`ReservedSlotCard`**：title 「行銷駕駛艙為你執行中」、description

     tag 「自動執行接上後開放」。（圖 6 左邊那張大卡的位置，但**不畫**吉祥物與「MarketingOS 正在：」
