# Objective
Asset confirmation judges copy against the ad's sell-way and offer coordinate (feature outcome 3). Today
`asset_suggestion_policy.violations` passes product `None`, so the sell-way's own 「優惠價／原價」 is refused — the 4 stuck drill-9
slots.

# Done
1. `asset_suggestions.snapshot`: `campaign` gains `sell_way` (`sell_way.of_campaign`); each placement gains `ad_id`, and for a
   placement with an ad: `sell_way` (`sell_way.of_ad`), `offer_key`, `offer_label` (the ad's offer coordinate; label from its
   coordinate snapshot). A library placement (`ad_id` NULL) uses the campaign's sell-way and no offer key.
2. `policy.violations(...)` takes the placement's sell-way, offer key and label and returns Contract C details (kind `copy`):
   unbacked with the sell-way (`validate_claims(…, sell_way, copy)`) → the unbacked sentence with those terms; backed by the
   sell-way but not under the ad's offer coordinate (`…, offer_key=<key>`) → the mismatch sentence; forbidden claim and the
   untraceable-generated-copy sentences keep their text. `statutory_note` passes the sell-way too.
3. `policy.source_rows` also returns the approved claims of the sell-way's knowledge products
   (`bi_repo.knowledge_product_ids` + `list_claims_for_product`, each once); their ids join the batch's `knowledge_ids`.
4. `_result` collects details for every problem it raises (kinds: copy fields / claims → `copy`; `media_error` → `file`; preview not
   made yet → `wait`; goal, dates, budget, purpose → `campaign`) and returns `pending_details` beside `pending_reasons`
   (= the details' texts, same order, deduplicated). `confirm` / `confirm_manual` return both on refusal.
5. `assets.py` (`_ad_set`, `dispatch_pack`) and `learning.py` (`_needs_revalidation`) read the sell-way through `app/ads/sell_way.py`.
6. Tests (fake the workbench facade or use real brand rows; never import workbench internals — the container gate refuses it):
   a slot copy with the sell-way's 「優惠價 NT$999（原價 NT$1,500）」 on an `offer=bundle` ad confirms; the same copy on an
   `offer=none` ad is refused with the mismatch sentence and terms; 「加贈」 on a sell-way without that offer → the unbacked
   sentence; a library placement is judged with the campaign's sell-way; details kinds for media error / not-ready preview.
