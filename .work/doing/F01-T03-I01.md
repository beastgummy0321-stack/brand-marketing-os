# Done — wording that must hold (acceptance; the discarded attempt broke each of these)

These four rules apply to `image_prompt.md` and `image-prompt-template.md` alike. Every sentence in
either file that touches headlines, on-image text, audience or numbers must agree with them; state
each rule once and do not restate it differently elsewhere in the same file.

1. **Adopted headlines are an optional hint, never a source.** Today `image_prompt.md` L10-13 says the
   brief's adopted headlines are attached 「供圖上文字取用」, and L28 says `text` is 「逐字取自附上的標題
   原文」; today `image-prompt-template.md` L27, L57 and L72 say the same. All of that goes. The new
   wording: the worksheet *may* contain one line 「可用的大標（可用可不用）」 (F01-T03-I02 puts it
   there); the model may use it, adapt it or ignore it; when it is absent the model still returns a
   complete reply. No sentence may say or imply that `headline`, `subhead` or `on_image_line` is
   taken, chosen, picked or copied from adopted headlines or 「附上的標題」, in either mode
   (ARCHITECTURE.md §5.7: "an image prompt can run before any copy is adopted").
2. **探索模式 has no coordinates.** A manual brief is product + parts + free text (§5.4); the seven
   coordinates arrive only from a schedule node. Describe the inputs per mode, separately:
   - 變體模式 reads: 風格, 商品, 受眾／痛點, 這則的訴求 (切角 + 標題公式), 可用字句 (may be absent),
     brand context, optional headline hint.
   - 探索模式 reads: 風格, 商品, 目的與對象 (the user's free text, may be 「未指定」), 可用字句 (may be
     absent), brand context, N, optional headline hint. The angle for each item comes from
     `creative-matrix.md` §1; who appears comes from 目的與對象 and brand context.
   No sentence may list 受眾, 痛點, 切角 or 標題公式 coordinates as an input of 探索模式, and no
   intro paragraph may describe "the brief's coordinates" as if both modes had them.
3. **On-image wording is written by the model, not bounded by 可用字句.** `headline`, `subhead` and
   each `on_image_line` are new copy the model writes for this image. 可用字句 is not a whitelist of
   allowed wording and the model is not told to choose on-image text from it. The only bound is
   rule 4.
4. **Numbers (and factual claims such as price, discount, spec, certification) come from 可用字句 or
   the brand context.** A number on the image must appear verbatim in the 可用字句 lines **or** in the
   compiled brand context; a number found in neither may not appear. When the 可用字句 line is absent,
   numbers that appear verbatim in the brand context are still allowed. This is exactly what
   F01-T03-I02's `check_image_prompt` enforces (`quotable_text` = promotion-note lines + compiled brand
   context). No sentence may say "no 可用字句 → no numbers"; the only true empty case is "neither
   source contains it". In `image-prompt-template.md` this rule lives in one place (the section that
   today is §4) and nowhere else contradicts it.
