# Objective

Runs after F02-I08 and before F02-I10 — strict chain over the same three frontend paths
(F02 Decisions). F02-I05 must be in first: the prompt cards and the seat line come from its payload.

Screen 3, the 素材組 studio — reference image 3, 1:1 at 1672px. Where the work actually happens:
generate, look at versions, 選定, finish the set. Tabs are the set's required 產物類型 in dispatch
order, never a fixed three and never navigation for a new type.

# Done

- Route `/brands/:brandId/workbench/packs/:packId/sets/:setId`; breadcrumb 品牌 / 素材工作檯 /
  <pack> / <set>.
- Set-local left rail 「素材組」: **總覽 first** (image 3 is missing it — add it; it goes back to the
  pack page), then every sibling set with its icon, name and angle, current one highlighted.
- Header: set name, chips (平台／風格／尺寸 from `chips`), right side status badge (等待決定 …),
  「到檔期規劃」 (only for a dispatched set), ⋯.
- Tabs (`ui/tabs`) = `required_parts` in order, labelled 文案／圖片／腳本 by the API's labels.
- Toolbar shared by every tab: 快速生成｜精準控制 toggle, a one-line spec summary with a link icon,
  and 「再生成 N 張」 where N is the 精準控制 產出數量 (default 4) — it posts
  `…/products/{part}/run`.
- **圖片 tab**: a 2×2 grid of numbered version cards. `image_generation.connected` is false, so the
  grid **defaults to the prompt view**: each card is a plain-text prompt card (① 主圖／② 變體 from
  `prompt_cards`) with its own copy button, plus 「複製全部」 under the grid. 「顯示提示詞」 is a
  toggle that switches back and forth — the image view is the same component fed by the port, so
  build one card component with two renderings, not two screens. Per card: 選定 (已選定 badge on the
  chosen one), 相似版本 (re-runs N from that version's settings), 修改需求 (opens 精準控制 prefilled
  from that version). Right column: 「生成設定」 table (品牌／商品, 平台, 尺寸, 風格, 人物, 場景,
  主要訊息) and a collapsible 「查看 Prompt」; 「已選文案（第 k 版）」 card with 更換版本 ↗ that
  switches to the 文案 tab.
  Nothing on this page may read as a refusal: the seat line is rendered from
  `image_generation.reason` (the API owns that string, F02-I05) — do not type 席位保留 into the
  TSX — and no text anywhere tells the user to run live ads to see a result.
- **文案 tab**: the same page pattern. One round = 5 version cards, each a complete set
  (主文＋標題＋說明) with 選定; under the 主文／標題／說明 fields a 「下一版」 button steps through the
  5. No length tabs, no 建議組合, no pools.
- **腳本 tab**: version cards with their timecoded blocks, 選定, 下一版.
- Bottom bar: 「再生成 N 張」 and 「完成此素材組」 — enabled only when every required 產物 is 已選定;
  it marks the set done and moves to the next unfinished set in the rail.
- Rounds are history: versions are listed newest round first with their round number on the card;
  there is no round switcher.
- An approved pack renders every 選定／再生成／完成 control inert (the API refuses with 409; the UI
  must not offer).
- No new npm dependency; reuse `ui/tabs`, `ui/badge`, `ui/button`, `CopyIconButton`, tokens.
