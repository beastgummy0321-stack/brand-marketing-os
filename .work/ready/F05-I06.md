# Objective

因果鏈（2026-09-14 在程式與資料庫兩邊查證過，寫在 `ARCHITECTURE.md` §8 第 4 條）：

- `repository.create_items` 全專案只有 `app/intake/state.py:284` 一個呼叫端，而它的資料來自
  **貼回**那一步的 `paste_parse`。也就是說，**外部 AI 的貼回是 `brand_fact`／`product_fact` 的
  唯一寫入者**。引導問答的答案只進 `intake_draft.qa_json`，只被拿去組交接包的提示詞。
- 實測：常春健康（有貼回）→ 11 列 `intake_item`、4 `brand_fact` ＋ 3 `product_fact` 全 confirmed。
  MOVE Daily（停在問答那一步、`paste_raw` 是 NULL）→ `intake_item` 0 列、facts 0 列，
  兩圈策略都印「沒有用到品牌事實」。
- 而交接包那一步本身是演練一的最低分（阿明 2/10，「差點關掉網頁」）：畫面要不懂技術的老闆自己
  去跑 Claude／ChatGPT 再貼回來，**沒有跳過、也沒有「系統幫我查就好」**。

使用者裁決：系統自己跑（花系統的錢，受既有的建檔花費上限管），外部 AI 那條路收進進階摺疊。
同一份提示詞、同一個解析器、同一個事實寫入者——**不要新發明任何一個**。
順手把 RC-H 的問答預設值一起修掉（同一個畫面、同一次觸碰）。

```python
def background_intake_research(org_id: str, brand_id: str) -> None
```
流程，每一步都是既有零件：
1. `draft = state.require_draft(brand_id, conn=conn)`
2. `prompt = script.build_prompt(draft, depth, known_products=..., existing=ir.existing_confirmed_data(...))`
   ——跟 `routes_api.py:511-527` 的交接包**一字不差同一份**（那段怎麼組，這裡就怎麼組）。
3. 經 `ai._run(...)` 送出（`task_type="intake_research"`、`purpose="品牌知識調研"`），
   拿回文字。**不新增 `app/departments/**` 或 `app/methodology/**` 的檔案。**
4. 回覆文字直接餵 `state.apply_paste(draft, <文字>, conn=conn)` —— 就是貼回那一步在做的事

5. 失敗／格式不符：`apply_paste` 回 `None` 時**不要當成沒事**——把原文留在 `draft["paste_raw"]`

   但格式要你看一下」。

   不要為了共用去改 `routes_api.py` 的私有函式）。

（單位 US$，跟 `DEFAULT_BUDGET = 30.00` 同一套）。
