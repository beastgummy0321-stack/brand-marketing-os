# Objective
Classify every imported ad of a campaign by program against its own previous window. Pure reads, no LLM, no platform write. The contract (enum, reason codes, item shape) is in the feature Decisions — implement it verbatim.
# Done
1. `triage.classify(conn, org_id, brand_id, campaign_id) -> {"window_days": int, "items": [...]}`; one item per `ads_external_entity` row with `native_kind='ad'` in the campaign.
2. Target from `targets.resolve(conn, org, brand, campaign)`, once per campaign. `value is None` ⇒ `no_target` / `target_unresolved` with `target.missing` verbatim; `result_kind` unknown on both target and view ⇒ `no_target` / `result_kind_unknown`.
3. Metrics only from `review_evidence.aggregate(rows, start, end)["result_views"]`, `metric_scope='ad'`, one entity at a time. No second SQL definition of "known".
4. `WINDOW_STEPS = (7, 14, 28)`; first window ends `today_for_org - 1 day`; on gate failure retry 14 then 28; previous window = the immediately preceding window of equal length; record `window.days` and `window.extended_from`.
5. Sample gate passes when `spend >= 3 * target.value` OR (`window.days >= 7` AND `result_count >= MIN_RESULT_EVENTS`), `MIN_RESULT_EVENTS = 10`. Failed at 28 ⇒ `insufficient` / `below_sample_gate`.
6. Stop-loss is checked first and needs no previous window: `spend >= STOP_LOSS_SPEND_MULTIPLE * target.value` (= 3) AND known `result_count == 0` (derived zeros count) ⇒ `stop_loss` / `spend_over_target_no_result`.
7. Otherwise: current view `reason` not None ⇒ `insufficient` with that reason verbatim; previous unusable ⇒ `insufficient` / `no_previous_window`; else `change_pct = (cur - prev) / prev`, `> FLAT_BAND` ⇒ `worse`, `< -FLAT_BAND` ⇒ `better`, else `flat`; `FLAT_BAND = 0.20`.
8. `GET /api/ads/brands/{brand_id}/campaigns/{campaign_id}/triage` in new `app/ads/triage_routes.py`, included from `routes.py` (only an `include_router` line there); the handler does its own `web.require_actor` + `web.require_brand` like `get_campaign_target`. Response `{"triage": {...}}`.
9. Constants at module top with a one-line comment citing discovery §2.3. No platform name in the file.
10. `docs/architecture/ads.md`: add the triage contract where target cost is documented.
11. Tests: every class and reason code; a non-sales ad with one incidental purchase is never judged on purchases; stop-loss does not fire without a target; a derived zero is what lets stop-loss fire.
