# Objective

演練四三個人裡有兩個走到第七站才發現地基是空的（小杰的品牌 `product` 0 列、`brand_fact` 0 列，
系統照樣讓他走完兩圈零提醒；他貼了權杖但沒把帳戶指定給品牌，畫面給綠勾，到配對才爆）。
成因是**沒有任何一處定義「一個品牌要能投放，最少要有什麼」**，沒有前提就沒有東西可以檢查。

這張票做那個定義，一次、一支函式、程式算（`ARCHITECTURE.md` §8 第 3 條，已定案）。
它只**產出**檢查表；接到畫面上是 F05-I07 的事。

# Done

## 1. `app/ads/readiness.py`（新檔）

```python
def launch_readiness(conn, org_id: str, brand_id: str) -> dict
```

回傳（欄位名就是這些，前端照抄，不再自己拼字）：

```python
{
  "ready": bool,                       # 三個 blocking 項目全是 ok
  "items": [                           # 固定三項、固定順序
    {"key": "offering"|"goal"|"channel",
     "label": str,                     # 「要賣的東西與數字」／「成效目標」／「廣告帳戶」
     "state": "ok"|"missing",
     "text": str,                      # 一句話，說清楚憑什麼綠、或缺什麼
     "next_label": str | None,         # state=missing 才有，例如「去精靈補齊」
     "next_href": str | None},         # router 路徑，**不含 /app**，例如 /brands/<id>/intake
  ],
  "notes": [                           # 不擋人的補充，目前只有一條
    {"key": "knowledge", "text": "品牌知識 7 條（已確認）"},
  ],
}
```

三項的判定與文字（每一句都由後端出，瀏覽器逐字印，`ARCHITECTURE.md` §5.3）：

| key | ok 的條件 | ok 的 text | missing 的 text |
|---|---|---|---|
| `offering` | `bi_repo.list_products` 裡至少一項，`bi_repo.get_product_economics` 算得出 `budget.breakeven_cpa`（不是 None） | 「<第一項的名字> 等 N 項已填好售價與成本」（只有一項就不印「等 N 項」） | 「還沒有任何一項填好售價與成本，算不出一次轉換值多少錢」 |
| `goal` | `bi_repo.get_brand(...)["conversion_goal"]` 有值 | 「成效目標：<中文 label>」（label 取 `app.core.vocab.CONVERSION_GOAL_LABELS`，不要自己寫一份） | 「還沒選成效目標，系統不知道要把什麼算成一次成效」 |
| `channel` | `channels.CHANNELS` 裡任何一個 `channels.connection_state(...) == channels.CONNECTED` | 「<那個通路的 label> 廣告帳戶已指定給這個品牌」 | 「還沒有任何廣告帳戶指定給這個品牌」 |

`next_href` 三項都是 `f"/brands/{brand_id}/intake"`（精靈自己會回到它該回的那一步），
`next_label` 分別是「去補商品與數字」「去設定成效目標」「去接廣告帳戶」。

`notes[0]` 的數字＝`bi_repo.list_brand_facts(conn, brand_id, status="confirmed")` 的長度；
**它不影響 `ready`**——事實影響的是文案品質，不是能不能花錢（§8 第 3 條：沒有「N 條事實」門檻）。
0 條時印「品牌知識 0 條（已確認）——不影響投放，但文案會很空」。

實作限制：
- 讀資料一律走既有 facade（`app.brand_intelligence.repository`、`app.ads.channels`、
  `app.ads.budget.breakeven_cpa`）。**不准在這支寫任何 SQL**，也不准 import `app.meta`
  （通路的事問 `channels.py`，它已經是唯一知道平台名字的地方）。
- `app/ads/channels.py:3-4` 的檔頭現在寫著「只有 `routes.py` 會 import 這個模組」——這張票讓
  `readiness.py` 也 import 它，**把那句話改對**（改字而已，不要動那個檔的任何邏輯）。
- 這支不寫任何東西、不打模型、不 fetch 網路。
