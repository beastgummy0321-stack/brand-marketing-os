# Done
1. Brand prefill (`ai._read_pages` / `run_prefill`): record `urls_read` and `pages_failed: [{url, reason}]` (reason from
   `fetch_url`, in Chinese) in `prefill_json`; `scan_status` returns both. `start_scan` treats a result whose `urls_read` differs
   from the draft's saved URLs as stale and starts again. `ScanStep` lists unreadable URLs with their reason and two exits
   (「改網址再讀一次」 → the URL step, 「跳過，自己填」); 「讀完你的網站了」 only when ≥ 1 page was read; a changed URL list
   triggers a new read instead of showing the old result.
2. Product page read: `POST …/products/{p}/onboarding/scan` accepts optional `page_url`; when given it is stored on the product,
   then read. `ProductOnboarding`'s retry sends the URL currently in the field.
3. One Meta classifier in `app/meta/graph.py` (Contract G). `routes._token_rejection` and `repository.read_external_page` both
   use it (today they disagree: `{100,10,200–299}` vs `{10,190,200}`). The stored sync code stays `permission_denied` for
   `auth` and `scope`, `source_error` for `transient`, so `app/ads/adapters/meta_read.is_auth_error` keeps working unedited.
4. Token connect: zero accounts → not stored, 400 with the Contract G sentence; `transient` / `other` → 502 sentence with the
   code. `MetaConnectPanel` (onboarding step 6) and `MetaSection` (settings) keep the token input visible after any failure and
   after a 0-account result, with 「換一把權杖」 when a token is already stored.
5. Q8: `product_onboarding._suggestions` hides a suggestion whose name (casefold) or page URL matches a product; each card gets
   「不用了」 (`POST …/products/suggestions/dismiss {name}` — exact path is the worker's), stored as `dismissed` names in the
   intake draft's `prefill_json`; dismissed names never come back.
6. Tests: a prefill with one unreadable URL returns it in `pages_failed`; changed URLs restart the scan; product retry with a new
   URL reads the new URL; classifier table (190 → auth, 2 → transient, 100 → scope, 999 → other); 0-account token not stored;
   suggestion hidden by URL match and by dismissal.
