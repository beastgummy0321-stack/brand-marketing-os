# Objective
The cross-product bundle page 「編輯組合」 puts base sell-ways × qty of any products into a bundle and shows each base's own numbers
(feature outcome 1, screen 2 of 2; drill 10 B1's 「Beast Gummy 單件 100・成本 25」). Layout spec = the prototype
`.harness/scratch/prototype/f45-sell-way-components/variant-bundle.html`; data = F45-I01's bundle API and products-page briefs
(`docs/architecture/intake.md` F45 section). Reuse the contents rows, picker and price block F45-I02 built.

# Done
1. 「裡面有什麼」: rows 〈product〉 / 〈base〉 × qty with that base's 售價・成本 (`unit_price` / `unit_cost`); the picker groups every
   finished product's base sell-ways (products-page briefs with `shape === "base"`) by product; 「＋再放一種賣法」.
2. Price block as step 4 with the bundle labels (notes 「推算：能量軟糖・單盒 180 × 2 ＋ …」 come from the server); no 「去填成本」 jump
   for another product's base — 「到「〈product〉」的賣法填」 as the prototype; 「這個賣法免運」 → 「這組免運」.
3. Request bodies `components: [{sell_way_id, qty}]` for create, save and preview; the server's 400 text (e.g. fewer than two
   products) is shown as is.
4. Products-page bundle cards keep working with the new component fields (`sell_way_id`, `product_name`).
5. Tests with real-shaped fixtures: unit numbers per component; derived cost note and 推算; free-shipping sentence; body shape.
6. Deliver 「參考圖｜成品」 for variant-bundle.html.
