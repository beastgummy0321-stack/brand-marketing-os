# Objective
Items 7 (cap) and 8: an ads-dispatched image set holds at most the selections it needs, and a version with failed checks is selected only after an explicit confirm (Feature Contract L).

# Done
1. `select_version_for_set` refuses a selection beyond the required count for `image_prompt` in a set with `source_ref.ads_ad_id` → 409 `selection_full`; copy parts and free jobs keep multi-select.
2. Set payload versions carry `validation_warning` from their ❌ lines.
3. `SetStudioPage`: when full, the other versions' 選定 is disabled with 「已選滿，先取消一張再選」; selecting a version with `validation_warning` opens the same confirm step `claim_warning` uses, listing the ❌ lines.
4. Regression tests (red on master): a second image selection on a one-image ads set → 409 and still one selected; a copy part still accepts two; a ❌ version shows the warning and needs confirm; a clean version selects in one click.
