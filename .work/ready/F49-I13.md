# Objective
The 投放結構 and 素材 tabs print each slot's served state and sentence, let a confirmed slot change its copy before launch, and
treat a stuck hand-off as retryable (feature Contract T; audit W10; slots #1–#4, #11, #12; drill-11 R2 B5／P4). Today the tiles pick
處理中／等你／卡住 themselves (a failed preview reads 處理中, a failed copy generation reads 等你), the structure tab paints one 缺素材
for six states, a confirmed slot has no 換文案, and a failed material hand-off disables its button with 「請先重新讀取」.

# Done
1. Slot tiles (`SlotTiles`, `AssetsBody`, `patterns/SlotGrid` where it draws states): every tile's chip prints `slot.state_label`
   and its line `slot.state_text`; `retrying` shows its retry time (the tile keeps polling like 處理中), `failed` shows the
   workbench exit (`workbench_href`); a `blocked` slot with an `assign` reason shows that sentence with no 改這句文案. A ready slot
   with `copy_editable` offers 換文案 (the existing copy dialog, posting to `…/slots/{ad}/copy`); after launch approval the server's
   refusal sentence shows beside the tile. Tone maps keyed by state (presentation only) may stay.
2. Structure tab (`StructureTab`): a planned ad's material cell prints `slot_label` from the structure read (no
   `missing_material` read; the key stays in the payload for now); `DeliveryTab` prints the served `delivery_label` for platform objects (no raw `native_status`), and its 開始做素材 handles
   `nothing_to_prepare: true` as an outcome (「這期的素材都沿用上一期，不用準備」, then the next step), not an error.
3. 素材 tab, imported (`AssetsTab`): platform ads print `delivery_label` (no raw `native_status`).
4. Material tasks (`MaterialTaskEditor`): the request prints the served `state_label`; on `unknown` it offers 「重新交給工作台」
   (the same dispatch call; the server retries the stored pack) instead of a disabled button and 「請先重新讀取」.
5. `oneRuler.test.ts`: delete every allowlist entry that names F49-I13.
6. Tests: one tile per state with its served chip and sentence (fixtures use the served words, not the old literals); a retrying
   tile keeps polling; a confirmed tile on a draft campaign shows 換文案 and posts a copy change; the structure cell prints
   `slot_label`; `nothing_to_prepare` moves on without an error; an `unknown` material request offers 重新交給工作台.
