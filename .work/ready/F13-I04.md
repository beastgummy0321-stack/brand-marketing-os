# Done

1. 新 task 走既有 gateway；providers／context_compiler 只接既有 task type 選模／思考與契約，產品編排仍留 ads。使用既有品牌事實與禁語檢查入口，不把未看過的影片描述寫成事實。
2. 每批 ≤10 placement revision，單次模型生成，12,000 字元輸入；支援硬限制的 API 為 4,096 output tokens，Codex CLI 依下述使用者確認例外；程式明列未處理數，核對 ID 全覆蓋／無重複／無其他品牌 ID，不用模型計算預算日期。
3. 成功結果以 input hash/品牌事實版本/placement revision 重用；同批 idempotency／鎖避免雙點重送。補齊只填缺欄，原文不改；未確認承諾保留來源與待核對，不自動採納。
4. 依當前 provider 完整 prompt 與最大輸出做 US$0.50 批次上限預檢與預留、既有組織額度檢查；無可靠費率／token 上界則不發送付費呼叫。禁自動付費重試。實際費用以 gateway 紀錄，測試用 fake provider 不花錢。
5. 每件必用均有建議用途／目的節點／安排，或明確 unknowns／待處理理由；預算不足不移除必用，未確認不得改採用配置。缺活動目標時可查看／保存，安排必要缺項以普通文字集中詢問。
6. 確認 API 帶 expected_revision，失效回 conflict；使用者確認後為待手動上架。資料改變使舊建議過時，不覆蓋舊確認證據。
7. 自帶成品不強制新產圖／腳本，不需建座標；internal 一般派工及 F07 行為仍通過既有回歸。第一版標明未做視覺內容分析，摘要來自使用者或可追溯文字。
8. 測試原文逐字不變、事實幻覺攔截、缺資料、模型漏 ID／亂 ID、超額零呼叫、並行／失敗不重送、未知影片、超過一批全部保留、版本 stale confirm。

2026-09-18 使用者明確確認：保留現行 Codex CLI，不切換模型；維持單次呼叫、輸入與執行時間限制、不自動重試，回傳後檢查長度，明示無法保證生成用量硬上限。Codex 的 API 美元費用為零不代表不消耗訂閱額度。此例外不放寬付費 API 的 US$0.50 與硬輸出限制。

必要持久狀態由 ads 擁有的 suggestion batch／reservation 保存（新增 migration、ownership、清理與隔離驗證）；不要把產品批次狀態放入 llm legacy。gateway 會自行 commit，因此先在短交易內預留並 commit，再呼叫。已發送但 timeout／中斷／費用不明，保留預留、不自動 TTL 釋放或重送；成功已入組織 spent 不重複扣，已知 failed cost 補記於本功能帳，不冒充全站跨功能並行硬封頂。
