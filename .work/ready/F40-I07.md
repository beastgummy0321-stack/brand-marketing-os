# Objective
The home quality band tells the truth in its three empty states (drill-7 #8: today every null quality says 「有一天的花費沒讀到」).
Reference: prototype `#/home` (the three stacked states and the normal band). Frontend only: the home payload already carries
`spent`, `quality`, and per-campaign `missing_days`.

# Done
1. `QualityBand.tsx::Band` — derive the state from the payload, in this order: (i) `quality === null && spent === null &&
   some campaign has missing_days` → 「N 月已花還不完整（MM/DD 沒讀到），先不分級」 + 「重新讀取平台」 button (the home's existing
   sync action; if the board has none, the button links to the first such campaign's 成效 tab); (ii) `quality === null && spent !==
   null` (the guarded block failed) → 「分級讀取失敗」 in danger tone + 「重試」 (reload the board); (iii) `quality` present but every
   bucket empty / `spent` is 0 or null with no missing days → 「N 月還沒有花費資料，先不分級」. Normal band unchanged.
2. Put the sentence-picking in `status.ts` as one pure function with the payload as input so `status.test.ts` covers the three
   cases and the normal case without rendering.
3. Tests: `status.test.ts` four cases; `HomeBoard.test.tsx` — one render per empty state asserting the sentence and the button.

# Touch notes
`adsHomeApi.ts` gains no field (the payload already has what the band needs); `AdsHomePage.test.tsx` / `MonthReviewPage.test.tsx` are unaffected. `DecisionQueue.test.tsx` imports `status.ts` and is in touch.
