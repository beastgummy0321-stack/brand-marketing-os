# Objective
One request marks every unreadable readback field as seen (drill-7 #18: 27 items clicked one by one). Backend half of the
`#/readback` screen; the frontend (I10) calls it.

# Done
1. `app/ads/handoff_check.py::confirm_all(conn, org, brand, campaign, actor) -> dict`: under the same `changes.lock`, loop every
   launch item field the readback reports as unreadable through `confirm_field` and every unreadable setting through
   `confirm_setting` (the two existing functions, unchanged), in one transaction; returns `{"confirmed_items": n, "confirmed_settings": n,
   "view": <the same payload GET …/launch returns>}`. Fields already seen or readable are skipped, never errored. Docstring names
   the drill-7 item.
2. `app/ads/handoff_routes.py`: `POST /handoff/launch/confirm-all` (same prefix/auth pattern as `settings-confirm`), body empty,
   returns the dict above; a campaign with nothing unreadable returns zeros and the view (200, not 4xx).
3. Tests: `test_ads_handoff.py` — a launch view with 2 unreadable settings and 3 unreadable item fields → one call confirms 5, the
   view shows them seen, a second call confirms 0; a readable field is untouched.
