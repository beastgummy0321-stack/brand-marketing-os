# Objective
One ruler means one answer to "is this ad judged yet?". Today `learning_rank.rank` ranks every known-zero row with spend > 0 as 沒賣出 → 換掉, so settle and closeout write 「無效」 for an ad that spent less than the 沒賣出 line (triage calls the same ad 剛開始 and cleanup leaves it unranked, F48-I02/I09 evidence). Budget split, not results, then decides which coordinates are learned as bad — the drill-11 L1 condition in another place.

# Done
1. `learning_rank.rank`: a known-zero row is 沒賣出 (ranked, `replace`) only when `spend >= triage.STOP_LOSS_SPEND_MULTIPLE × cap`; below that line, or with no cap, it is not ranked (left out like an unknown row). Import the constant (lazy import if `triage` imports `learning_rank`); no literal. `rule_text` unchanged in wording for the ranked rows.
2. Every caller follows by construction: cleanup (already excluded), settle (the row is skipped with `skip_reason` 「還沒賣出，花費也還沒到門檻」), coordinate closeout learning (writes nothing for it), month summary, planner learnings view. No caller keeps its own zero rule.
3. Settle rows are served in rank order within each campaign (unranked rows after, by name); the frontend prints served order.
4. Tests: a 0-sale row at 0.5 × cap is unranked in rank(), skipped in settle, absent from coordinate learnings; at 3 × cap it is 沒賣出／換掉 everywhere; settle order follows rank. `test_ads_one_ruler.py` stays green (no new literal).
