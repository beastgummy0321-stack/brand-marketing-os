# Objective

檔期規劃 leaves the product, with no parallel run. §0: it serves no link any more — it is the
retirement of the surface 投放中心 replaced; its input is nothing; its output is one fewer way to do
the same job; its trace is this issue and `ARCHITECTURE.md` §4, which records what is left of the
`schedule` package and when it goes; it is the opposite of core.

**Scope guard**: only the user-facing surface retires. `app/schedule/**` is not touched — 經營概況
still reads its 判讀 surfaces (creative-performance, diagnosis, coordinates, 舊廣告 history) and
those are entangled with `plan.py`／`state.py` (measured 2026-09-12). The package retires when those
readers move (feature 2/3).

# Done

- **Delete** the six files under `frontend/src/components/schedule/` and the
  `/brands/:brandId/schedule` route and its route component in `App.tsx`. `frontend/src/lib/
  scheduleApi.ts` **stays** — the cockpit and the intake history page import it.
- Any remaining 檔期規劃 wording in a surface that is still alive is corrected to 投放中心 and the
  link retargeted: `DiagnosisPanel.tsx`'s 「到檔期規劃→素材準備看進度」 becomes 「到投放中心的素材
  分頁看進度」. `LoginPage.tsx`'s marketing sentence keeps 檔期規劃 only if rewriting it would change
  the paragraph's meaning — prefer 投放.
- **設定 loses the budget card** (user ruling 4): `app/core/rule_cards.py` gains one constant
  `HIDDEN_IN_SETTINGS = {"schedule_budget"}` and `list_cards()` skips those keys — one line, one
  comment naming the ruling. `get_card`/`get_value` keep working so the legacy schedule code that
  still reads `daily_budget` is unaffected. **No card definition is deleted**, no migration.
- **e2e**: `smoke.spec.ts` and `width-overflow.spec.ts` no longer visit `/schedule`; width-overflow
  covers `/ads`, `/ads/new` and a campaign workspace route instead (the 1280 `#root.scrollWidth`
  formula stays — never the `documentElement` one).
- `app/tests/test_ads_settings_budget_card.py` (the falsifier): `list_cards()` for a brand does not
  contain `schedule_budget`; `get_value(..., "schedule_budget", "daily_budget")` still returns its
  value; the other cards are all still listed.
- Run `uv run python -m pytest app/tests/test_schedule.py -q` unchanged — it must stay green, which
  is the proof that nothing in the backend was pulled out with the page.
