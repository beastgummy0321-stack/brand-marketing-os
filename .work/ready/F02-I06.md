# Objective

自由創作's 「AI 解析結果」 is a **real model call** — the user's ruling, 2026-09-12. Exactly one call,
fired when they press 「建立自由工作」, none while typing. This issue is that call: one endpoint, one
department task file, one place that turns free text into the spec the second click submits. It
spends money once per click, so it is reviewed.

# Done

- `app/departments/workbench/free_parse.md` — a **department task file**, not a methodology part
  (same precedent as `copy.md`; `app/methodology/**` stays untouched in this feature, see
  `.work/features/F02.md` Decisions). It states the task (讀一段中文自由描述，抽出可執行的素材規格),
  the reply object (below), and the two rules that keep it honest: **不補寫使用者沒說的訴求或賣點**,
  and 沒說到的欄位一律回 `null`——不要猜. Keep it short; it is read verbatim as the prompt.
- Reply object, one level of keys:
  `{"topic": str, "outputs": [{"part": "copy"|"image_prompt"|"video_script", "count": int}],
  "style_hint": str|null, "platform": str|null, "size": str|null, "audience": str|null,
  "key_message": str|null}`. `count` is what the user asked for (「五張」 → 5), absent → 1.
  `free` is not a valid `part` (`.work/features/F02.md` Decisions).
- `app/workbench/free_parse.py` — module-private, ~80 lines:
  - `PROVIDER = providers.AnthropicProvider()` at module level, exactly like `jobs.py:32`, so a test
    swaps it with `mock.patch.object(free_parse, "PROVIDER", FakeProvider(...))`. It does **not**
    import `jobs.py` (that file is the procrastinate body; the request path stays independent of
    it) and reads its own `.md` path.
  - `parse(conn, *, brand_id, free_text, defaults) -> dict`. One `gateway.run_task` with
    `task_type="workbench_free_parse"`, `prompt_template_id="workbench_free_parse"`,
    `prompt_template_version="v1"`, an **empty `TaskContext`** (`context_scope={"brand_id":
    brand_id}`, no `context_compiler` call — this is shape extraction, not brand voice, and the
    compile would multiply the cost of every click) and
    `TaskOptions(max_tokens=2000, timeout_s=60.0)` — a person is watching a spinner, not a worker
    queue. `brand_id` is the URL's brand even when the form's 品牌 is 不指定: that only affects what
    goes into the pack, never who the `llm_task` row belongs to.
  - Reply → `gateway.parse_json_reply`; validate the shape here (known `part` names, `count` an int
    1..30, strings or `null`). `style_hint` is mapped onto an existing `image_styles.json` key and
    returns `null` when nothing matches — never an invented key, because `submit_pack` would reject
    it.
  - **Failure is never a dead end**: `run_task` returning `failed`/`timeout`, an unparseable reply
    or a shape that does not validate all return
    `{"parsed": false, "note": "AI 沒能整理出規格，下面是你填的設定，可以直接建立。", "spec": <the
    `defaults` the caller sent>}` — no exception, no retry loop beyond the one `gateway` already
    does. A successful call returns `{"parsed": true, "note": null, "spec": {…}}` with the model's
    fields merged over `defaults` (model wins per field, `null` keeps the default).
- `app/workbench/routes.py`: `POST /brands/{b}/parse` `{free_text, defaults}` →
  `{"parse": {parsed, note, spec}}`; `require_actor` → `require_brand` → one `free_parse.parse(...)`
  call → wrap, same shape rule as every other route, no logic in the route. `free_text` empty or
  >1,000 characters → 400 `free_text_invalid`.
- `app/tests/test_workbench_free_parse.py` (new, the falsifier — no real provider, ever): a
  `FakeProvider` returning a valid reply for 「幫 Beast Gummy 做五張夜跑廣告，風格真實、有競技感，
  適合 Meta 4:5」 gives `outputs == [{"part": "image_prompt", "count": 5}]`, `size == "4:5"`,
  `platform == "Meta"`; a reply with an unknown `part` and a reply that is not JSON both come back
  `parsed: false` with the defaults intact and **no exception**; a provider timeout does the same;
  exactly **one** `llm_task` row is written per call (follow `app/tests/test_workbench.py` for the
  fake-provider fixture and the `llm_task` assertion).

# Verify

The commands above. Nothing here is judged against a live model: the test suite's fake provider is
the falsifier, and the shape check is what the frontend depends on.

# Blocked if

`gateway.run_task` cannot be called inside a request without a compiled brand context, or one call
takes longer than the request budget on `codex_cli`. Report the measured number; do not turn this
into a background job and a polling endpoint without a planner decision — that is a different UX.
