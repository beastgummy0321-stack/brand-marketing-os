# Objective
The flip (rulings 1, Contracts P, R, and the `coverage_gap` helper of Q): every performance reader of an internal campaign
reads `ads_external_daily` through one mapping, the simulated adapter writes `ads_external_entity` + `ads_external_daily` +
recorded coverage like a platform, and the manual ingest path is deleted. Root cause (dig 2026-09-28): after readback
binding (`handoff_check.py:426-446`) a real campaign feeds two pipelines — `POST …/ingest` → `outcome.ingest_meta`
(`routes.py:826-853`, `outcome.py:115-162`) → `ads_outcome_daily`, and `external_sync` → `ads_external_daily` with coverage —
so the performance tab / closeout / budget history disagree with the home / workspace / triage and never see missing days.
`ads_outcome_daily` itself stays until F37-I06 (the cleanup registry `repository.py:1258` and `test_cleanup_coverage` need the
table and the entry to go together).
