# Objective

The program, with no model call, decides which look each of a round's slots uses: learned winners
take at most 7 of 10, at least 3 explore the least-tried looks, nothing is excluded by a guess, and
each round recommends one item so about 3 in 10 rounds recommend exploration. The user's trap to
prevent: 「假設系統今天丟了5個風格，回收回來的前3名被放到品牌成功區，而系統之後只會走快樂路徑，不去找其他可能，
永遠都在這三個風格繞」. Rules: ARCHITECTURE.md §5.9 (Look catalogue, Slot plan, Exploration reaches the
test, Learnings read); F07 Decisions 19, 21–23. Never delete or overwrite anything under `data/`.

# Done

1. **`app/workbench/looks.py` (new)**:
   - `LOOKS: dict[str, tuple[str, str]]` — the 12 entries of `run_v4.py::LOOKS`, keys, labels and texture
     text copied verbatim, same order (that order is the catalogue order).
   - `BRAND_SPEC = "brand_spec"`, `BRAND_SPEC_LABEL = "品牌規範"`.
   - `look_label(key) -> str` (`brand_spec` → 品牌規範; unknown → the key) and
     `look_texture(key, brand_spec_text: str | None) -> str` (`brand_spec` → that text; catalogue → its
     texture).
   - `allocate(n, *, fit_looks, excluded, winners, history, rng) -> {"plan": [(look, slot)], "explore_first": str | None, "exploit_looks": [str], "explore_looks": [str]}`:
     - `fit_looks`: ranked keys, may start with `brand_spec`; `excluded`: keys (drop `brand_spec` if
       passed); `winners`: learned look keys newest first; `history`:
       `{look: {"adopted": int, "offered": int}}`; `rng`: `random.Random`.
     - available = `LOOKS` keys plus `brand_spec` when it is in `fit_looks`; minus `excluded`.
     - `exploit_n = n * 7 // 10` (10 → 7; 2 → 1). Exploit pool = winners that are available, else
       available `fit_looks`. Slots `i < exploit_n` get `(pool[i % len(pool)], "exploit")`.
     - Candidates = available looks not in the exploit pool (§5.9 "outside the 主力 pool"; for n 2 the
       pool holds more looks than exploit slots), sorted by (`adopted`, `offered`, rank in `fit_looks` or
       99, catalogue index with `brand_spec` = -1). Remaining slots get
       `(candidates[i % len(candidates)], "explore")`; `explore_first = candidates[0]` (or `None` when
       `n - exploit_n == 0`). If candidates is empty, fill from the exploit pool as `"explore"`.
     - `exploit_looks` = distinct looks of the exploit slots in pool order; `explore_looks` = distinct
       looks of the explore slots in candidate order (both taken before the shuffle).
     - `rng.shuffle(plan)`, except when `n == 2` (輪播): keep `[exploit, explore]` order. The shuffle
       is for the prompt only; display order comes from `exploit_looks`/`explore_looks`.
   - `recommend(plan, explore_first, *, rounds: int, explore_recommended: int) -> int`: 1-based index.
     When `10 * (explore_recommended + 1) <= 3 * (rounds + 1)` and some slot's look is `explore_first`
     with slot `"explore"`, return the first such index; else the first `"exploit"` index.
   - `plan_text(exploit_looks, explore_looks) -> str`: 「主力：<labels>；探索：<labels>」, labels via
     `look_label` in the given order, joined 「、」; a side with none is omitted.
   - `visual_learnings(conn, brand_id, audience_key, *, today) -> {"winners": [...], "lines": [...], "omitted": int, "ids": [...]}`:
     - read `bi_repo.list_learnings(conn, brand_id, source_track="visual", limit=200)` (not expired by
       default);
     - keep rows with `confidence` in (`likely`, `validated`), `learned_at` within 180 days of `today`,
       and `applicability_scope` parsing as `visual；audience=<key>；<dimension>=<value>` with audience
       equal to `audience_key` and value ≠ 看不出; a malformed scope is skipped, never raised;
       `audience_key` `None` → everything empty;
     - newest first by `learned_at`; `winners` = distinct values of `look` rows in that order;
       `lines` = first 5 `learning_text`; `omitted` = matched − 5 (min 0); `ids` = ids of the rows in
       `lines` plus ids of rows that produced a winner.
