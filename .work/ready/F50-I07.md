# Objective
Every background job ends with a stored outcome — failed, empty or done, with a code — that one helper reads, failures fail so the
bell counts them, notices never cut off their outcome, and an LLM error keeps its kind (feature Contract J; audit W14; intake #9,
#10; triage #3 (bell); slots #8; other F10 (customer voice); drill-11 M1-c bell 「失敗數未增加」, W1). Today procrastinate status
is the only outcome, so a handler that swallows a failure ends 「succeeded」 and `failed_today` stays 0; an unknown job reads
running on one screen and done on another with a fabricated `started_at`; a 28-character product name makes success and failure
notices identical; `llm_task.error` is free text with no kind.
