name, and never leave the user without a forward exit (feature Contracts Q, B, L; frontend-ads F2, F6, F12; drill-11 R4 H4／Q2,
E11／Q4). Today 「下一件」 walks every kind (it can land on 資料不足 with no exit), `reported` and `unknown` both read

locally, and the month-budget gate links to the home with no way back.
