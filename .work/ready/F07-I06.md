outputs: the task table by audience × conversion goal, allowed persuasion from offer and proof, the
device/layout/subject/persuasion vocabularies, and the per-item and per-round checks including
look-equals-slot and label leak. No DB, no model. Rules: ARCHITECTURE.md §5.7 (table, fingerprint

# Done

1. **`app/workbench/visual.py` (new)**, the one home of these tables (cite
   `app/methodology/meta-format-specs.md` for the ratios in a comment):
   - `IMAGE_PROMPT_COUNT = 10`.
   - `shape_for(format_key) -> "single" | "carousel"`: `carousel` → carousel; everything else
     (`single_image`, `flexible`, `video`, a brand-made key, `None`) → single.
   - `RATIO = {"single": ("4:5", "4:5 直式單圖廣告，1080×1350"), "carousel": ("1:1", "1:1 輪播卡片，1080×1080")}`.
   - `DEVICES`, `LAYOUTS`, `SUBJECT_ROLES`, `PERSUASIONS`, `SLOTS` as ordered `{key: label}` dicts with
     exactly the keys and labels of ARCHITECTURE.md §5.7 ("Visual fingerprint"); `SLOTS = {"exploit":
     "主力", "explore": "探索"}`.
   - `CLOSE_WORDS = {"purchase": "下單", "booking": "預約", "lead": "留下資料或報名", "awareness": "進一步了解"}`;
     `None`/unknown → 下單.
   - `TASKS`: audience key → `{key, label, how, subject_roles}` exactly as the §5.7 table (label may hold
     `{close}`). `task_row(audience_key, conversion_goal) -> dict | None` (label formatted);
     `all_task_rows(conversion_goal) -> dict[task_key, row]`.
   - `OFFER_PERSUASION`, `PROOF_PERSUASION` exactly as §5.7; `allowed_persuasion(task_key, offer_key,
     proof_key) -> list` = `["none"]` for `stop_relate`, else `none` plus the union, in `PERSUASIONS`
     order; unknown keys contribute nothing.
   - `NEGATIVE_PATTERN = re.compile(r"(?<!要)不要|請勿|避免|禁止|不得|不出現|不放|勿")` — `請勿` must count
     once (verify with a test).
   - `leak_terms(*, audience_label, angle_label, hook_label, proof_none_label, task_label) -> list[str]`:
     classification jargon only, each label whole — the full audience label (never split on 「・」), the
     angle and hook names, `proof_none_label` (the proof label, passed only when proof is `none`, i.e.
     無證明) and the task label; empty/`None` skipped; deduplicated. Pain and offer labels are everyday
     words and are never parameters.
   - `spec_warnings(brand_id, spec_text) -> list[{text, href}]`: more than 2 `NEGATIVE_PATTERN` matches
     in `spec_text` → one warning 「視覺基礎裡有 N 句「不要／避免」這類限制；限制太多會鎖死整張圖的設計，建議只留
     最重要的一兩句。」 with `href` `/brands/<brand_id>/library?tab=facts`; else `[]`; `None` → `[]`.
2. **`app/workbench/validate.py`**, new functions next to the existing checks, same `{path, ok, message}`
   result shape and path convention as `check_copy` (do not remove the old image check — F07-I07 retires
   it with its caller):
   - `trim_image_reply(data, shape) -> None`: more than 10 `items` (single) / 2 `concepts` (carousel) are
     cut to that count in place.
   - `check_image_reply(data, *, shape, plan, allowed, task_rows, leak_terms, quotable_text) -> list`:
     - `plan`: list of `(look, slot)` per item/concept; `allowed`: `{"subject_role": [...],
       "persuasion": [...]}` or `None`; `task_rows`: `{task_key: allowed}` used when `allowed` is `None`
       — then top-level `image_task` must be one of its keys and that row is used.
     - Per item (single) or concept (carousel): `look == plan[n][0]`; `device` in `DEVICES`; `layout` in
       `LAYOUTS`; `subject_role` and `persuasion` in the allowed lists.
     - Per item prompt, or per card prompt: the ratio token of `shape` occurs in the first sentence (text
       up to the first 「。」); no 「【」; no English code `(?<![A-Za-z])[a-z]+_[a-z_]+`; `headline` is a list
       of 1–2 strings, each ≤14 characters and each equal to one 「」 string of that prompt; every 「」
       string (`re.findall(r"「([^」]*)」", prompt)`) is ≤22 characters and contains no 「; ≤6 「」
       strings; no 「」 string contains a `leak_terms` entry that does not itself occur in `quotable_text`; every fact number inside a 「」 string occurs
       verbatim in `quotable_text`; `len(NEGATIVE_PATTERN.findall(prompt)) <= 1`.
     - Fact number: a digit run (with `,` / `.` inside) attached to 元／折／%／％／mg／g／ml／盒／包／入／組／件／
       顆／堂／次／位／人／天／小時／分鐘, or preceded by $／NT$／滿／剩／第, or a countdown `\d{1,2}:\d{2}:\d{2}`.
       Plain clock times `\d{1,2}:\d{2}` and dates are not fact numbers.
     - Per round: single fewer than 10 items → ❌ at the round path; `headline[0][:3]` shared by more than 2
       items → ❌ on each item beyond the 2nd; fewer than 5 distinct layouts → ❌ round; fewer than 4 distinct
       devices → ❌ round. Carousel: exactly 2 concepts × 5 cards, the 2 concepts' layouts differ.
