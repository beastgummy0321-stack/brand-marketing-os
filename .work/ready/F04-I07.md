# Objective

F03 的四張 UI 票各自從零拼版面，結果跟預覽圖長得不像（F04.md「為什麼 F03 UI 走鐘」）。這張票
是後面每一張 UI 票的地基：**先把參考圖裡重複出現的八個版面樣式寫進 `docs/design-system.md`，
再在 `frontend/src/components/ads/patterns/` 各做一個元件**，之後的頁面票只負責組合，不再自己
發明卡片。§0 連結：這一步不動資料鏈，它服務的是「使用者看得懂、敢按下一步」這件事
（ARCHITECTURE.md §6.1 第 9 條＝R9）。

**動手寫 UI 之前，先用這五張參考圖呼叫 `Skill impeccable:impeccable`**（R6）：
`docs/design/ads/01-home.png`、`02-campaign-list.png`、`04-understood.png`、`05-strategy.png`、
`06-workspace-overview.png`。圖是方向，不是素材：版面結構、區塊順序、資訊密度照圖；顏色、字級、
圓角、圖示一律用 `tokens.css` 與 lucide（design-system §2）。圖上的插畫、吉祥物、手寫字、
紫色手寫註記**一律不做**（R3：判斷帶沒有插畫欄位）。

## 2. 九個元件，`frontend/src/components/ads/patterns/`

共同規則：全部是 **pure presentational**（props in，JSX out）——不 fetch、不認得 `adsApi`
的型別（props 用自己的小型別，頁面票負責把 payload 對進來）、不放 `useEffect`。全部用
`surface`／`table-surface`／tokens class，不寫一個 hex。全部 `export` 到 `patterns/index.ts`。

1. **`JudgmentBand`**（頁首判斷帶，圖 1／5／6）：整寬 tinted band（`bg-accent` 系，圓角 12，
   1px border），左邊一個 44px 圖示圓盤（lucide icon 由 props 給），右邊上下兩行：
   `sentence`（16–18px／600，一句判斷）、`facts`（13px muted，一行事實，可為空就不渲染）。
   props：`{ icon, sentence, facts?, tone?: "neutral" | "good" | "warn" }`。**沒有插畫欄位、
   沒有第三行、沒有按鈕。**
2. **`DecisionCard`**（決定卡，圖 1／6）：`surface`，header 左「需要你決定」＋一顆
   `Badge variant="secondary"` 顯示件數（0 件時不顯示 badge），body 是 `items` 列表，每列：
   48px 圖示方塊、標題（15/600）、一行理由（13 muted）、右邊三顆按鈕
   `同意`(default)／`先不要`(outline)／`查看原因`(outline)，各自 `onClick` 從 props 來。
   `items` 是空陣列時 body 只有一行 muted 置中字：`目前沒有需要你決定的事`（**不是** `EmptyState`，
   這是卡內空狀態，不要插圖、不要按鈕）。props 的 `onAgree`/`onDefer`/`onWhy` 都可以是 undefined，
   那時按鈕 `disabled`（F04 沒有產生端，只有空狀態會出現，但元件要能給 F05 直接用）。
3. **`CampaignTile`**（Campaign 卡，圖 1）：`surface` 可點（`hover:shadow`），
   上排：名稱（15/600，一行截斷）＋右邊狀態 `Badge`；第二行 13 muted：`目標・通路`；
   第三行：`已花費 / 總預算` 兩個金額（tabular）＋右邊百分比；第四行：進度條
   （高 6px、圓角 3、`bg-muted` 底、`bg-primary` 實心，寬度＝百分比，**上限 100%**）；
   最下面一條 tinted 內縮區塊：一行 `judgment`（13/600）＋一行 `judgmentDetail`（12 muted）。
   props 全部是**已經格式化好的字串**（`spendText`、`budgetText`、`percentText`、`percent`
   這個 0–100 的數字只給進度條寬度用）——金額格式化與判斷句都是後端／呼叫端的事，元件不算數。
   沒有數字可說時呼叫端傳 `spendText="尚未開始"`，元件照印，**不准自己印 0**。
4. **`KpiStrip`**（數字條，圖 2／5／6）：一張 `surface` 裡 3–5 格（等寬），格與格之間 1px 直線；
   每格：36px 圖示圓盤、`label`（12 muted）、`value`（`metric-number`）、`caption`（12 muted，
   必填——design-system §7「每個數字都要有說明」）。props：`{ cells: {icon,label,value,caption}[] }`，
   `cells.length` 只接受 3～5（TypeScript 不必強制，但註解寫明）。
5. **`ActionTimeline`**（時間軸，圖 1／6）：垂直線＋每筆一個小圓點，每筆：`time`（12 muted）、
   `title`（14/600）、`detail`（13 muted，可為空）。props：`{ items, emptyText }`；
   空陣列時只印 `emptyText`（呼叫端給，例如「還沒有任何紀錄。」）。**每一筆的文字都是後端給的字串**，
   元件不拼、不翻譯 kind。
6. **`ReservedSlotCard`**（佔位卡，圖 1／6／10）：`surface`，整張 `bg-muted`／muted 文字、
   **不可點、沒有按鈕、沒有 disabled 樣式的假按鈕**；內容：標題（15/600）、一行說明、
   右上角一顆 `Badge variant="secondary"` 顯示 `tag`（例如「自動執行接上後開放」）、
   選填 `bullets: string[]` 以 muted 小字列出保留的欄位（圖 10 的進階設定清單）。
   一行註解寫明：席位保留不是拒絕，文案不得出現「不支援」「無法」「尚未開放使用」。
7. **`StepIndicator`**（步驟指示，圖 4）：水平三步 `1 確認需求 → 2 產生策略 → 3 查看結果`，
   props：`{ steps: string[], current: number }`（0-based）；已完成的步驟圓圈 `bg-success`＋
   lucide `Check`，當前 `bg-primary`，未到 `bg-border`；步驟之間 1px 連接線。
   **不要**複製 `OverviewTab` 的狀態時間軸（那是另一個東西，留在原地）。
8. **`FieldCard`**（摘要欄位卡，圖 4）：`surface` 一格，左邊 40px 圖示方塊、
   `label`（12 muted）、`value`（15/600；`value` 為空時印呼叫端給的 `emptyText`，例如「未設定」），
   右邊一顆 `Button variant="ghost" size="sm"` 帶 lucide `Pencil`（`onEdit`）；
   `source`（`"user" | "system"`）渲染成一顆小 `Badge variant="secondary"`：`你說的`／`系統帶入`。
   選填 `editing` 為 true 時，`value` 位置換成 props 傳進來的 `children`（頁面票放 input），
   元件自己不管狀態、不管存檔。
9. **`Disclosure`**（進階收合，圖 5／10 的規則載體）：`{ label, children, defaultOpen? }`，
   內部一個 `useState`；收起時只有一列可點的 header（lucide `ChevronDown` 旋轉），展開時
   header 下方是 `children`。用 `<button aria-expanded>`＋條件渲染，**不要**引進新套件、
   不要動 `layout/ui/`。註解寫明：R9 的「不點開是不會看到」就是這顆元件。

## 3. 一份測試 `patterns/patterns.test.tsx`

照 `frontend/src/components/ads/OverviewTab.test.tsx` 的寫法（vitest ＋
`@testing-library/react`，不 mock fetch）。**最便宜的證偽**，五個斷言就夠：

1. `DecisionCard items={[]}` → 畫面上有「目前沒有需要你決定的事」，而且**沒有**「同意」。
2. `CampaignTile` 給 `percent={140}` → 進度條的 style width 是 `100%`（不溢位）。
3. `KpiStrip` 的每一格 caption 都印得出來（傳三格，三句 caption 都在畫面上）。
4. `ActionTimeline items={[]} emptyText="還沒有任何紀錄。"` → 印出那句話。
5. `Disclosure` 預設看不到 children；點了 label 之後看得到（R9 的機器證明）。

# Blocked if

- 某個樣式在圖上讀不出必要資訊（例如進度條的數字口徑），**先照圖做視覺、把口徑留給頁面票的
  props**，不要自己發明一個計算。
- 需要新的 kit 元件（`layout/ui/*`）才做得出來：release 並說明是哪一個——加 kit 元件要走
  shadcn generator，是另一張票（design-system §6）。
