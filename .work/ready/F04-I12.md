# Objective

建立 Campaign 從「一句話＋必填日期 → 直接進策略頁」變成兩步：
`docs/design/ads/03-new-campaign.png`（描述）→ `docs/design/ads/04-understood.png`（理解如下，
六張可改的欄位卡）→ 按「產生策略建議」才花第二次模型錢。ARCHITECTURE.md §6.1 第 11 條。
§0 連結：**goal（the brief）**——使用者確認過的理解，才是後面每一步的輸入。

**動手前先用這兩張圖各呼叫一次 `Skill impeccable:impeccable`**（R6）。圖上的插畫、手寫字、
「AI 幫你規劃，讓投放更簡單！」貼紙**不做**；右側那張「MarketingOS 會自動幫你整理」說明卡**要做**
（它是新手要的預期管理），但用 tokens 的圖示與文字，不畫插圖。

# Done

- `PageHeader` title 「建立投放計畫」、description
  「只要告訴我們你的目標，行銷駕駛艙會幫你整理投放策略、預算、素材與排程。」，
  左上一個返回連結「← 投放中心」（`/brands/${brandId}/ads`）。
- 兩欄：左邊 `surface`（主卡），右邊 `surface`（說明卡，1024 時移到左欄下方）。
- 左邊卡：
  - 標題「你這次想做到什麼？」＋一行 muted「用自然語言告訴我們你的想法，越詳細越好。」
  - `Textarea`（既有的 `goalText` state），右下角字數 `{n} / 500`（`maxLength=500`）。
  - **日期不再是必填欄位**：既有的兩個 `Input type="date"` 從主畫面**移除**，改放進
    「限制條件（選填）」那一列的 `日期` chip 裡（chip 展開時才出現兩個日期輸入）。
    兩個都沒填就不送 `start_date`／`end_date`（F04-I11 的後端會從句子判斷，判斷不出來就
    今天～+30 天並標「系統帶入」）；只填一個時前端擋下來並提示
    「開始與結束日期請一起填，或兩個都留空。」
  - 其餘四個 chip（預算上限／指定平台／指定商品／其他限制）照舊，chip 的 placeholder 改成圖上的
    例子：`例如 NT$ 30,000`／`例如 Facebook`／`選擇商品`／`例如受眾、地區等`。
  - 主要按鈕文字改成「產生建議」（圖 3），送出後照舊顯示既有的讀取狀態，成功後
    `navigate(\`/brands/${brandId}/ads/new/${draft.id}\`)`——**不再**直接跳策略頁。
    `parsed === false` 時把既有那句提醒改用 `navigate` 的 state 帶到步驟二（見下）。
- 右邊說明卡：標題「行銷駕駛艙會自動幫你整理」，五列（圖 3 的五項），每列一個 lucide 圖示圓盤
  ＋標題＋一行說明：商品／目標／平台／預算建議／素材需求。純靜態文字。

## 2. 步驟二：新檔 `ConfirmBriefPage.tsx`（圖 4）

路由 `/brands/:brandId/ads/new/:campaignId`（`App.tsx` 加一條、`index.ts` 加一行 export）。
進來先 `getCampaign(brandId, campaignId)`；同時 `fetchProductList(brandId)`（`@/lib/productsApi`）
拿商品名字（`context_json.product_ids` 只有 id）。兩個請求並行，載入中用 `Skeleton`。

版面：

- 返回連結「← 投放中心」，`PageHeader` title 「行銷駕駛艙理解如下」、description
  「這是我們根據你的需求整理的重點內容。如果理解有誤，可直接修改。」
- 右上角 **`StepIndicator`**：`steps = ["確認需求", "產生策略", "查看結果"]`、`current = 0`。
- 一張 `surface`：header 「你的行銷需求」＋一行 muted「我們已根據你的輸入，整理出以下重點。」；
  body 是 **六張 `FieldCard`**（`grid-cols-2`），順序照圖：

  | 卡 | label | value | 編輯方式（就地） | source |
  |---|---|---|---|---|
  | 1 | 商品 | 商品名稱，多個用「、」接；空 → 「不指定」 | 商品清單的多選 checkbox → `patchCampaign({product_ids})` | `field_sources.product` |
  | 2 | 目標 | `objective` | 五選一 `select`（購買／加購物車／名單／流量／知名度）→ `patchCampaign({objective})` | `field_sources.objective` |
  | 3 | 平台 | `constraints_json.platform` 的中文 label；空 → 「尚未指定」 | 五選一 `select`（`meta`／`google_ads`／`tiktok`／`shopee`／`momo`，label 寫死在這個檔案的一張小對照表）→ `patchCampaign({constraints_json})`（整包送回，改那一個鍵） | `field_sources.platform` |
  | 4 | 預算 | `constraints_json.budget` → `約 NT$ 30,000`；空 → 「由行銷駕駛艙建議」 | 數字 `Input` → `patchCampaign({constraints_json})` | `field_sources.budget` |
  | 5 | 時間 | `start_date ~ end_date`；缺 → 「未設定」 | 兩個 `Input type="date"` → `patchCampaign({start_date, end_date})` | `field_sources.dates` |
  | 6 | 受眾方向 | `context_json.audience_hint`；空 → 「未設定」 | **唯讀**（`onEdit` 不給 → 鉛筆不出現）：`audience_hint` 沒有 PATCH 欄位 | `field_sources.audience` |

  - 「你說的／系統帶入」badge 由 `FieldCard` 的 `source` prop 渲染，**不要**在這裡重寫那兩個字。
  - **存檔之後那一格會變成「你說的」，而且不是前端自己改的**：`patchCampaign` 回的是完整
    campaign，後端已經把被改的那一格的 `field_sources` 翻成 `user`（F04-I11 §2b）。
    這一頁只要把回傳值放進 state 重畫即可——**不要**在前端另外維護一份「使用者改過哪幾格」。
  - 編輯採 `FieldCard` 的 `editing` 模式：點鉛筆 → 那一張卡的值換成輸入元件＋「儲存／取消」兩顆
    小按鈕；儲存成功後用回傳的 campaign 更新本地 state（`patchCampaign` 回的是完整 campaign）。
    存檔失敗印一行紅字在卡片下方，**不整頁換掉**。
  - `parsed === false`（由步驟一帶進來的 navigate state）→ 在六張卡上方一行 `warning` 提示
    「這句話沒有完全被理解，請確認下面的欄位。」
- 第二張 `surface`：header 「行銷駕駛艙將據此產生：」，四格（圖 4）：策略建議／預算配置／
  素材需求／追蹤建議，各一個圖示＋標題＋一行說明。**純靜態文字**，不承諾任何這一期做不到的東西
  ——「追蹤建議」那一格的說明寫「成效追蹤的設定建議（自動發布接上後開放）」。
- 底部兩顆按鈕（置中，圖 4）：`Button` 「產生策略建議 →」（default）與 `Button variant="outline"`
  「返回修改」（回 `/brands/${brandId}/ads/new`）。
  - 「產生策略建議」＝ `generateStrategy(brandId, campaignId)`（既有 API），按下去 disabled ＋
    文字改「產生中…」，成功後 `navigate(\`/brands/${brandId}/ads/campaigns/${id}?tab=strategy\`)`。
    失敗印一行紅字，按鈕回復可按（**不是死路**）。
  - 這是整個流程裡第二次、也是最後一次模型呼叫（ARCHITECTURE.md §6.1 第 11 條）：
    寫一行註解，免得下一個人在這頁加第三個「幫我想想看」按鈕。

# Blocked if

- 六張卡裡有一張沒有現成的 PATCH 欄位可以存（受眾方向就是這種，已經指定唯讀）——**不要**為此
  改 `app/**`；照唯讀處理並在完成回報裡說明。
- `fetchProductList` 需要的權限／參數跟 ads 頁面對不上 → 商品卡退成唯讀（印 id 以外的東西都行，
  唯獨不准印 raw id），release 說明。
