# Objective
Two exits land where they say (feature outcome 6; drill-10 D3, D4): 「設定 N 月月預算 →」 / 「提高 N 月月預算」 open the monthly-budget
form instead of the ads home top, and picking an ad account assigns it without a second 「指定給這個品牌」 click. No new layout:
the existing form and panel, opened in the right state.

# Done
1. `PublishList` and `ConfirmPage` pass `budgetHref = /brands/{b}/ads?budget=edit` to `BudgetFitCard` (one shared builder or
   constant, not two string literals).
2. `AdsHomePage` reads `budget=edit`: `MonthMoney` opens its adjust area on load and scrolls it into view; `MonthlyBudgetPanel`
   gains a `startEditing` prop that opens the edit form once the budget is read (amount = the saved amount, empty when unset —
   no invented default). Closing the area removes the param (back / reload do not reopen it).
3. `MetaConnectPanel`: choosing an unbound account calls the existing assign at once (「指定中…」 on that row while it runs; a
   failure shows the existing error and leaves the radio unpicked); the separate 「指定給這個品牌」 button goes; an already bound
   account stays disabled with 「已指定給這個品牌」. The 「權杖已存，還沒指定給這個品牌。」 line stays until one is bound.
4. Tests: both budget links carry the param; the home opens the form with the param and not without it; the account radio assigns
   on change, shows the busy and error states.
