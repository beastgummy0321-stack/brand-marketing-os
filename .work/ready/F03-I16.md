# Objective

The campaign is published, watched and closed. §0: it serves the **action → outcome → verdict**
links; its input is the publish/performance/close payloads (F03-I09, I10, I11, I12); its output is
a bound, running campaign and a verdict a person can read; its trace is the checklist the user
actually followed, the bind result, and the verdict card with its numbers; it is **core**.

# Done

- **發布** (prototype `screen-manual.js`): the campaign header's primary action 「發布 Campaign」
  opens the publish screen. The normal path shows 自動發布未接上 as a plain state (never as a
  refusal, never as an instruction to go run real ads); the 「⋯」 menu carries 手動發布（進階） and
  模擬發布（演練用）.
  - 手動發布: one card per group and per ad, each field with a `CopyIconButton` (name, daily budget,
    dates, the selected copy and image prompt when present), in the order they must be created;
    then 「我已在 Meta 建好，開始配對」 → the bind result: matched n／m, and for anything unmatched the
    backend's own message rendered verbatim (it already knows whether the cause is 沒綁帳戶 or a name
    mismatch — the browser must not re-word it), plus 重新配對.
  - 模擬發布: a confirm stating it creates 示意資料 for a walkthrough, then the same result surface.
  - On full success the campaign turns 投放中 and the screen offers 查看成效.
- **成效 tab** (prototype `screen-performance.js`, minimal fidelity — **no suggestion cards, no
  為什麼這樣建議 panel**, those are feature 2): KPI row (花費／購買／CPA／ROAS／點擊率／曝光) each
  captioned with its window and source; the daily trend chart drawn with ECharts through the
  existing `lib/useEchart.ts` — `docs/design-system.md` §7 was amended by F03-I13 to allow exactly
  this chart, so no further docs change is needed or allowed here; a per-group and per-ad table
  with spend share; 未追蹤 and
  累積中 where the data is `NULL`, never `0`; 資料更新時間.
  Before publish the tab is one honest empty: 「還沒有成效資料」 with what will appear after publish.
- **結案**: on an ended campaign the tab shows 立即結案 with a confirm that states the consequence
  (verdict written, learning written, campaign locked); after closing, a verdict card — 達成／未達成／
  看不出 with the compared numbers, the window, the sample bucket, and the learning sentence with a
  link to 品牌智庫. 看不出 is rendered as a legitimate result, not as an error.
- `CampaignWorkspace.tsx` mounts the tab and the publish entry; `adsApi.ts` gains only what is
  missing.
