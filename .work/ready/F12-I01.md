# Objective

同頁收合與編輯保護。使既有收合與受影響編輯表單符合 docs/design-system.md §F12，不搬移模組、不建立跨站設定框架。

# Done

- Disclosure 保持既有呼叫相容，收起後保留已掛載的草稿；隱藏內容不能被 tab 聚焦或輔助工具誤讀。不得為保持草稿而預先啟動原本未展開的昂貴請求。
- 需要定位缺漏的呼叫端可明確展開並聚焦正確欄位；手動設定避免要求使用者猜多層分類。保留明確儲存、取消；收起不觸發任一動作。
- 一般摘要呈現生效值、已自訂／未儲存、範圍。草稿留在所属頁面，不串品牌／活動；切頁有未存變更時提供離開保護，不以每次收合都彈確認打擾。
- 修改圖示有具體可存取名稱；已保存值與畫面一致，資料重新讀取不默默覆蓋 dirty 草稿。已有規則卡恢復能力留在其所有者，不複製後端規則。

# Verify

測試輸入→收起→展開→保存；巢狀缺漏定位；儲存失敗保留；離開／取消；品牌活動切換隔離；鍵盤不可進入隱藏內容。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
