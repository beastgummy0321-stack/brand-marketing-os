# Objective

（F04-I09），全部的、可篩可搜的清單在這一頁。§0 連結：**next goal**（回頭找到任何一次投放）。

**動手前先用 `docs/design/ads/02-campaign-list.png` 呼叫 `Skill impeccable:impeccable`**（R6）。
圖上的縮圖、插畫、手寫貼紙、右上「＋ 新增 Campaign」以外的裝飾都不做；每列左邊的商品縮圖
**不做**（我們沒有那個資料，design-system §7：資料沒有就不先長出外觀）。

   （圖上第三格是「需要決策的 Campaign」——F04 沒有那個資料，改成已結束，**不要印一個算不出來
   的數字**。）
3. 篩選列：四顆 pill（`Button variant` 切換 active／outline，或 `Badge`＋按鈕，用既有 kit）：
   `全部`／`進行中`／`即將上線`／`已結束`，每顆帶筆數；右邊一個 `Input` 搜尋框
   （placeholder 「搜尋 Campaign 名稱」，只比對名稱，`toLowerCase().includes`）。
   圖上的「所有目標」「最新建立」兩個下拉**不做**（排序固定 `created_at` 新到舊，後端已經這樣回）。
   狀態對應：進行中＝`live`；即將上線＝`draft`／`ready`；已結束＝`ended`／`closed`。
4. `table-surface` 表格，欄位照圖：
   | Campaign 名稱 | 狀態 | 目標 | 預算進度 | 行銷駕駛艙一句判斷 | 建立時間 | （動作） |
   - 名稱：粗體名稱＋第二行 muted 的 `goal_text`？——**沒有**（清單 payload 沒有 goal_text），
     只印名稱。
   - 狀態：`STATUS_LABEL`／`STATUS_TONE`，從 `./AdsHomePage` import（同資料夾內可以直接
     import 檔案，不必經 index.ts）。這張票排在 F04-I09 之後就是為了這個：I09 重寫首頁時
     那兩張表照樣 export（它的 Done 有寫），你進來時它們一定還在。

   - 預算進度：上面一行 `{pct}%`（`pct === null` → `spent === null ? "未追蹤" : "未設定"`）、

     `{formatCurrency(spent)} / {formatCurrency(total)}`；`total === null` 時整行改成「尚未設定總預算」，

     紅／綠以外的自創色。
