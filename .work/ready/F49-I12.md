# Objective
The publish pages say once, at approval, which fields no platform read can see, and the readback then checks only what can be
read and names why a read failed (feature Contract B; decision 5; drill-11 R3 E2／B11, E3; frontend-ads F2). Today every launch
reads 「7–8 項讀不到，請到 Meta 看一眼」, the user presses 「全部標記」 for fields nobody can ever prove, two items lose their buttons
in a race (「核對期間來源已更新」), and the launch-item states are worded locally.

   launch view's `approval_confirms`; the month-budget card gets `returnTo` = this page's path (F49-I11's prop).

   sentence. The header counts no longer count declared fields as 讀不到.
