# Objective

投放中心首頁從「一張 Campaign 表」變成參考圖 `docs/design/ads/01-home.png` 的四塊判斷。
§0 連結：**outcome → next goal**——使用者每天第一眼要看到的是「現在怎樣、有沒有事要我決定、
在跑的是哪幾個、系統最近做了什麼」，不是一張需要自己解讀的表格。

**動手前先用 `docs/design/ads/01-home.png` 呼叫 `Skill impeccable:impeccable`**（R6）。
圖是版面方向：區塊順序、欄寬比例、卡片密度照圖；顏色／字級／圓角／圖示用 tokens 與 lucide。
圖上的插畫、吉祥物、紫色手寫字、「持續優化，讓好表現再放大！」那種貼紙**都不做**（R3）。
圖上的「本月投放整體正常」「表現優於預期」是示意文案——**真正的句子一律用後端給的
`judgment.text`／`headline.text`**（F04-I08 已經把它們算好了，R7：判斷句是程式的）。

# Done

資料：一支 `getAdsHome(brandId)`（F04-I08 已提供）。**不要**再呼叫 `listCampaigns`，不要在
瀏覽器端算任何判斷句或百分比。載入中用既有 `Skeleton`，失敗用既有 `EmptyState`＋重新載入
（沿用這個檔案現在的 `LoadState` 寫法）。

版面（由上而下，全部用 `patterns/` 的元件，不自己寫卡片）：

- 檔案頂端的 `STATUS_LABEL`／`STATUS_TONE` 兩張表**原封不動保留並繼續 export**（清單頁票
  F04-I10 直接 import 它們；狀態文字只有一份）。
1. **`PageHeader`**：title 「投放中心」，description 「讓行銷駕駛艙幫你持續優化廣告投放。」
   右側 actions 保留現在的「建立 Campaign」按鈕（連到 `/brands/${brandId}/ads/new`）。
   圖上右上角的日期區間選擇器**不做**（沒有那個資料來源，design-system §7 最後一段）。
2. **`JudgmentBand`**：`sentence = home.headline.text`、`facts = home.headline.facts`，
   icon 用 lucide `BarChart3`。
3. 兩欄 grid（左 2/3、右 1/3，1024 寬時仍不可橫向捲動——必要時右欄降到左欄下方）：
   - 左欄上：**`DecisionCard`** `items={[]}`（F04 沒有建議產生端）→ 它自己會印
     「目前沒有需要你決定的事」。標題列的件數 badge 不出現。
   - 左欄中：一張 `surface`，header 「進行中的 Campaign」＋右側連結
     「查看全部 →」 → `/brands/${brandId}/ads/campaigns`（清單頁的路由由排在後面的 F04-I10 建立；
     在它合併之前這個連結會落到工作區的 404 分支，這是刻意的順序，不要為此改 `App.tsx`）；
     body 是 `home.campaigns` 每筆一張 **`CampaignTile`**（`grid-cols-3`，1024 時 `grid-cols-2`），
     點整張卡進工作區 `/brands/${brandId}/ads/campaigns/${c.id}`。
     props 對應：`name`、狀態 badge 用這個檔案既有的 `STATUS_LABEL`／`STATUS_TONE`
     （**這兩張表維持 `export`、名字與值一個字不改**——F04-I10 的清單頁 import 它們）、
     第二行 `目標・通路` 用 `objective`（通路資料首頁沒有，就只印 objective，**不要**硬寫 Meta）、
     `spendText = spent !== null ? formatCurrency(spent) : "還沒有花費資料"`
     （`budget_progress.spent` 為 `null` ＝一列成效都沒有，F04 Decisions 第 12 條：**不准印
     NT$0**）、
     `budgetText = budget_progress.total !== null ? formatCurrency(total) : "尚未設定總預算"`、
     `percentText = pct !== null ? \`${pct}%\` : (spent === null ? "未追蹤" : "未設定")`
     （`pct` 為 null 時 `percent={0}`，**不要印 0%**）、
     `judgment = c.judgment.text`、`judgmentDetail = c.judgment.detail`。
     `home.campaigns.length === 0` → 卡片區改成一行 muted 置中字
     「目前沒有進行中的 Campaign。」（不是 `EmptyState`，這是卡內空狀態）。

# Blocked if

- 需要後端沒給的欄位（例如每個 Campaign 的通路、或建議清單）→ **不要**自己 fetch 別的端點、
  不要改 `app/**`：release 並說出缺什麼。
- 版面在 1024 出現橫向捲軸而你只能靠固定寬度解決 → release（`width-overflow` e2e 會擋）。
