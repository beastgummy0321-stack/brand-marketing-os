# Objective
Every 「停掉／暫停」 entry lands on a pause page that reads the ad itself (feature outcome 2, screen). Layout spec = the prototype
`.harness/scratch/prototype/f45-slot-states/index.html` routes `#/c2/pause/<id>?from=…` (proposal, `m6` already paused, `m9` not
found), `#/c2/perf` (the 「暫停」 row button), `#/c2/review/m3` (停掉這則 → 下一步), `#/c2/verify` (暫停舊廣告). Data = Contract P
(`docs/architecture/ads.md` §6.49, F45-I05).

# Done
1. `adsTriageApi.ts`: `getPauseView(brand, campaign, entityId, signal)` with the Contract P type.
2. `ConfirmPage` in pause-propose mode (`propose/pause/:entityId`): builds from Contract P (via a small hook, e.g.
   `usePauseView.ts`); the queue read only adds 「第 n 件／共 N 件」 when the ad has a row, and its failure no longer blocks this
   mode. The draft is created from Contract P's `triage` (name, entity id); an existing `change_set_id` is reused. The other
   propose kinds (budget, cleanup) and the `changes/:setId` path keep reading the queue as today.
3. States as the prototype: `active` → 「提議：暫停這則廣告」, evidence card (花費／成交／每筆成本／評級, meter against the cap; for zero
   sales the 「上限 × 3」 line), 「這則廣告自己的數字・〈window〉」, the angle card, 核准／拒絕暫緩, back to `from`; `closed` →
   「這則已經停了」, the card with 「已暫停・〈MM/DD〉在平台上關掉」 (date omitted when `closed_at` is null) and one
   「← 回上一頁（〈from label〉）」; `gone` → 「找不到這則廣告」, 「〈name or 這則廣告〉在平台上已經刪除，系統讀不到它，沒有東西可以暫停。」
   plus 「（最後一次讀到是 MM/DD）」 when `last_read_at` is set, and 回投放中心. Contract P read failure → the existing `ReadFailed`
   with 重試.
4. `proposePausePath(brand, campaign, entityId, from?)` adds `?from=perf|review|verify&ref=…`; back target and label: perf → the
   campaign's 成效 tab 「成效」, review → that review round 「覆盤」, verify → that set's verify step 「核對結果」, none/unknown →
   「投放中心」. Callers: `PreparePage` retire (`from=review`, ref = review id), `VerifyPage` follow-up and stale restart
   (`from=verify`, ref = set id), `home/status.ts` keeps no `from`.
5. 成效 tab (`GradeGroups` rows on `CampaignDetailPage`): every active ad row gets the 「暫停」 button of the prototype (to
   `proposePausePath(…, from=perf)`); closed rows keep their 已暫停 look.
6. Tests with real-shaped Contract P fixtures: the three states; no queue row → no position, page still works; queue read failure
   in pause mode → page still works; draft created from Contract P; back links per `from`; the 成效 row button href.
7. Deliver 「參考圖｜成品」 for the proposal, already-paused, not-found and 成效 row.
