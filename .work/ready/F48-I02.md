# Objective
Every judgement that is not the ruler derives from it (feature Contract R, "ordering／verdict", "derived rulers",
"reason texts"): cleanup closes in `learning_rank`'s order with sample size shown; settle fates, the closeout verdict,
confidence, visual learning, the month review and A/B thresholds read the two ruler modules; pause／cleanup／scale reasons are
program sentences from the ad's own grade.

# Done
1. `triage_capacity.cleanup_candidates`: build `learning_rank.rank` rows from the campaign's graded active items
   (`grade in triage.GRADED`; row = `{entity_id, name, spend, results, currency, cap}` from `item["current"]` and
   `item["target"]`), close from the bottom: every 沒賣出 (verdict `replace`, `cost_per_sale is None`), then `replace` sold
   rows most expensive first while `active_ads − can_support > closed`; `keep`／`keep_relative`／ungraded／open-lineage never
   close. Delete `_CLOSE_RANK`／`_KEEP_RANK`; `GRADE_RANK`／`got_worse` stay (decision memory). `ads` and `keep` entries carry
   `rank, of, sales, few, verdict, verdict_label, flags, reason_text` and come in rank order (`keep` = the kept rows in rank
   order, closing rows after). `reason_text`: 「第 r／n 名，每筆 X 對上限 Y（太貴）」／「花了 X，一筆都沒賣出」／「第 r／n 名，每筆 X
   在上限內（划算）」 — numbers through `learning_rank.whole`.
2. `triage_capacity.can_support(daily_budget, target_value)` pure (`capacity_view` calls it; F48-I06 reuses it).
3. `triage_scale.scale_candidates`: unchanged qualification plus the stated reason — an owner whose active ads' summed sales
   < `triage.MIN_RESULT_EVENTS` is not proposed and the campaign's queue／triage read carries `scale_hold {owner_id,
   reason_text: "樣本少，先不加碼"}` (shape your call, documented in the docstring); the raised row carries `scale.reason_text`
   「近期每筆 X 都在上限 Y 內，加碼 {SCALE_FACTOR−1 as 成} 擴量」 built from the owner's cheapest 划算 item.
4. `triage_pause.view`: `pause.reason_text` from `triage` (grade + numbers, same sentences as 1; 剛開始／資料不足／未判斷 →
   「這則還沒有分數：〈label〉」); `null` when `triage` is null.
5. `settle._FATE` → derive from `learning_rank`: per campaign, rank the month's `grade_period` rows of that campaign and map
   `keep`／`keep_relative` → effective, `replace` → ineffective, unranked → skip (reason 「沒有可排名的數字」); the written
   scope becomes `ads;campaign=<id>;group=<customer_group_id|none>` (group through the entity's bound `ads_ad`, as
   `coordinate_learning` maps it); `_totals` 「有效」 counts keep rows. The settle page payload rows carry `rank, of, sales, few`.
6. `closeout._judge`: verdict 達成 if `actual <= target` else 未達成 whenever both are known; `sample_bucket` no longer flips
   it — `verdict_json.sample = {purchases, days, bucket}` is kept for display and `missing` is set only for an unknown
   cap／actual. `outcome.sample_bucket(purchases, days)` accepts `None` → `"未追蹤"`; `closeout` passes the real value.
   `learning._confidence` counts same-direction campaigns whose `verdict_json.sample.purchases >= triage.MIN_RESULT_EVENTS`
   (this campaign included; below it → `observed`). `visual_learning`: `purchases is None` → skip with 「成效未追蹤」 (checked
   first); 低 sample writes the row with `sample_size="低"` instead of skipping.
7. `month_summary._verdict` → `triage.cost_grade(cost, cap)[0] == "on_target"` → met, other graded → missed, else unjudged.
   `experiments.DEFAULT_RULES` = `{"min_days": triage.WINDOW_STEPS[0], "min_conversions_each": triage.MIN_RESULT_EVENTS,
   "relative_difference": 0.10}`; `ab_pairs.RULES` reads the same.
8. Tests: cleanup orders two sold ads by cost per sale regardless of grade label (H1: 634／4 sales kept, 1,009／1 sale
   closed when over capacity); a 沒賣出 ad closes before any sold one; `keep_relative` never closes; settle fates equal
   `learning_rank.is_keep`; a 7-day campaign with 9 purchases closes 達成／未達成 (not 看不出) with `sample.bucket == "低"`;
   confidence stays `observed` below 10 purchases; `visual_learning` with `purchases=None` writes nothing and says why;
   `GET …/triage/{e}/pause` carries `reason_text`; extend `test_ads_one_ruler.py` so the AST scan also fails on a new
   `_FATE`-style dict keyed by grade words outside `triage.py`／`learning_rank.py`.
