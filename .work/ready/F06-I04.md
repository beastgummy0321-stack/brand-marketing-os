# Objective

The publish screen stops being a dead sentence and warns instead of silently letting the user build
empty ads (ARCHITECTURE.md §6.2 decisions 17–18). While auto publish is not connected, the screen
offers the two working paths as buttons, 手動發布 and 模擬發布（演練）; the header's ⋯ menu goes away.
When some ads have no assets, a big red band says so and offers 「回到素材」. The band blocks nothing,
and 模擬發布 never shows it. Reference image for the band: `docs/design/ads/08-preflight.png`, the red
「還有 1 件事需要處理：…」 row with its button on the right.
