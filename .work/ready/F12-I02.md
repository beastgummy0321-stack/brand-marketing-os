# Objective

投放模組比較設定契約與實際判讀。依 docs/architecture/ads.md §6.8 的確定契約，讓選用比較的進階參數實際生效；由 ads 擁有整理、驗證、快照與判讀，零新增 LLM 呼叫。

# Done

- GET 回應新增結構化 settings；PUT 同一路徑保存本活動 overrides，POST 仍僅確認提案。前端 lib 與後端語義一次對齊。
- 合法天數、每則轉換門檻、相對差異與觀察窗由程式驗證；還原單項不影響其他自訂。有效設定供提案、文字、指紋及 judge 共用，禁止 UI／後端各自維護規則常數。
- 使用 ads_campaign.context_json 獨立命名空間，保留其他 context；鎖定活動、檢查設定 revision，避免併發覆蓋。保存不確認、不改預算／素材／平台、不刪歷史資料。
- 既有 plan 缺新欄位視為原預設，純部署不使原計畫失效；相關有效值改變才要求重確認。結案禁止修改。
- 保留真實未追蹤、模擬來源、缺日／樣本不足／非隨機限制；未支援指標回傳明確不可用狀態，不能套用購買規則假裝支援。平台與指標沿既有投影，不新增平台預設。

# Verify

涵蓋非預設門檻確實改變判讀、單項還原、非法值／未知鍵拒絕、過期與舊計畫兼容、觀察窗、併發 revision、closed、跨品牌組織拒絕。以假 gateway 證明設定／提案／判讀不呼叫 LLM。
# Blocked if

需要 Full auto、新平台整合、新 LLM 呼叫、未規劃 schema／依賴／跨模組入口、放寬租戶或費用保護，或發現影響既定產品行為的新分歧時停止該部分並回報；一般範圍內缺陷直接修正。不得擅自擴張。
