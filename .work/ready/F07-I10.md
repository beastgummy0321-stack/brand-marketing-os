# Objective

投放中心's dispatch decides the image work per ad and the workbench only renders it: single-image ads
get a variant count from the plan, carousels none, video ads get copy + video script and no image, and
no stale style/count/彈性 parameter is sent; the manual checklist shows the image prompt the user
actually selected. The user: 「依照排程決定，不一定每期每組每個素材都要10張變體」「影片廣告不用出圖」. Rules:
ARCHITECTURE.md §6.3 item 21, §5.4 (`variant_count`); F07 Decision 30.
Never delete or overwrite anything under `data/`.

# Done

1. `app/ads/assets.py`:
   - Delete `_image_prompt_count` (and its 彈性格式 docstring).
   - `_ad_set(ad, group, campaign, campaign_id, fallback_product_id)` (update the one caller in
     `dispatch_pack` to pass each ad's group and the campaign row):
     - `format_key = ad.get("format_key")`;
     - `video` → `required_outputs = {"copy": 1, "video_script": 1}` and `request.video_script_count = 3`;
     - `carousel` → `{"copy": 1, "image_prompt": 1}`, `request.variant_count = 0`;
     - anything else (`single_image`, a stored `flexible`, `None`, a brand-made key) →
       `{"copy": 1, "image_prompt": 1}`, `request.variant_count = _variant_count(group, campaign)`;
     - no `style_key` key and no `image_prompt_count`; everything else in the set payload unchanged.
   - `_variant_count(group, campaign) -> int`: `days = plan._days(group.start_date, group.end_date) or
     plan._days(campaign.start_date, campaign.end_date)`; `0` → 6; else ≤7 → 3, 8–21 → 6, >21 → 9;
     `+3` when `group["role"] == "retarget"`; `min(…, 9)`. If importing `app.ads.plan` into `assets.py`
     creates an import cycle, inline the same three-line day count instead, with a comment naming
     `plan._days`.
2. `app/ads/routes.py::_enriched_campaign`: `ad["image_prompt_text"]` = `image_output["body_json"]["text"]`
   only when `image_output` is not `None`, `image_output["is_adopted"]` is true and `text` is a non-empty
   string; otherwise `None`. Delete the old `rendered` str/list branches. The copy branch is unchanged.
3. Tests:
   - `test_ads_assets.py`, with the existing `wraps=submit_pack` pattern (`test_ads_assets.py:243`):
     each set has no `style_key` and its `request` has no `image_prompt_count`; a single-image ad in a
     `new` group with campaign dates spanning 7 / 8 / 21 / 22 days → `variant_count` 3 / 6 / 6 / 9; the
     same in a `retarget` group → 6 / 9 / 9 / 9; no dates anywhere → 6; group dates win over campaign
     dates; a `carousel` ad → 0; a `video` ad → `required_outputs == {"copy": 1, "video_script": 1}`,
     `video_script_count == 3`, no `variant_count`; a `flexible` ad follows the single-image rule;
     `dispatch_pack` still succeeds end to end (the workbench accepts every set).
   - `test_ads_publish_manual.py`: patch `routes.workbench.adopted_output` via `mock.patch.object`
     (never import workbench internals or write `workbench_*` rows): an adopted §5.8-shape row → the
