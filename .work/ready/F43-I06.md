# Objective
The model calls of product onboarding: (a) the product-page prefill that fills `#/p1`–`#/p4` (「✦ AI 從商品頁讀到」), (b) the product
blocks of 「自訂」. Same rules as F42-I05: one gateway call each, contract-checked, nothing confirmed by the model.

# Done
1. `app/intake/product_prefill.py`: background job (registered in `__init__.py`, lock per product) on product creation with a
   `page_url` and on an explicit re-read: fetch the page (`net.fetch_url`, + up to 3 product photos already uploaded as image blocks),
   task type `intake_product_prefill`, one call. Contract: `{intro, mechanism, difference (each {value, note}), groups: [{who,
   pain_keys ⊂ PAIN_KINDS (1–2), quote, when_used, note}] (≤3), proof: [{fact_key ∈ PROOF_KINDS, text, note}], claims: [{text,
   note}] (≤8), sell_ways: [{name, qty, price, list_price|null, note}] (≤4)}`. Invalid entries dropped; unreadable reply → job
   failed with the existing message. Stored in `intake_product_prefill`; `GET …/onboarding` reports status; routes
   `POST …/products/{p}/onboarding/scan` (re-read). Draft cost cap refuses before calling. Quotes must be verbatim from the page or
   absent (prompt rule); no web search.
2. `custom.py` blocks for products: `difference` → value; `group` → `{who, pain_keys, quote, when_used}`; `pain` → `{pain_key, quote}`
   (a worry mapped to one of the six); `product_proof` → `{fact_key, text}`; `claim` → `{text, verdict: "ok"|"no"}` with statutory
   hits forcing `no`. `POST …/products/{p}/onboarding/custom`.
3. `providers.py`: label, thinking (low) and `SCRIPTED_REPLIES` for `intake_product_prefill` (and the new custom blocks share
   `intake_custom`'s reply only if its shape passes; else add per-block scripted replies keyed the way the provider supports).
4. `intakeProductApi.ts`: scan + custom clients/types.
5. Tests: prefill drops an out-of-vocabulary pain key and a 5th group, stores the rest, cost cap refuses; custom product blocks happy
   path + contract failures; statutory claim forced to `no`; scripted replies pass their contracts.
