# Objective

投放結構分頁的廣告面板寫死「實際花費占比（觀察值）：尚未追蹤」（`DeliveryTab.tsx:558-563`），
可是成效分頁**有**那張「廣告花費占比」表（F03-I16）。硬寫的「尚未追蹤」在成效已經回來之後
還是照說一次，那就從「誠實」變成「說謊」。F03 整合審查把它記下來，這張票關掉它。
§0 連結：**outcome**（每個數字都要說得出它是哪一段期間、哪個來源）。

**最省的正確做法**：不在這一頁多打一支 `getPerformance`（這個面板每選一支廣告就會重建，
多一次 fetch 是為了一行字；成效分頁已經有完整的表）。改成把人指過去。
