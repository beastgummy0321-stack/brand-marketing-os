# Objective

素材 and 成效 stop being dead ends: both end with the shared next step from `nextStep(c)`
(ARCHITECTURE.md §6.2 decision 15).
- On 素材, once every ad is ready, a full-width primary 「發布 →」 opens the publish screen.
- While the pack is being made, 素材's own action is 「前往素材工作檯 →」.
- The dispatch button leaves 素材 (the handoff lives on 投放結構, §6.2 decision 16), but the pack-level
  「查看素材任務包」 link stays.
- An ad added after the handoff is labelled on its row, so the user knows to tick it.
- A manual tick refreshes the campaign, so the rule never reads stale readiness.

Runs after F06-I02, so the branch is never without a handoff button. Reference image for the button
shape: `docs/design/ads/05-strategy.png`.
