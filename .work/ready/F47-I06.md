# Done
1. Stores (all through `app.core.input_rules`, F47-I01): monthly budget total `> 0` (unset stays `null`); group dates end `>=`
   start, the stored side counting when one side is patched (`plan.update_group` / `create_group`, route maps a new
   `dates_reversed` code to 「結束日不能早於開始日」); copy apply (Q6): an empty field keeps the current text, all empty refused
   (`user_assets_repository` / route, per Contract A).
2. Launch settings: `pixel_id` checked by the platform adapter's own rule (`adapters` registry: Meta digits 10–20; a platform
   without a rule accepts any non-empty text); `bid_amount` per Contract A — the card shows a money field when the strategy is
   `cost_cap` / `bid_cap`, the handoff copy (`LaunchSettingsCopy`) prints 「出價方式：〈label〉 〈amount〉」, readback ignores it.
3. Pixel (R5): when the list cannot be read and the settings are locked (approved), the sentence names the lock and the current
   value and drops 「請手動填在下面」; when editable, the typed field is enabled. A stored readback error shows its read time
   (「M/D HH:MM 讀回時讀不到：〈原因〉」) next to 「重新讀回」; a later successful readback replaces it.
4. Q5: saving 「各廣告組的其他設定」 refreshes the approval state the list uses (the same reload `onCampaignSaved` triggers), so
   「核准上架清單」 does not 409; a 409 that still happens says 「設定剛改過，已重新讀取，請再按一次核准」 and reloads.
5. Monthly budget (`MonthlyBudgetPanel`): sends what was typed, shows the server sentence; after a save the home money card
   re-reads (W3: home passes its reload); 「調整月總額」 opens the editor. `PaceChart` draws nothing (no NaN) for a 0 / unset
   total and says 「還沒設月預算」.
6. Disabled with reason (`disabledReason`): 「改期間」 完成 (`ConfirmBriefPage`, the invalid field), 「在這一組新增廣告」 「新增」
   (which dropdowns are still empty), 「已回報人工操作」 (`ManualHandoffPanel`, what is missing). No-reaction controls:
   「新增素材需求」 scrolls to and focuses the request cards (or is removed where the cards are already the only content), 「建立變更
   清單」 opens the composer or says why it cannot.
7. Money: every per-sale / money figure uses `formatAmount` without `Math.floor` (`MonthMoney`, `TodayDecisions:299`,
   `AbEvidence`, `PeriodStatusRow`) — home and performance show the same 2,015; `patterns/csv.ts` writes numbers rounded to 2
   decimals (both CSVs).
8. Titles from data: `PublishPage` says 「首次上架」 only for a campaign's first launch (later: 「第 N 期上架」 or the campaign
   name — worker picks from the data the page already has); the review breadcrumb uses the row's own kind label, not a fixed
   「變貴」; `/wait`'s title follows the data state (not a fixed 「資料不足」).
9. Tests for each rule and screen above; `ads-cold-start.spec.ts` still passes the placement edit (update only if a label
   changed).
