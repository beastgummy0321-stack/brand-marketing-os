# Done — wording that must hold (acceptance; the reviewer checks each)

These four rules apply to `image_prompt.md` and `image-prompt-template.md` alike. State each rule
once per file and do not restate it differently elsewhere.

1. **Adopted headlines are an optional hint, never a source.** The worksheet *may* contain
   `可用的大標（可用可不用）：「…」`. The model may use it, adapt it or ignore it; when it is absent
   the model still returns a complete reply. No sentence may say or imply that `headline`,
   `subhead` or `on_image_line` is taken, chosen, picked or copied from adopted headlines or
   「附上的標題」, in either mode (§5.7: an image prompt can run before any copy is adopted). The hint
   lives only in the worksheet section, never in a skeleton.
2. **探索模式 has no coordinates.** Describe the inputs per mode, exactly as in the template's §1.
   No sentence lists 受眾, 痛點, 切角 or 標題公式 as an input of 探索模式. No intro paragraph
   describes "the brief's coordinates" as if both modes had them. (The 切角 in ③ is the model's pick
   from `creative-matrix.md` §1, not a coordinate.)
3. **The model writes the on-image wording; 可用字句 does not limit it.** `headline`, `subhead` and
   each `on_image_line` are new copy written for this image. 可用字句 is not a whitelist of allowed
   wording. The only limit is rule 4.
4. **Numbers and factual claims (price, discount, spec, certification) come from 可用字句 or the brand
   context.** A number on the image must appear verbatim in the 可用字句 lines **or** in the brand
   context; a number found in neither may not appear. When the 可用字句 line is absent, numbers that
   appear verbatim in the brand context are still allowed (F01-T03-I02's `check_image_prompt`:
   `quotable_text` = promotion-note lines + compiled brand context). No sentence may say
   "no 可用字句 → no numbers".
