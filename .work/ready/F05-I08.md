# Objective

使用者：「廣告中心有排過就 Agent 自己抓歷史數據建議金額，沒排程過就由系統算出最佳試驗金額去做
投放。」

現況：`app/ads/repository.py:381 budget_history` **只讀 `ads_outcome_daily`**，也就是只認得新迴圈
自己跑過而且已經結案的 Campaign。一個有 37 個月 Meta 歷史、剛接上帳戶的品牌，第一次建 Campaign
照樣走「冷啟動估算」——使用者宣告的「有排過」在系統眼裡等於沒排過（演練四 V-13：第二圈推薦
137,795，她宣告的預算是 60,000，而且仍然印冷啟動）。

修法：沒有迴圈歷史時，退回讀這個品牌自己綁的廣告帳戶。**數字全部程式算，模型不讀廣告歷史**
（ADR 0067；`ARCHITECTURE.md` §8 第 5 條）。

# Done

## 1. `app/ads/channels.py` 多一支（平台名字只准住在這裡）

```python
def account_spend_history(conn, org_id: str, brand_id: str, conversion_goal: str | None) -> dict | None
```
- 這個品牌有綁的通路才問得到；目前只有 `meta` 答得出來，走
  `app.meta.repository.bound_account_ids_for_brand` ＋ `spend_summary(...)`
  （`level="campaign"`、半開區間 `[今天−30, 今天+1)`、把 `conversion_goal` 傳進去——那支的
  docstring 明講 CPA 要用哪個事件是呼叫端決定的）。「今天」用
  `app.core.settings.today_for_org`，不是機器的 `date.today()`。
- 回 `{"cpa": float|None, "daily_spend": float, "days": 30, "channel_label": "<label>"}`；
  沒綁帳號、或 30 天總花費是 0 → `None`。
- `spend_summary` 的 `total["cpa"]` 是 None（沒追蹤到轉換）時，`cpa` 就是 None——**不要用
  ROAS 反推、不要拿 0 當分母**。

## 2. `app/ads/repository.py::budget_history`

現有的 `ads_outcome_daily` 路徑成功時，多回兩個鍵：
`"source": "ads_loop"`、`"source_text": "上一期日預算"`。

原本兩個 `return None` 的地方（沒有日 CPA、沒有已結案的 Campaign）改成退回帳戶歷史：

```python
    hist = channels.account_spend_history(conn, org_id, brand_id, brand_conversion_goal)
    if hist is None or hist["daily_spend"] <= 0:
        return None                      # 什麼都沒追蹤 -> 誠實冷啟動，維持現狀
    return {"last_daily_budget": round(hist["daily_spend"]), "cpa": hist["cpa"],
            "sample_days": hist["days"], "sample_ads": None,
            "source": "meta_account",
            "source_text": f"{hist['channel_label']} 近 30 天平均日花費"}
```

`brand_conversion_goal` 從 `app.brand_intelligence.repository.get_brand` 讀（既有 facade），
在這支函式裡讀一次就好。

## 3. `app/ads/budget.py::_history_scenarios`

    base_text = history.get("source_text") or "上一期日預算"

## 4. 測試

`app/tests/test_ads_budget.py`：
- `history = {"last_daily_budget": 500, "source_text": "Meta 近 30 天平均日花費", ...}`
  → 三張情境卡的 caption 帶得出那句話，金額仍是 300／500／800。
- 沒有 `source_text` 的舊形狀 → caption 仍是「上一期日預算 …」（不准把既有行為改壞）。

`app/tests/test_ads_strategy.py`（已經有 `budget_history` 的測試）：
- 有已結案 Campaign 的花費 → `source == "ads_loop"`（現有行為）。
- 沒有迴圈花費、但有綁帳戶且 `meta_entity_spend` 有近 30 天的列 → `source == "meta_account"`、
  `last_daily_budget` 等於總花費 ÷ 30 四捨五入。
- 沒有迴圈花費、也沒有綁帳戶 → 仍然回 `None`（冷啟動）。
