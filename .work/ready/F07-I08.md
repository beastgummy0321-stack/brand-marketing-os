# Objective

The 圖片 tab's data ships as text from the backend: 10 selectable cards with badges (主力／探索, 建議選這張)
and fingerprints, one 複製全部 block, a ② 變體 card with exactly the plan's count on the selected
single-image card, the eight 生成設定 rows, the pack-level exploration warning, and the 品牌事實
negatives warning. Rules: ARCHITECTURE.md §5.7 (② count), §5.9 (exploration warning, visual-spec route),
§5.11, §5.13; F07 Decisions 26–29. Row shape: §5.8 (written by F07-I07). Never delete or overwrite
anything under `data/`.

# Done

1. **`app/workbench/image_cards.py` (new, pure)**:
   - `prompt_cards(body, *, version_index, selected, variant_count) -> list`: `[]` when `body` has no
     string `text` (a pre-F07 row); else `[{label: f"{version_index:02d}｜{title}", text}]`, plus
     `{label: "② 變體", text: variant_text(body, variant_count)}` when `selected`,
     `visual.shape_for(body.round.format) == "single"` and `variant_count > 0`.
   - `variant_text(body, count)`, exactly F07 Decision 27: lead with `count`; the ratio sentence from
     `visual.RATIO["single"]`; the 「」 strings = every 「…」 in `body.prompt`, in order, deduplicated; the
     first `count` of the 9 numbered lines; then the tail = `body.text` after `body.prompt + "\n\n"`.
   - `fingerprint_text(body)`: labels of look · layout · device · persuasion joined 「 · 」, persuasion
     omitted when its key is `none`; `None` for a pre-F07 body.
   - `badges(body, version_index) -> list[str]`: `[fingerprint.slot.label]` plus 「建議選這張」 when
     `round.recommended_index == version_index`; `[]` for a pre-F07 body.
   - `copy_all_text(bodies)`: the latest round's bodies in `version_index` order; single lead
     「請一次生成 10 張圖，每張只照下面對應的那一段，一段一張，不要合併。」, carousel lead
     「請一次生成 10 張圖：兩組輪播各 5 張，每張只照下面對應的那一段，一段一張，不要合併。」; then `第 N 張` + the text
     for each prompt (carousel numbers cards 1–10 across both concepts, one card text each); `None`
     when no body has `text`.
2. **`repository.py`**:
   - `_part_versions` for `image_prompt`: each version gets `prompt_cards` (with `selected` = its
     `adopted_at` is set and `variant_count` = the brief's `request_json.variant_count` when it is an
     int 0–9, else 0), `fingerprint_text` and `badges`. `_prompt_cards` and the `rendered`/`hero`
     reading go away. A pre-F07 row renders no cards and never crashes.
   - `products.image_prompt.copy_all_text` from the max `generation_round`'s rows; `null` for other
     parts. `_generation_settings("image_prompt", …)` returns `{}`.
   - `_generation_settings_rows` returns exactly, in order: 品牌／商品, 平台, 尺寸, 品牌視覺
     (`round.identity_text`), 這張圖的任務 (`fingerprint.image_task.label`), 風格分配
     (`looks.plan_text(round.look_order.exploit, round.look_order.explore)`), 視覺學習 (「N 條」 from `len(round.learning_ids)` or
     「無」), 主要訊息 — from the latest image round's first row; 「—」 for the image rows when no round.
   - `set_detail`: `chips.style` is `None`; stop calling `get_style` (F07-I09 deletes it).
   - `pack_detail` adds `image_exploration_warning`: over the pack's sets whose `required_outputs` has
     `image_prompt`, M = sets whose `adopted_output(..., "image_prompt")` has `is_adopted` and a
     `fingerprint.slot`, N = those with slot `explore`; when M ≥ 1 and `10 * N < 3 * M` →
     「這包選定的圖裡，探索風格只有 N／M 張（少於三成），新風格很難被測到。可以在標著「建議選這張」的探索圖改選。」 else
     `None`. It never changes `can_approve`, `blocking_text` or `approve_pack`.
