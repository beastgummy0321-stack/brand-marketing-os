# Objective

The screens show the round as the backend ships it: badges (主力／探索, 建議選這張) and a fingerprint line on
each card, ② only when the API sends it, one 複製全部 that copies `copy_all_text` verbatim, a one-click
「再生成一輪（10 張）」 with no count, the exploration warning beside 核准整包, and the 視覺基礎 negatives warning
on 品牌事實. Existing screens are extended; no new page (ARCHITECTURE.md §5.9, §5.11–§5.13; F07
Decisions 26–29). Every string the user reads about rules comes from the API; the browser never
re-spells it. Never delete or overwrite anything under `data/`.
