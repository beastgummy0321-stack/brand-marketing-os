# 近期工程：接管／查看既有 Campaign、使用者自行匯入素材

狀態：2026-09-18 使用者已核准並執行 [F13 計畫](../../.work/features/F13.md)。既有活動、自帶素材、補文案、手動交接與版本證據流程已實作；人工可用性驗收仍保留，機器整合結果以當前 Harness 收據為準。
本頁保留 dig 已確認範圍、原始查核及尚未納入的後續方向；現行契約統一見 [投放中心 §6.9](../architecture/ads.md)。Codex CLI 的生成用量不能硬封頂，已依使用者確認的單次呼叫與事後長度檢查方案處理。

## 目標與已確認決策

讓使用者把正在使用的活動與自己準備的素材納入 MarketingOS，先具備粗略但真實可用的流程：

自動讀取既有活動 → 納入品牌工作區 → 加入自帶素材 → 系統補齊缺少文案、建議安排 → 使用者確認 → 手動到平台上架 → 系統同步確認。

- 接管在本期只指內部查看、管理與建議；發布、停投、續跑及預算修改由使用者在平台操作。本期不做平台寫入。
- 使用者確認已有 Meta Token 可自動讀取；沿用現有連線，只支援串接讀取，不做 CSV／報表匯入備援。已實讀部分活動及一筆動態廣告父鏈；影片原檔、完整帳號權限及素材等價證據仍未驗證。
- 共用核心遵循根目錄 [CLAUDE.md](../../CLAUDE.md) 的多平台原則。先做 Meta 串接不等於固定所有平台的層級、預算位置或成效口徑。
- 自帶素材的「必用」代表一定納入投放測試安排；成效差仍可提醒停用，不因系統預估差而默默排除，也不保證曝光或花費。
- 自帶成品採 A：已有文案沿用，系統補齊缺少的投放文案並建議使用安排，由使用者確認；保留原始圖片／影片。
- 使用者不填廣告層級、維度座標等內部資料；不要求模型完整讀取所有圖片／影片才能保存及安排。
- 廣告預算預設只含投放費；系統不負責外部素材製作或 KOL 費用。費用選填與分析候選見後續文件，不作近期既定需求。

## 工程範圍與介面建議

以下保留原交接範圍；細化契約與實作限制以 §6.9 為準。

### 既有活動

- 沿用品牌綁定帳號，自動列出既有活動（包含已暫停及未產生花費的活動），選取後可納入工作區，查看原有結構、可取得的素材、狀態及成效。
- 以平台、來源帳號與原生 ID 識別，重複同步不重複建立；不要求先建立同名內部活動再配對。
- 保留原預算位置、日期與平台狀態；尚未完整支援的結構明示限制，不強制轉為舊有投放組日預算模式。
- 顯示資料更新時間；同步失敗保留舊資料並標示狀態，未讀到不等於零成效、已刪除或已停投。
- 納入既有活動不得觸發舊結案規則而失去持續查看能力，也不修改平台設定；內部狀態與平台狀態分開。

### 自帶圖片／影片

- 建立活動及活動素材頁提供「這次一定要用的素材」，可批次加入、預覽，重開仍存在；卡片呈現素材、建議用途、安排與下一步。
- 補文案、建議安排時使用已知品牌與活動資訊；缺資料明示，不把尚未理解的影片內容編造成事實。必要補充用一般語言詢問，避免逐檔問卷。
- 區分待安排、待確認、待手動上架與平台已確認。確認內部安排或使用者自行回報，都不冒充平台已讀回確認。
- 格式、尺寸／長度、縮圖及完全相同檔案去重由程式完成；模型按需處理有限預覽／摘要，保存判讀範圍並重用結果。未分析不假稱理解完成。
- 手動上架後的廣告與內部素材／安排如何可靠對應，須在 carve 設計；不能混淆原有廣告、新素材及不同版本的成效。

## 範圍邊界與待細化

- 允許完成近期功能必要的小型結構增補，不加深單平台假設。若某部分必須大型重構才能安全支援，提出限制與取捨，不冒充已支援。
- 大型資料重建、完整成效學習、持續優勝劣汰機制、跨平台配置與 Full auto 仍保留在原主工作區未追蹤的 `docs/backlog/roadmap-autonomous-marketing-major-updates.md`；本隔離分支不自動收錄該使用者文件，也不暗中併入本次工程。
- F13 已細化並實作活動／素材種類與缺漏呈現、同步範圍、手動上架後的對應、大量素材分批與費用護欄；已知限制見 §6.9。完整學習、自動配置及 Full auto 不在本期。
- 原先 40–65 人日是大型核心重建的粗估，不適用本期；依定案重新估算。

## 驗收方向（已轉為 F13 的檢查與人工項目）

1. 既有活動無需重建名稱即可納入，反覆同步不重複，原結構／平台狀態與資料時效可查；缺資料與同步失敗不顯示成零或停止。
2. 圖片／影片批次保存後可重開預覽；必用素材皆有安排或明確待處理原因，已有文案沿用、缺少文案可補，原檔保留。
3. 使用者可看懂並確認建議安排，取得手動上架所需內容；平台讀回確認之前不顯示已發布。
4. 維持品牌／帳號隔離，測試涵蓋不支援結構、部分讀取失敗及重複同步；整條流程沒有平台寫入。
