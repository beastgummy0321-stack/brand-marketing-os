# Variant-level learning (② 變體) — deliberately not built

Status: not planned. Recorded by F07 (2026-09-15).

- ② 變體 prompts are rendered by the program from the selected item: subject unchanged, 1–2 small
  changes per image, 單圖 only (ARCHITECTURE.md §5.7).
- Not learned, because:
  - Meta groups visually similar creatives in one ad into one entity, so the platform does not treat
    them as separate concepts;
  - the deltas are small enough that per-variant differences are noise at the samples a brand gets.
- To revisit only with evidence: per-asset results from Ads Reporting's creative breakdown for
  flexible ads, and a trace from each uploaded image back to its variant number.
