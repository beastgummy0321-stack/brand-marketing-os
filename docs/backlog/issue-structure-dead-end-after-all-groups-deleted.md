# 採用策略後把投放組全刪光：投放結構頁變死路

Status: 2026-09-14 F06 整合審查發現（F06 之前就存在，不屬於 F06 任何一張票）。

事實（審查者讀程式得出，變 issue 前要實測）：
- 「調整結構（進階）」可以刪掉投放組；全部刪光後 `c.groups.length === 0`。
- `frontend/src/components/ads/nextStep.tsx` 的規則在 `groups.length === 0` 時回 `strategy_adopt` → 指回策略頁。
- 但策略早已採用，再按採用會被後端 `app/ads/plan.py:128` 以 `plan_already_adopted` 擋下。
- `DeliveryTab.tsx` 在沒有投放組時提早 return 空狀態，看不到進階區的樹，所以也無法在這一頁「新增投放組」。
- 結果：總覽、策略、投放結構三頁互相指來指去，使用者加不回投放組。

待決：規則是否該區分「從沒採用」與「採用過但投放組被刪光」（例如後者 → 投放結構直接打開進階並給「新增投放組」）；
或進階區不允許刪掉最後一個投放組。層級＝狀態流（同 F06 的一條下一步規則），不要在單一分頁加 if。
