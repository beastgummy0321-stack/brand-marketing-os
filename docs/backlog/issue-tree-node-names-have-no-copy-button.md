# 要「一字不差」抄去 Meta 的名稱，是全站唯一沒有複製按鈕的字

Status: 2026-09-06 可用性演練量到（`docs/drills/`）。小杰兩輪各手打 13 個、9 個名稱，
第二輪特地回頭確認過：還是沒有。

成因：素材文案（主要文字／標題／說明，每組 5 個變體）每一條都有複製圖示；
**活動樹的三層節點名稱旁邊只有「提醒」標籤，沒有複製。**

而配對失敗訊息自己講得很清楚，這些名字有多不能錯：

> 「名稱要一字不差（區分大小寫，前後空白也算）。」

名稱裡還有全形分隔號「｜」——2026-09-07 真跑時特別交代過使用者「**一定要複製不要用打的**」，
但畫面上沒有可以複製的地方。

使用者看到的（小杰，兩輪都抱怨）：
> 「13 個名字要一字不差抄進 Meta，但畫面上這些名字沒有複製按鈕（文案倒是每組都有），
> 等於要我肉眼對照手 key，**最容易打錯字的地方反而最難複製**。」

阿明沒抱怨這件事，因為他是被「配對失敗」嚇到之後才理解要去 Meta 建——他到停止點都還沒開始打字。
Vivian 也一樣。也就是說，**這條的成本只有真的去打字的人才付得出來**，而那正是這條路徑的必經之處。

`file:line`：`frontend/src/components/schedule/CampaignTree.tsx`（節點名稱的呈現）；
複製按鈕的既有做法在同一棵樹底下的素材文案區。

做法（未裁決，空間很小）：每個節點名稱旁加一顆複製，跟文案用同一顆元件；
再加一顆「複製整棵樹的名稱」（一行一個，含層級），因為使用者是一次要建一整棵。
route A，一兩小時。**這條的投報率高到不像 issue**——它是這條手動路徑上唯一會讓整批配對失敗的
單點錯誤來源。
