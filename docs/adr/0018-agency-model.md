# 0018 產品模型翻新：使用者＝客戶、系統＝行銷公司（2026-08-14 定案）

使用者發起，四批 grill 逐條定案（過程紀錄 `.scratch/grill/GRILL-agency-model.md`，用完即刪）。
背景事實：系統從未發布、資料全為測試用；實測從零到廣告上線使用者親手過約 20 關，
僅 3–4 關是花錢煞車或平台硬限制；判讀無自動排程且觸發僅存舊 Jinja 頁，新殼走不完旅程。

## 決定

1. **產品模型**：使用者是客戶，系統是行銷整合公司。全站設計紅線：**使用者關卡 ≤4**——
   ①開戶訪談一次 ②提案書核可 ③上線授權 ④週提案核可。其餘系統自理，打擾只走收件匣。
   每個畫面必答「這關憑什麼要使用者做」，答不出平台限制（A）或花錢煞車（B）即收回系統。
2. **確認反轉**：AI 整理的資料（品牌/產品事實、規則）預設直接採用＋全程審計紀錄可回改。
   只問兩類：查不到的商業數字（售價/成本/毛利）、對外宣稱紅線（療效/法規類）。
3. **三幕流程**取代現行多站流程（骨架照 v4b-agency 原型，只取流程不取視覺）：
   - Act1 開戶訪談四步（聽產品→目標變數字→描述買的人→銷售現場健檢），合併建品牌精靈、
     建產品、經濟數字、逐筆確認四站；訪談只走一次，之後新增產品只補問必問項。
   - Act2 提案書：五類管道全進、深度分級——Meta＝可投放＋成效自動同步；Google/TikTok＝
     規劃＋引導式手動上線＋成效先靠匯入；LINE/Email 與 KOL/媒體/公關＝任務卡（AI 給建議
     與進度，執行靠人）；官網落地頁＝健檢＋建議。執行深度在提案書誠實標注。
   - Act3 營運：週引擎每週自動「同步→判讀→出 3 張優化提案」；月報每月自動產出；
     三件事常駐卡（產品資訊完整度／回覆速度／好客戶定義）。
4. **自動度＝品牌層單一設定**：保守檔（預設）＝引導式手動上線＋提案全等核可；
   放手檔＝平台寫入 API 自動投放（過審後）＋煞車內自動微調（週報告知）。
   引導式手動是**永久選項**非過渡。兩檔共用同一份執行清單資料模型，只換執行器。
   平台寫入 API 申請排獨立線。
5. **追蹤主軌**：EasyStore 官方 GA4 擴充＋Meta Pixel/CAPI（系統做「追蹤健檢＋引導安裝精靈」
   帶使用者裝一次；來源：support.easystore.co 官方文件）。UTM 隨 GA4 生效。
   期別配碼降為蝦皮/藥局等查不到來源管道的備援。代管落地頁不進第一版。
6. **砍除**：外借 AI 貼回步驟、逐筆確認必經路、檢查清單當使用者任務、排期理由填寫、
   重複入口、v1–v5 初代原型。96 頁 Jinja：先補齊僅存於舊頁的路徑（判讀觸發／期末結算／
   訂單），新流程驗收過即整批刪除、訂死刪除日，不留備援。
7. **文件權威**：分票唯一依據＝`docs/ui-migration-contract.md` v2。本 ADR 取代
   `redesign-blueprint.md` 第一節定位與 ADR 0017 中與本案衝突的互動模型條款；
   引擎層（資料表、Meta/GA4 同步、判讀規則、素材主題引擎、LLM 閘道、方法論注入）沿用不重寫。

## 不可逆項目定案（code-rules 五項）

| 項目 | 定案 |
|---|---|
| 資料模型 | 既有表為基底；新能力（管道計畫／任務卡／週提案／月報／自動度）開新表，不改舊欄語意 |
| 模組邊界 | 週引擎與提案書組裝＝新編排層，單向依賴既有引擎；前端照 feature 資料夾 |
| 對外契約 | API 照 `/api/<module>/…` 規範；v4b mock-data.js 為形狀草稿，修 per-brand 缺陷（管道／節點／長期系統名稱改為每品牌自有欄位） |
| 同步/非同步 | 沿用背景執行緒＋輪詢；週引擎掛既有排程機制（auto_sync 同款） |
| 錯誤/交易邊界 | 不動 |

## 理由

- 20 關裡的 16 關是把行銷公司內部作業攤給客戶做，根因是產品模型不是單點體驗。
- 系統未發布、資料全測試，翻案成本最低的時點就是現在。
- 引擎層 2,023 測試全綠、Meta/GA4 真接讀取 API，重寫零收益；錯的是流程編排層與 UI。

## 當時排除了什麼

- 維持操盤手模型只優化各關體驗：治標。
- 操盤手／客戶雙模式並存：兩套介面維護翻倍，違反單一路徑。
- v4b 獨立成另一個產品：同一使用者同一批資料，另起爐灶要重養品牌/產品/訂單。
- v4b 琥珀金視覺接管全站：使用者定案維持現行藍色系。
- 全部預設採用、一項都不問：對外宣稱有法律後果，紅線仍過人。
- 等寫入 API 過審直接做全自動：中間數週人肉搬運照舊，不可接受。
