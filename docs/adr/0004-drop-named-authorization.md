# 取消「具名授權」手續，關卡保留一鍵確認

舊產品原則：花錢的板機必須具名人類扣——廣告三道關卡（計畫確認、素材採用、投放授權）要求填寫操作者名字，`authorized_by` 欄位 NOT NULL。使用者於 2026-08-05 重設計訪談中明確推翻：系統是單機單人，永遠只有當事人操作，填名字不產生任何額外資訊，只是煩人的步驟。

新規則：三道關卡本身**保留**（防手滑的一鍵確認不取消），但去掉填名字／選身分的手續；`authorized_by` 由系統自動帶入固定值，資料表結構不動。

## Consequences

- 稽核紀錄仍完整（時間、動作、關卡都在），只是「誰」永遠是同一人，欄位失去鑑別力。
- 系統哪天變多人使用，這個決定必須重新檢視——自動帶入的 authorized_by 會讓責任歸屬失真。
- 三道關卡的「確認」語意不變：新前端不得把關卡做成自動通過。
