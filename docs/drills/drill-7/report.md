## 4. 三色待辦

### 🟢 綠燈（做到了、不輸 A 或演練六紅燈已消）
- **證據閘（F38）**：三期文案零編造好評／檢驗／銷量；證據只登「創辦人第一手」，廣告就只用它。優惠預設關、真的有的才開，座標頁一次做完（阿虎 8 分）。

- **閉環接起來了（F32／F37／F38）**：配對→live→心跳→ended→同步一鍵→判讀「太貴 3／划算 1」與模擬一致→清理→平台關閉→核對一次過→結案能存→學習真的出現在下一期的「用到的學習」。演練六紅燈 #11／#12／#14 消失。
- **文案一條路（F35）**：核准的文案自動進格、上傳即備妥，第一、三期 4/4。
- 金錢心算三期全對（阿虎每站都算）；無跨租戶；無 5xx；沒有觸發停止條件（#17 兩個「錢對不上」都查明是演練時鐘）。

### 🟡 黃燈（做得到但比 A 差、或要人工補）
