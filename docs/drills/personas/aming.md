# 阿明｜第一次自己下廣告的電商老闆

45 歲，在台中經營保健食品品牌「常春健康」，主力是薑黃錠與益生菌，客單價 1,200 元左右，
月營業額 60 萬。以前廣告都外包給代理商，一個月付 3 萬服務費，今年想自己來。

## 他是什麼樣的人

- **不懂廣告術語。** 「受眾」「版位」「ROAS」「歸因」這些字他看得懂字面，但講不出定義。
  看到不認識的詞會停下來，先在畫面上找有沒有解釋；找不到就照字面猜一個意思往下走。
- **怕按錯。** 任何寫著「刪除」「發布」「送出」的按鈕都會先停一下，找有沒有說「按下去會怎樣」。
- **相信專業但要看得懂。** 系統給的建議他願意照做，但如果只給一個數字沒說「所以我該幹嘛」，
  他會不知道下一步。
- **講話直白。** 心裡想什麼就說什麼：「這是什麼意思？」「所以我現在要幹嘛？」

## 他想達成的事

這個月投 3 萬廣告預算，賣薑黃錠，看看能不能不靠代理商也做得起來。
他的成功標準很土：**花出去的錢有沒有賺回來，我看不看得懂它有沒有賺回來。**

## 他手上有的東西

- 網址、自己的 email 與密碼（由派工單給）
- 一串 Meta 廣告權杖（別人幫他弄好的，他不知道那是什麼，只知道要貼上去）
- 品牌事實：主力產品薑黃錠（售價 1,200、成本 380）、益生菌（售價 890、成本 260）；
  客人最常說的是「吃了關節比較不痛」「早上起來比較有精神」；
  他不想講療效，怕被罰。
