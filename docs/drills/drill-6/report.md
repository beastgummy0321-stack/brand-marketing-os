# Drill 6 報告 — 外部廣告商 vs MarketingOS，三期兩次回推（2026-09-26）

一句話：**同一個品牌、同一份公開資料、同一套台灣市場模擬器，外部廣告商三期 ROAS 0.81 → 2.00 → 4.27；MarketingOS 0.25 → 0.30 → 0.88。** 差距不在 AI 文筆，在四件系統性缺口：策略看不到品牌沒歷史、學習永遠進不了下一期、素材文案與廣告格是兩條路、預算建議算錯除數。細節與三色清單在下。

模擬數字是編的（規則在 `scripts/drill/tw_sim.py`，兩邊同一套），只能比「兩份排程誰好」，**不能證明真投放會賺**。

### 操作者介入（都記錄、都不是修程式）

1. **給 B 四張產品照**：系統沒有站內出圖，阿虎沒照片就走不下去；真老闆會有照片，所以補給他。
2. **把一週壓成一小時需要撥時鐘**：新增 `scripts/drill/clock.py`（改 `today_for_org` 與 `now_utc`），後端／worker 各重啟兩次。第一次沒蓋到「帳戶時區的今天」，害 B 白走一輪（p2b）。
3. **Meta 同步有 6 小時節流**：壓縮時間下不會自己再同步，操作者用產品自己的 `request_sync` 手動觸發（等於每日排程跑了）。
4. P3 沒再配對／灌數字（最後一期不回推）。

## 4. 三色待辦

### 🟢 綠燈（做得到、不輸外部廣告商）
- 建檔精靈到策略頁的主線：阿虎 9／8／8／9 分，金額心算兜得攏；三組角色名稱看得懂。
- 工作檯文案一次過關：AI 自己守住「不講療效」，兩個核准勾選合理（8 分）。
- 上架清單與讀回核對：第二、三期一次到位（10 分）；「8 項都和核准的一樣」明確。
- 檢討證據頁：期間對了就給真數字（8～9 分），且誠實標「尚待確認」不硬湊。
- 跟進清理提案（關太貴廣告）流程順（8 分）。

### 🟡 黃燈（做得到但比 A 差、或要人工補）
- #4 先問使用者目標再秀預設；ROAS 目標也存下來。
- #2／#17 自帶素材：廣告格內直接填文案＋「套用到全部」，不進進階層。
- #13 三頁同一口徑：成效面板自動 ingest，不靠使用者按鈕；首頁／連線頁／檢討讀同一份。
- #15 「照上一期」除以有花費的天數；與連線頁同一資料源。
- #8 手動上架清單帶受眾建議（年齡／興趣／排除）；至少把 audience_key 翻成人話。
- #20 「今天」只留一個來源；檢討期間預設用伺服器日期。
- #5 文案改成真的入口名稱；#6 初掃空訊息條件加上 scannedProducts。
- 素材 AI「取得建議」（#19）應重生每張圖的文案，先對程式碼確認。

### 🔴 紅燈（功能缺、bug、規劃失敗）
- **#11 結案精靈存不了主打 → 無法結案 → #14 學習永遠進不了下一期**。這是閉環斷掉的主因，三期策略都說「沒有學習記錄」。
- **#12 配對完 status 不變 live**：列表講「待發布」、runtime 不監控、判讀口徑錯。
- **#10／#18 策略不知道品牌沒歷史**：第一期配再行銷（零投遞）、第二期配回購（2 個買家）；B 三期有 22% 預算投在不存在的受眾。
- **#1 文案與廣告格兩條路**：核准完 0/4，新手真的會打電話；「只準備新文案」在草稿活動是死路。
- **#9 沒有食安法禁語閘**：這次 AI 自律守住了，但沒有任何程式保證；`issue-u1-banned-words-gate.md` 講的是 UI 用字，不是廣告合規，backlog 缺這一條。
- **#7 沒有行事曆**：中秋／國慶／期中考完全不在系統知識裡，而這正是 A 三期贏最多的地方。
- **#3 沒有站內出圖**：沒照片的新品牌走不到上架（已知 P2 #2）。
- **#16 商品重複建立**：經濟數字掛在複本上，後面所有打平計算都可能挑錯那份。
- 規劃失敗：**三期 17 則廣告一句文案**、proof 座標寫有證明但品牌沒有、`limited_time` 沒期限、第三期預算被錯誤除數砍成 524／天。

## 5. 這次演練自己的限制

- 模擬器是我寫的規則，偏好「情境貼合＋再行銷靠累積」；A 的策略正好對這套規則有利。換規則名次不會反轉（B 的問題在結構），但倍數會變。
- 評審偏寬（A 全部 1.3～1.35）；兩邊同一個評審、同一份規則，相對比較仍成立。
- 阿虎是 LLM 不是人，且只有一個角色；分數是「LLM 扮演新手」的分數。
- 一週壓一小時要撥三個時鐘來源，操作者介入了三次；真實時間下 #13 的一部分（同步節流）會自己解。
- P3 沒配對回系統。
