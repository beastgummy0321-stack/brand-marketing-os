## 規劃重點抄錄
1. 策略頁理由全文：
   - 「品牌目前沒有投放、花費、平台、像素或回購資料，因此不安排依賴暖受眾的角色。」
   - 「目標是購買，且品牌優先服務高強度訓練與競技族群，分配以新客觸達搭配探索學習為主。」
   - 「商品尚無確認過的事實，探索配置可用來檢驗合規的專業教練式溝通與不同高強度生活情境。」
   - 「投放期間只涵蓋國慶假日前一日，沒有足夠依據把節日當作主要策略。」
   - 這輪想學到什麼：「找出高強度訓練、競技與高強度生活族群中，較能帶來新客購買的受眾組合。」「比較專業教練式、力量挑戰與行動導向訊息，哪類更能推動單品購買。」「確認合規溝通前提下，哪些商品利益表述能支持下一輪廣告優化。」
   - 目前最大的未知：「尚不知道哪些受眾與訊息組合能帶來購買。」「尚不知道商品頁與廣告溝通是否能有效支撐購買目標。」「尚不知道國慶日前一日是否會對目標買家的購買行為造成影響。」
   - 策略依據彈窗：品牌事實 5 條＋「商品價格 NT$ 999」；「用到的學習　沒有可用的學習紀錄。」
2. 廣告組（畫面只有名稱，沒寫受眾／情境）：「探索｜高強度生活情境」每日 600；「新客｜日常痛點認識」每日 900。素材組：訓練族｜高強度活動中的使用選擇（benefit_explainer，影片）、競技族｜比賽前確認使用方式（how_to_tutorial，輪播圖）、日常使用者｜先看懂問題再選擇（product_explainer，影片）、忙碌生活族｜減少每天處理麻煩（daily_use_sharing，單圖）。工作檯摘要的「目標受眾」：「大學生、健身族、上班族」。
3. 標題與第一句文案：
   - 訓練族：標題「訓練後補給，不必多一個瓶子」；「高強度訓練結束，器材收好，補給也該有清楚安排。」
   - 競技族：標題「上場前，把補給安排好」；「進入比賽場館熱身區，先別急著上場。」
   - 日常使用者：標題「早晨出門前，還在猜咖啡因怎麼帶？」；「早晨出門前，你會先確認今天要帶什麼，卻還在想咖啡因到底吃多少才好安排？」
   - 忙碌生活族：標題「坐下就開工，補給先排好」；「通勤到座位，先別讓找飲料打亂開工節奏。」
