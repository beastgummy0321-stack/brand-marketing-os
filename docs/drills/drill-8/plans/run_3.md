- 撞名：第三期沒有再在系統裡卡讀回（要看操作者建好後才知道）。
還是卡的：
- 影片格不收照片：三期都一樣，只能靠「進階」裡繞路（指派）才過；正常人找不到。
- 系統不講理由：策略頁不會說「因為 X 划算所以留下」；沿用只有名字對得上，文案卻重寫。
- 日期壞掉：成效頁、核准時間、結案視窗都是 09/30，首頁只有「今天」是對的。
- 首頁數字跟第二期脫節：花費、每筆成本、還能花全是第一期。
- 「這個活動沒有要決定的事」跟「太貴／划算」並存；「換掉這一則」沒回饋、划算那則沒有「留下」。
- 行事曆（期中考）沒進策略；證據／優惠（教練出身、三盒免運）沒地方登記。
- 每一期名稱都是同一串被截斷的長句，容易撞名。
