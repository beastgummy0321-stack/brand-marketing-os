## 一、驗收前準備

### 1. 準備一個測試品牌與檔案

建議使用可丟棄的測試品牌，不要把未完成的驗收資料放進正式品牌。

準備：

- 2 張圖片：JPEG、PNG 或 WebP。
- 1 支影片：MP4 或 MOV。
- 每檔需介於 1 byte 與 50 MiB。
- 一張圖片保留「說明」空白，用來驗收補文案。
- 另一張圖片填好「標題／內文／說明」，用來驗收保留原文。
- 如要驗收大量素材，可準備 12 檔；系統應自動拆批，不需自己分批。

請勿使用機密、客戶個資或未獲授權的素材。

`supabase migration up --local` 只套用尚未執行的 migration。不要用 `supabase db reset`；reset 會刪除 seed 以外的本機資料。

如果專案目錄有未提交修改，先不要強制切換分支、reset 或覆蓋檔案；改用乾淨 worktree 進行驗收。

## 二、先理解畫面上的狀態

| 畫面文字 | 真正代表的意思 | 不代表什麼 |
|---|---|---|
| 待處理 | 素材已加入活動，但文案、用途、目的節點、日期或預覽仍需核對 | 不是失敗，也不是已上架 |
| 已確認內部安排 | 使用者已確認這一版素材在 MarketingOS 內的安排 | 不代表 Meta 已建立廣告 |
| 使用者自行回報，尚未由平台證實 | 使用者按了「我已手動上架」 | 不代表平台真的讀得到廣告 |
| 平台已讀回廣告與父層關係 | 系統重新向平台讀到指定廣告及其父層 | 不代表平台素材一定等於這一版原檔 |
| 尚未核對是否使用這一版素材 | 廣告存在，但素材等價證據不足 | 不應把該廣告成效算到這一版素材 |
| 使用者已核對；平台尚未證明素材等價 | 使用者人工比對過原檔與文案 | 仍不是平台提供的素材等價證據 |
| 已有平台素材等價證據 | adapter 取得足以證明素材相同的資料 | 仍需完整日期與版本歷史，才能歸屬成效 |

判定原則：廣告存在、素材版本相同、成效可以歸屬，是三個不同問題，不能互相代替。

## 三、驗收既有活動納入工作區

### 入口

1. 左側品牌切換器選擇測試品牌。
2. 點左側「投放中心」。
3. 在頁面右上方按「加入既有活動」。

### 操作

1. 在彈窗的「品牌綁定帳號」選擇要讀取的帳號。
2. 按「更新清單」。
3. 等待畫面顯示「清單已同步」，或至少出現可選活動。
4. 暫停中或沒有花費的活動也應保留在清單中。
5. 如果有下一頁，按「載入更多活動」。
6. 找到測試活動，按右側「納入並開啟」。

### 通過條件

- 按下後進入該活動工作區，頁面標題為該活動名稱。
- 看到「既有平台活動」。
- 重複納入相同平台、相同帳號、相同原生 ID，不應建立第二份活動。
- 沒有任何畫面聲稱已修改 Meta 設定。

### 沒看到活動時

- 顯示「尚無可讀取的綁定帳號」：回「設定 → Meta 廣告連線」檢查品牌綁定。
- 顯示「此帳號尚無已讀回活動」：按「更新清單」，等待同步後再試。
- 顯示錯誤：按「重試讀取」。舊快取仍應保留，不應整頁清空。

## 四、驗收既有活動原始資料

既有活動開啟後，「總覽／策略／投放結構／成效」分頁都會顯示同一個「既有平台活動」唯讀面板；「素材」分頁顯示自帶素材流程。

### 操作

1. 按「重新讀取平台」。
2. 按鈕應暫時變成「同步中…」。
3. 同步結束後，確認「最近成功」有時間，或清楚顯示「尚未成功讀回」。
4. 查看「原生結構」「素材資料」「成效資料」三個同步區塊；每區都有自己的狀態、最近成功時間與涵蓋範圍。
5. 展開「原生結構與預算」。
6. 核對活動、廣告組、廣告或其他平台原生層級的父子關係、日期、狀態、幣別與預算位置。
7. 若顯示「平台原始值（未換算）」，確認畫面沒有自行換算出看似精確的金額。
8. 展開「原始成效」。
9. 核對日期、層級、歸因、幣別、花費、曝光、點擊、購買與收入。
10. 在「內部活動目標」輸入例如「介紹品牌產品並增加購買」，按「儲存目標」。

### 通過條件

- 同步分區成功時，頁面上方「最近成功」不再錯誤顯示從未成功。
- 讀不到的數字顯示「未知」，不能補成 0。
- 不同幣別、層級或歸因方式沒有被混成一個總數。
- 動態素材或無法完整還原的素材會明示限制。
- 平台影片縮圖不會被當作可播放的影片原檔。
- 同步失敗時舊資料仍可查看，並顯示錯誤與最後成功時間。

## 五、驗收自帶圖片／影片上傳

### 入口

在活動上方分頁列按「素材」。

畫面會依序出現：

1. 「自帶圖片／影片」：品牌素材庫、上傳與原文。
2. 「自帶素材安排」：這個活動實際要用哪些素材、如何安排與確認。

### 上傳操作

1. 在「自帶圖片／影片」按「選擇圖片或影片」。
2. 一次選擇準備好的圖片與影片。
3. 每個待上傳檔案下方可填：
   - 標題
   - 內文
   - 說明
4. 第一張圖片刻意把「說明」留空。
5. 第二張圖片三欄都填入原文。
6. 按「保存原檔與原文」。
7. 等待每個檔案顯示「原檔已保存」。
8. 在「品牌上傳紀錄」找到每個檔案，按「加入此活動（保留本批原文）」。
9. 重新整理瀏覽器，回到「素材」分頁。

### 通過條件

- 原檔、檔名與原文重新整理後仍存在。
- 圖片可以按「查看預覽」顯示；影片可以播放預覽片段。
- 影片預覽最多前 15 秒，但「下載原檔」仍應取得完整原檔。
- 12 檔會自動拆批，畫面不卡住，也不需要使用者手動分成 10＋2。
- 完全相同內容可共用品牌原檔，但不同上傳批次的原文不能互相覆蓋。
- 壞檔或超限檔案只影響自己，其他成功檔案仍保留。

### 上傳失敗時

- 先按「重試／核對保存」。系統會先核對伺服器是否其實已保存，不應直接重傳。
- 若畫面要求重選，按「重新選原檔」，選擇同檔名、同大小的原檔。
- 新檔案不要拿來覆蓋失敗項目；應另建一次上傳。

## 六、驗收必用素材、補文案與確認安排

加入活動後，每張卡片會顯示「第 N 版」「必用／選用」及「待處理／已確認內部安排」。

### 路徑 A：保留完整原文，手動確認

1. 在素材卡按「編輯原文與內部安排」。
2. 核對標題、內文、說明仍是上傳時的原文。
3. 填入「用途」，例如「產品介紹」。
4. 勾選「此素材必用」。
5. 如為既有活動，先按上方「載入本活動目的節點」。
6. 在「安排目的」選擇正確節點；不確定時可保留「未指定（沿活動安排）」。
7. 視需要填「內部開始日／內部結束日」。這些是內部安排，不會修改平台日期。
8. 按「儲存為新版安排」。
9. 按「只用我的文案，檢查並確認」。

預期：卡片由「待處理」變成「已確認內部安排」。

### 路徑 B：補齊空白文案

1. 勾選素材卡左上方「納入建議［檔名］」。
2. 可在「整批素材說明（未核實）」輸入背景；這段內容不會自動變成已確認事實。
3. 一批最多選 10 件。可按「選取前 10 件待處理」。
4. 按「為選取 N 件取得建議」。
5. 等待「建議已備妥，請逐件核對」。
6. 核對「本批補充建議（尚未採用）」：
   - 原本已有的文字不得被改寫。
   - 只補原本空白的欄位。
   - 不得捏造未驗證的折扣、功效、保證或影片內容。
7. 若內容可用，按「核對後確認這件建議」。

使用 Codex CLI 時，每批只呼叫一次、不自動重試，會限制輸入與執行時間，回傳後再檢查長度。這條線路會消耗 Codex 訂閱用量，且不能保證生成 token 的硬上限。若不想消耗用量，走路徑 A。

### 通過條件

- 每件「必用」素材都有已確認安排，或仍清楚留在「待處理」並說明原因。
- 系統不能因建議不足而把「必用」偷偷改成「選用」。
- 確認內部安排後，畫面不得顯示成「平台已上架」。
- 離開再回來，已完成與未完成的建議批次都能從「先前建議批次」找回。
- 如果另一分頁或另一人先建立新版，畫面應顯示版本衝突，保留本機編輯，不能靜默覆蓋。

## 七、驗收手動交接與平台核對

### 取得手動上架內容

1. 在「已確認內部安排」的卡片按「手動交接與平台核對」。
2. 核對並使用：
   - 「查看預覽」
   - 「下載原檔」
   - 建議追蹤名稱
   - 標題、內文、說明旁的複製按鈕
   - 用途、目的節點、開始日與結束日
3. 展開「原文與補充文案分開查看」，確認原文和系統補充沒有混成一份不可追溯的文字。
4. 到 Meta 手動建立或更新廣告。MarketingOS 本身不會替你送出。

### 只記錄使用者自行回報

只有在你真的完成平台操作後，才按「我已手動上架（僅自行回報）」。

預期顯示：

```text
廣告存在：使用者自行回報，尚未由平台證實
素材版本：尚未核對是否使用這一版素材
```

這是正確結果，不應直接顯示「平台已確認」。

### 從平台重新讀回廣告

1. 在「平台帳號」選擇對應帳號。
2. 按「載入平台候選」。
3. 在「選擇平台廣告」選擇剛才手動上架的廣告。
4. 如果你已逐一比對平台上的原檔與文案，可勾「我已自行比對這一版原檔與文案」。
5. 按「重新讀回並核對廣告」。

預期至少顯示：

```text
廣告存在：平台已讀回廣告與父層關係
```

素材版本可能仍顯示：

```text
尚未核對是否使用這一版素材
```

或：

```text
使用者已核對；平台尚未證明素材等價
```

這兩種都可能是正確結果。只有平台 adapter 取得足夠證據時，才可顯示「已有平台素材等價證據」。

### 驗收版本成效歸屬

1. 展開「檢查這一版的成效歸屬」。
2. 選擇開始日與結束日。
3. 按「讀取版本成效」。
4. 查看每筆觀測最後一行。

如果顯示「不可歸屬本版：證據不足」或「版本成效未知」，在缺少連續版本歷史時是正確結果。不能因為廣告存在或兩次快照相同，就把成效算給這一版素材。

## 八、驗收修改後建立新版及保留歷史

1. 找一張已確認且已有平台核對紀錄的素材卡。
2. 展開「編輯原文與內部安排」。
3. 修改標題，例如在原標題後加「新版」。
4. 按「儲存為新版安排」。

### 通過條件

- 版號由第 N 版變成第 N＋1 版。
- 新版回到「待處理」，必須重新確認。
- 新版尚未確認前，不顯示目前版的「手動交接與平台核對」。
- 舊版出現「查看第 N 版歷史／結束對應」。
- 舊版的平台核對紀錄仍保留，但不會自動套到新版。
- 若平台同步發現 creative 已變更，舊對應會標為過時，不會刪除歷史。

若舊素材已停用，可在舊版交接區按「結束這筆對應」。這只結束 MarketingOS 內的版本對應，不會去 Meta 停止廣告。

## 九、驗收新建活動也能使用同一素材庫

### 入口與操作

1. 回左側「投放中心」。
2. 按右上方「建立 Campaign」。
3. 頁面上方會先出現同一個「自帶圖片／影片」品牌素材庫。
4. 在既有上傳紀錄旁勾選要使用的素材；也可以先上傳新檔。
5. 在「你這次想做到什麼？」輸入測試目標。
6. 按「產生建議」。
7. 活動建立並進入「行銷駕駛艙理解如下」後，按「先處理自帶素材與手動交接」。若停在附件加入失敗的建立頁，可按「前往此活動核對素材」查看已保存部分。

### 通過條件

- 進入新活動的「素材」分頁後，只看到剛才選取的素材。
- 素材原文與原檔仍保留。
- 若建立活動成功但部分素材加入失敗，畫面提供「重試加入未完成素材並繼續」，重試不應再建立第二個活動。
- 重新整理或重新進入活動後，素材仍存在。

## 十、品牌隔離與錯誤狀態

### 品牌隔離

1. 記住測試素材檔名。
2. 用左側品牌切換器切到另一個品牌。
3. 進入「投放中心 → 建立 Campaign」。
4. 查看「自帶圖片／影片」。

通過條件：另一品牌看不到原品牌的素材。空品牌顯示「品牌尚無自帶素材」。

### 讀取錯誤

一般人工驗收不需要故意中斷網路。若實際遇到錯誤，應確認：

- 錯誤訊息可見，不是永久轉圈。
- 已經讀到的活動、素材或安排不會因一次失敗被清空。
- 「重新載入品牌素材」「重新讀取安排」「重試讀取」能再次操作。
- 未成功讀到的資料顯示未知，不顯示 0 或平台已確認。
