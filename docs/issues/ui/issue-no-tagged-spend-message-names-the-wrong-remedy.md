# 判讀說「要先讓系統產的素材真的花到錢」——錢已經花了，缺的是「採用」

Status: open（drill 2026-09-09，Vivian step 10，**分數 3**，她整趟最低的兩個之一）。
連著 ADR 0068 §3 的座標覆蓋率決策（主聊處理）；這一條只講**那句話本身講錯了補救方向**。

成因：`frontend/src/components/cockpit/DiagnosisPanel.tsx:176-178`，判讀回來 0 條建議且
`no_tagged_spend` 為真時印的是「這個月的花費全部沒有座標可對，要先讓系統產的素材真的花到錢。」
Vivian 的 9 則廣告花了 5,270 TWD，錢確實花到了。真正的閘門在
`app/schedule/state.py:230`：只有按過「採用這一輪」的文案才會同步進 `creative_candidate`
（ADR 0068 §3），她一張都沒按，於是 0 個 candidate、65 列花費全部落進「未標座標」。
這句話把因果指到「素材沒花到錢」，使用者能做的動作因此是錯的。

同一畫面上還有一個誤導：她報告看到的其實是**表格的空狀態**
（`PerformanceDetails.tsx:266`「還沒有座標可以對」），不是判讀的輸出。兩句話講同一件事、
用不同的詞、上下相鄰，她的結論是「判讀卡住了、什麼都沒出來」——實際上判讀跑完了、
賺賠線也印出來了。她的原話：
> 「我本來期待系統會分析這一週的成效……結果系統說『我要座標才能判讀』。但座標是系統產生的啊，為什麼沒打上去？」

`file:line`：`frontend/src/components/cockpit/DiagnosisPanel.tsx:176-178`（那句話）、
`frontend/src/components/cockpit/PerformanceDetails.tsx:266`（相鄰的第二句）、
`app/schedule/state.py:230`（真正的閘門）。

做法（未裁決）：這句話要說出使用者下一步能做的事——「這個月的花費對不到任何座標：
系統只把**按過「採用這一輪」**的文案記成座標，去工作檯把要投的那幾輪採用起來」＋連到工作檯。
兩句空狀態擇一留下。ADR 0068 §3 那一刀怎麼裁（同步採用版 vs 採用－否則－最新）會改變這句話
要不要存在，但不會改變「現在這句指錯方向」。route A。
