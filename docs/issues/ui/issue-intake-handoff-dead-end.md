# 建檔精靈的「交接包」：叫不懂技術的老闆自己去跑 Claude／ChatGPT

Status: 2026-09-06 可用性演練量到（`docs/drills/`）。阿明給 **2 分**，是整場最低分，
也是他自己說「差點關掉網頁」的那一刻。這是**設計決策的後果**，不是壞掉，所以是 issue 不是票。

成因：建檔精靈第 4 步「把調研包丟給外部 AI」，畫面吐出一大段中英夾雜的技術指令
（含「輸出格式」「用『|』分隔欄位」「不要用 Markdown 表格語法」「種類｜分類｜標題｜內容｜
適用範圍｜佐證來源」），配「複製全部」與「我跑完了，去貼回來」。理由畫面上有寫，而且誠實：
「這一步不花系統的錢——跑的是你自己的 Claude 或 ChatGPT 額度」。

問題不在省錢這個決定，在**這一步沒有給不會做的人一條路**：畫面上只有標準調研／深度調研兩種，
兩種都要自己去外部工具跑，**沒有「跳過」，也沒有「系統幫我查就好（要花錢）」**。

使用者看到的（阿明原話）：
> 「什麼？系統自己不會查喔？還要我去複製一大串東西貼到別的軟體跑完，再貼回來？我根本不知道
> Claude 是什麼……如果我是真的老闆，這裡我大概會直接放棄調研這件事，或者打電話問人。」

他最後是**亂點到產品頁才發現可以繞過去**——產品頁那句「品牌可以沒有產品」讓他意識到前一步不是必經。
他的話：「鬆了一口氣。」也就是說，這一步能被跳過這件事，是使用者自己撞出來的，不是畫面講的。

Vivian（懂技術）給 5 分，判定「跟『省時間』的期待有落差」，但她做得到。
小杰直接全部留空跳過，沒受影響。**受害的正好是最需要這個功能的那種人。**

`file:line`：`frontend/src/components/intake/steps/`（交接包那一步）、
`frontend/src/components/intake/steps/PasteStep.tsx`（貼回）。

做法（未裁決，這是產品決策不是 bug）：
- 最小一刀：這一步明說「**這一步可以跳過，之後隨時回來做**」，並給一顆「先跳過」。
  改文案與一顆按鈕，半天以內。這一刀就把「差點關掉網頁」拿掉。
- 要裁決的：要不要給「系統幫我跑（花 US$ X）」這條路。給了就不再是零成本建檔；不給就要接受
  「不會用外部 AI 的人，品牌事實永遠是空的」——而品牌事實空的後果，`docs/issues/ad-loop/spec.md`
  已經寫過：方案品質差一階。
