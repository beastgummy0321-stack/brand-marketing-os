# 建檔精靈填到一半跳走再回來，填的字不見了

Status: 2026-09-06 可用性演練量到（`docs/drills/`）。小杰給 **3 分**，
是他整趟唯一「真的掉東西」的一次。

成因：建檔精靈第一步的表單沒有存草稿。使用者填了品牌名稱、還沒送出就切到別的頁面
（或按瀏覽器上一頁）再回來，欄位是空的。

使用者看到的（小杰）：
> 「期待『應該還在吧』，實際真的不見了，品牌名稱清空要重填。」

他測了兩條路都一樣：側邊選單跳走再回來、瀏覽器上一頁再回來。

範圍要講清楚，免得被當成比實際嚴重：**掉的是還沒送出的表單內容，不是資料庫裡的資料。**
同一輪他測的其他四種亂用都沒有掉東西——連按兩下沒有生出兩份、背景工作跑到一半整頁重整回來
原樣接上、開第二個分頁做同一件事沒有互相蓋掉、必填以外全留空一路走得下去。
建檔精靈**送出之後**的每一步（初掃、問答、產品、顧客原話）也都存得住，重新登入資料全在。

只有這一格是例外，而它剛好是每個新使用者遇到的第一格。

`file:line`：`frontend/src/components/intake/steps/`（起始輸入那一步）。

做法（未裁決，空間很小）：那一格的輸入存進瀏覽器本機（草稿只屬於這台機器這個人，
不必進資料庫），回來時填回去並說一句「幫你留著上次填的」。route A，一兩小時。
不必做通用的「全站表單草稿」——那是還沒有人要求的東西。
