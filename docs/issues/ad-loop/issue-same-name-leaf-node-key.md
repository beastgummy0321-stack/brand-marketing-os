# 同名的最深層節點，哪份內容配哪個位置是任意的

Status: wait-until-it-bites——2026-09-03 T3d 使用者裁決「先不根治」；至今一次都沒咬到人。
關聯：規則寫在 `docs/contracts/schedule.md`（Decisions in force, T3d）；根治動到 ADR 0047 的地盤。

成因：代理的回覆只帶節點**名稱**、不帶編號，同一份方案裡兩個廣告取一模一樣的名字時「先出現的
那段配第一個節點」——穩定，但無法證明是對的（審查原話：構造上無法證偽）。
影響：真跑那一輪是它最可能現形的時候。
根治：讓代理把 `node_key` 一起回傳（改部門提示詞檔＋解析＋測試）。
