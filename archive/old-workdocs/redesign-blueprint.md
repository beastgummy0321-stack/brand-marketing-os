## 一、定位

**行銷駕駛艙**：打開先看見各品牌狀況（圖表為主、純文字為輔），系統主動告訴你下一步。功能多但藏在引導後面，使用者只管點下一步。

## 三、模組化藍圖與接口鐵則

- 未來模組：**內容產出與發布、SEO 搜尋佈局、顧客與口碑、訊息推播（EDM/LINE）**——大方向確定，功能細節不預設，各模組動工前必先訪談使用者定流程。
- **廣告優先**：廣告模組全部落地（見第四節驗收定義）之前，不動其他新模組。
- **接口鐵則**：模組之間只透過定義好的通用內部接口交換資料，禁止直接 import 對方內部或共用資料表寫入（前車之鑑：廣告↔訂單糾纏，2026-08 才拆完）。
- **平台插槽**：廣告模組做成插槽式——Meta 為第一個完整插槽（範本），Google Ads、蝦皮廣告、TikTok Ads、LINE LAP 預留插槽位置與接口，之後逐一實作不改架構。

## 五、環境感知顧問（採第一＋第二層）

- **第一層（免費，先做）**：內建台灣行銷檔期日曆資料檔（固定節日＋電商大檔）。提前期分級：大檔（雙11、母親節）90 天/8 週、中檔 45 天/6 週、小檔 30 天/3 週；素材一律提前 14 天完稿提醒。檔期內投放分預熱→高潮→衝刺三階段。提醒進駕駛艙指南卡。
- **第二層（AI 聯網）**：**2026-08-11 已落地**。`complete()` 加了可選 `tools` 參數（預設不開），打法生成（`app/ads/plan.py`）與素材生成（`app/ads/creative.py`）兩處開通 web_search（`max_uses` 3、`user_location` TW），搜尋費計進 `llm_task.cost`。ADR 原文點名的第三處「下期建議」不存在（該檔沒有 LLM 呼叫），已在 ADR 0005 更正。
- **第三層（Google Trends 等第三方數據源）**：不做。官方 API 未開放、替代方案花錢且有法律灰色地帶，第二層跑穩後再評估。

## 六、全站修繕清單（persona 實測痛點）

1. 「進單建檔」全面正名為「品牌建檔精靈」（詞彙表已收錄）。
2. 「累積智慧」等頁面的工程內部用語（規則卡門檻等）全部翻白話。
3. 不可用的選單項目（未選品牌、即將推出）一律變灰＋提示，不得看起來可點。
4. 錯誤頁保留導覽與麵包屑，不得只剩一顆返回鈕。
5. 資料頁（品牌事實等）加摘要與分類，首屏不超過一屏文字。
6. 交接包手動搬運流程本次只優化操作指引（更手把手），自動化屬後端 agentic 工程，另案。

## 七、下一步指南卡（新建機制）

現況：建議都是「出事才跳」（打斷佇列）或「跑流程才出現」（方案生成）。新建常駐掃描：**判定用程式算，AI 只翻人話**（沿用系統鐵則）。貨源：待確認事實數、檔期卡在哪道關卡、判讀出爐未讀、下期草案已備好、檔期日曆備戰提醒、pacing 警示。與打斷佇列的分工見 CONTEXT.md 詞彙表。

## 十一、舊版介面 Persona 實測補充（2026-08-10，回應第六節）

進一步印證並補充第六節「全站修繕清單」，對應第八節「階段 4 全站遷移」動工時一併處理，本次不動工：

1. 核准計畫按鈕（純 HTML 表單、零 JavaScript）點擊後，在長時間同步 AI 呼叫期間零視覺回饋，使用者無法判斷是否成功送出，容易重複點擊。
2. AI 生成（計畫／素材）常見逾時或卡住，失敗訊息不一致（有時老實告知可重試，有時完全沉默）。
3. 目標 CPA／預算建議公式實質只服務「銷售」目標，選其他目標時顯示「此目標無公式依據」，但頁面其他區塊可能同時顯示轉換導向的預估數字，兩者互相矛盾。
4. 使用者手動輸入的自訂預算金額，在特定操作路徑下會被系統悄悄還原成滑桿預設值。
5. 素材／交接包頁面出現與品牌產業完全無關的法規警告（如食品安全法出現在五金行素材裡），研判規則卡套用範圍過寬。
6. 交接包每個欄位旁固定顯示「找不到這欄位」小字，即使欄位本身有正確內容，容易誤導使用者以為資料遺失。
7. 舊版「看素材」按鈕（檔期頁）直接連到 legacy `/creatives` 路徑，與新版素材工作檯並存且優先攔截使用者動線——新版全面上線前需決定去留或導向策略。

## 十二、Persona 測試方法論教訓

1. Workflow 的 `pipeline(items, singleStage)` 只有一個階段時不會依序執行，會變相同時並行——需要真的依序執行時用一般 `for` 迴圈搭配 `await`。
2. React SPA 掛載在 `/app` 前綴下（ADR 0003），組測試網址必須帶這個前綴，否則全部 404。
3. 隔離測試環境要同時隔離資料庫路徑（`BRAND_OS_DB`）與檔案輸出路徑（如 `creative_asset_root`），只隔離其中一個仍會讓真實輸出寫進正式目錄。
4. `FakeProvider()` 不帶自訂 `response` 時，預設回覆是佔位字串，不是合法的任務 JSON——拿來當「手動觸發生成」的安全網之前，要先確認預設回覆真的能通過對應的 `normalize_*()` 驗證。
